# Capsaicin の文書

Capsaicin は、Mac のスリープを種類ごとに止め、止めている間は Caps Lock の LED で知らせるメニューバーアプリである。この文書群は、何を作るか、どう振る舞うか、なぜそう決めたかを残す。

| 知りたいこと | 読む場所 |
| --- | --- |
| 何を、誰のために、なぜ作るか | [`product/`](product/) |
| 何を満たせばよいか | [`meta/requirements/`](meta/requirements/) |
| どう振る舞うか | [`specs/`](specs/) |
| なぜそう決めたか | [`meta/decisions/`](meta/decisions/) |
| まだ決まっていないこと | [`meta/questions/`](meta/questions/) |
| 確かめていない前提と、確かめた事実 | [`meta/hypotheses/`](meta/hypotheses/)、[`meta/evidence/`](meta/evidence/) |
| 将来の機能 | [`meta/plans/`](meta/plans/) |
| 進行中の作業 | [`meta/tasks/`](meta/tasks/) |

文書を足したり直したりする前に、[`documentation-management.md`](documentation-management.md) を読む。
