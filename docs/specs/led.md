# LED の仕様

## 対象範囲

抑止中に Caps Lock の LED で知らせる振る舞いと、LED が上書きされる可能性の案内を定める。LED を制御する方式は `DEC-LED-001` と `DEC-LED-003`、抑止中は常に点灯させる判断は `DEC-LED-002` にある。設定項目の既定値は `SPEC-SET-002` にある。

受け入れ例の共通の前提は、`specs/blocking.md` の「受け入れ例の共通の前提」にある。

## 状態

- LED の表示: Caps Lock の状態に連動する通常の動作（`"Auto"`）か、点灯（`"On"`）のどちらか。
- 「Caps Lock の LED で知らせる」のスイッチ。

## SPEC-LED-001 抑止中の点灯と解除後の復帰

関連要件: `REQ-LED-001`、`REQ-LED-002`、`REQ-LED-003`、`REQ-LED-008`

「Caps Lock の LED で知らせる」がオンのとき、抑止を開始したら対象のキーボード（`SPEC-LED-002`）の LED を点灯させ、抑止中は点灯させ続ける。止めるスリープの種類や Caps Lock の状態によって点灯の仕方を変えず、点滅もさせない。抑止を解除したら、LED を Caps Lock の状態に連動する通常の動作に戻す。LED を点灯できなくても抑止は始まり（開始の全部か無しかに LED は含めない。`SPEC-BLK-010`）、LED は止めるべきなのに適用できていない制御になる（`SPEC-BLK-007`）。

LED の制御で、Caps Lock の入力状態（大文字入力）は変えない。入力監視の権限を求めない。

### 受け入れ例: 入力状態を変えずに点灯する

1. Caps Lock がオフで、「Caps Lock の LED で知らせる」がオンの状態にする。
2. 抑止を開始し、テキストエディタで文字を入力する。
3. LED は点灯したままで、入力した文字は小文字のままである。入力監視の権限を求めるダイアログは出ない。

### 受け入れ例: Caps Lock を操作しても点灯したまま

1. Caps Lock がオフの状態で抑止を開始する。
2. Caps Lock をオンにし、続けてオフにする。
3. LED はどちらの間も点灯したままである。

### 受け入れ例: 解除したら通常の動作に戻る

1. Caps Lock がオフの状態で抑止を開始し、LED が点灯していることを確かめる。
2. 抑止を解除し、続けて Caps Lock をオンにしてからオフにする。
3. 解除で LED が消え、Caps Lock をオンにすると点き、オフにすると消える。

## SPEC-LED-002 対象のキーボード

関連要件: `REQ-LED-004`

内蔵キーボードと、接続している外付けキーボードのすべてを対象にする。抑止中にキーボードが接続されたとき、切断されたとき、Mac がスリープから復帰したとき、画面がスリープから復帰したとき、画面のロック（スクリーンセーバーを含む）が始まったときと終わったときは、その時点の対象に LED の状態を設定し直す。画面だけのスリープ、スクリーンセーバー、画面のロックでも、LED は Caps Lock に連動する通常の動作に戻されるためである（`EVID-LED-003`、`EVID-LED-004`）。ただし、画面がスリープしている間にロックが始まっても点け直さず、画面の復帰を待つ。画面のスリープ中は OS が LED を消しており、キーボードのバックライトも消えているためである。ロックの扱いは `DEC-LED-004` にある。外付けキーボードで LED が実際に光るかは `HYP-LED-003` で確かめる。

### 受け入れ例: 内蔵と外付けの両方が点灯する

1. 外付けキーボードを接続し、「Caps Lock の LED で知らせる」をオンにする。
2. 抑止を開始する。
3. 内蔵キーボードと外付けキーボードの両方で、Caps Lock の LED が点灯する。

### 受け入れ例: 抑止中に接続したキーボードも点灯する

1. 外付けキーボードを外した状態で抑止を開始する。
2. 抑止中に外付けキーボードを接続する。
3. 接続した外付けキーボードの LED が点灯する。

### 受け入れ例: 画面が復帰したら点灯し直す

1. 抑止を開始し、LED が点灯していることを確かめる。
2. 画面だけをスリープさせ（`pmset displaysleepnow`、または「手動スリープとディスプレイを閉じたときのスリープ」をオン、「閉じたときの画面」を「消灯」にして蓋を閉じる）、画面を復帰させる。
3. LED が点灯している。

### 受け入れ例: スクリーンセーバーやロックから戻ったら点灯している

1. 抑止を開始し、LED が点灯していることを確かめる。
2. スクリーンセーバーを起動して戻る。続けて、Control + Command + Q でロックし、解除する。
3. どちらの後も LED が点灯している。

### 受け入れ例: 画面のスリープ中にロックしても点灯しない

1. 「ディスプレイがオフになってからパスワードを要求」を「すぐに」にし、抑止を開始する。
2. `pmset displaysleepnow` で画面をスリープさせ、数秒待つ。
3. 画面が消えている間、LED も消えている。画面を復帰させると LED が点灯している。

## SPEC-LED-003 LED で知らせるかの設定

関連要件: `REQ-LED-005`

「Caps Lock の LED で知らせる」がオフのときは、抑止中も LED を制御せず、LED は Caps Lock の状態に連動したままにする。

### 受け入れ例

1. 「Caps Lock の LED で知らせる」をオフにし、Caps Lock をオフにする。
2. 抑止を開始する。
3. LED は消えたままである。

## SPEC-LED-005 Karabiner-Elements の案内

関連要件: `REQ-LED-007`

Karabiner-Elements の起動を検出したら、LED が上書きされて消えることがあることを、メニュー（`SPEC-MENU-001`）と設定の「LED」セクション（`SPEC-SET-002`）に表示する。終了を検出したら、案内を消す。Karabiner-Elements が LED を書き直しても、Capsaicin は書き直し返さない（選んだ理由は `DEC-LED-003`）。点灯が保たれるかは `HYP-LED-002` で確かめる。

### 受け入れ例

1. Karabiner-Elements を起動した状態で、Capsaicin のメニューを開き、設定の「LED」セクションを開く。
2. 表示を確かめ、Karabiner-Elements を終了してから、もう一度確かめる。
3. 起動中はどちらにも案内が表示され、終了後は表示されない。

## SPEC-LED-006 LED を制御できない環境

関連要件: `REQ-LED-001`

LED の制御に使う関数が OS にない環境では、LED の機能だけを無効にし、抑止のほかの機能は動かす（`DEC-LED-003`）。この環境では LED のあるべき状態を求めないので、LED は合わせられていない制御にならない。

### 受け入れ例

1. LED の制御に使う関数がないことを模した試験用のビルドで、アプリを起動する。
2. 抑止を開始する。
3. アプリは終了せず、スリープの抑止は効き、LED は Caps Lock の状態に連動したままである。

## 未決のこと

- LED が点灯し、Caps Lock の入力状態が変わらないこと: `HYP-LED-001`
- Karabiner-Elements が有効なときの点灯: `HYP-LED-002`
- 外付けキーボードの点灯: `HYP-LED-003`
