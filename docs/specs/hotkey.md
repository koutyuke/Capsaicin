# ホットキーの仕様

## 対象範囲

抑止を切り替えるグローバルホットキーと、その記録欄を定める。Caps Lock キーを使わない判断は `DEC-KEY-001`、記録欄の部品は `DEC-KEY-002` にある。既定値は `SPEC-SET-002` にある。

受け入れ例の共通の前提は、`specs/blocking.md` の「受け入れ例の共通の前提」にある。

## SPEC-KEY-001 ホットキーによる切り替え

関連要件: `REQ-KEY-001`

割り当てたホットキーは、どのアプリが前面にあっても効く。押したときの結果は `SPEC-BLK-011` のホットキーの行に従う。

### 受け入れ例

1. ホットキーを割り当て、別のアプリを前面にした停止中の状態にする。
2. ホットキーを押し、続けてもう一度押す。
3. 1回目で「抑止中」、2回目で「停止中」になる。

## SPEC-KEY-002 ホットキーの割り当て

関連要件: `REQ-KEY-002`

設定の「操作」セクションの記録欄で、キーの組み合わせを割り当て、外す。割り当てていないときは、ホットキーで切り替えられない。

- 未設定のときは、記録できることを示す仮の文字を表示する。設定済みなら、キーの組み合わせと、割り当てを消すボタンを表示する。
- クリックか Space で記録を始め、修飾キーを含む組み合わせを押すと確定する。Esc で記録を取り消す。Delete で割り当てを消す。
- システムやほかのアプリと重複しているなどで登録できないときは、確定せずに直前の値に戻し、記録欄の下にエラーの行（`exclamationmark.triangle.fill` と文字）を表示する。アラートは使わない。

### 受け入れ例: 割り当てて外す

1. 設定の「操作」を開き、記録欄をクリックする。
2. ⌃⌥⌘C を押す。続けて消すボタンを押す。
3. ⌃⌥⌘C が表示された後、割り当てなしに戻る。

### 受け入れ例: 登録できない組み合わせ

1. 記録欄に ⌃⌥⌘C を割り当てておく。
2. 記録を始め、システムが使っている組み合わせを押す。
3. 割り当ては ⌃⌥⌘C のままで、記録欄の下にエラーの行が表示される。
