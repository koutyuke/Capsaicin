# 蓋を閉じたときに輝度を 0 にする方式を実機で確かめる手順

オーナーが MacBook で `Q-BLK-001` を判断するための手順である。画面を暗くし、蓋を閉じて、光漏れ・ロック・画面収録・電池の電流を比べる。通常のユーザー権限で補助を動かす。所要時間は未実測だが、C5 だけで30分、C4 ではパスワードを要求するまでの時間を超える待機が要る。

一度に全部を行わなくてよい。判断に効く順は、準備 → C2（そもそも暗くする必要があるか）→ C3（閉じたまま暗くし、開けて戻せるか）→ C4（ロックされず取り込みが続くか）である。C1、C5、C6 は後に回してよい。C2 で「オンのまま」でも光らないと分かったら、残りは行わずに PM へ渡す。

## 確かめる問い

| 問い | 仮説・論点 | 手順 |
| --- | --- | --- |
| 「オンのまま」で閉じた蓋の中のバックライトは光り続けるか | `HYP-BLK-010` | C2 |
| 輝度 0 で真っ暗になり、スリープ・ロックせずに画面の取り込みが続くか | `HYP-BLK-011` | C1、C4 |
| 閉じている間は輝度 0 を保ち、開けた後は元の値を保てるか | `HYP-BLK-012` | C3 |
| 蓋を閉じた通知と開いた通知が数秒以内に届くか | `HYP-BLK-008` | C3 |
| 輝度 0 で機体全体の電力はどれだけ変わるか | `Q-BLK-001` | C5 |
| 強制終了や再起動で暗い画面が残り、手で戻せるか | `Q-BLK-001` | C6 |

DisplayServices から輝度を読めることは `EVID-BLK-007`、抑止中に蓋を閉じてもディスプレイがスリープしない観測は `EVID-BLK-008` にある。**`IODisplayParameters` は閉じても変わらないので、光っているかの判定に使わない。** 本手順の輝度変更・開閉・目視の結果は未検証であり、期待を実測として扱わない。

```text
[準備: 開始値と明るさのキーでの復旧を確かめる] ──復旧できない──▶ [中止]
│
▼
[C1〜C4: 暗さ・通知・復元・取り込み] ──異常──▶ [後片付け・PMへ報告]
│
▼
[C5: 電流比較 → C6: 強制終了と任意の再起動]
│
▼
[後片付け: 開始前の状態へ戻し、記録をPMへ渡す]
```

## 補助と記録の読み方

補助は `scripts/manual/display-brightness.swift` である。アプリには組み込まない。`xcrun swift scripts/manual/display-brightness.swift get` の形でも動くが、本手順ではビルドした実行ファイルを使う。起動直後に観測を始められ、`$!` が輝度を扱うプロセスの PID になるためである。

| サブコマンド | 動作 |
| --- | --- |
| `get` | 変更せずに状態を1行出す |
| `set 0`、`set 0.5` | 内蔵ディスプレイの輝度を 0〜1 にし、状態を1行出す。不正な値は変更せず失敗する |
| `watch` | 開閉の通知と10秒ごとに状態を出す |
| `watch --dim` | 開いていると分かっている状態から閉じたら、輝度を覚えて 0 にする。開いたら戻す。起動時に閉じていたら暗くしない |

各行には時刻、`event`、`pid`、`AppleClamshellState`（`1` は閉じた状態）、`CGDisplayIsActive`、`CGDisplayIsAsleep`、`brightness`、`InstantAmperage_mA`、`Voltage_mV`、`ExternalConnected` がある。電流は符号付き mA、電圧は mV、外部電源は `1` が接続である。`restoreBrightness` は閉じた瞬間に覚えた復元先で、保持していないときは `none` になる。`unknown` は取得できていない値で、0 と解釈しない。

`event=close` / `open` は IOKit の通知、`timer` は10秒ごとの読み取り、`start` は起動時である。`timer` に開閉の状態が出ただけでは、通知を受けた証拠にはならない。時刻は UTC の ISO 8601 である。開閉を操作した時刻も別の時計で秒まで控える。

`watch --dim` は閉じたときに一度だけ 0 を書く。macOS が輝度を上書きしても、補助は繰り返し 0 を書かない。元の値はメモリーだけに保持する。Ctrl-C（SIGINT）と SIGTERM では暗くしている間なら復元してから終了するが、`kill -9` やクラッシュでは復元しない。DisplayServices の失敗は `event=error` と操作名・状態値で出る。`watch --dim` の途中では続行するので、オーナーがログを見て止める。

以下は準備で開いた同じ Bash で行う。ログはリポジトリの外の `LC` に保存する。`verify.sh env` の変数 `B` とは分ける。ログの保存はシェルが行い、補助自体はファイルを保存しない。

**共通の中止条件**: Mac が熱いと感じる、焦げた臭いがする、明るさのキーで戻らない、抑止が解除できない、補助に `event=error` が出る。閉じた Mac をかばんに入れず、机の上に置く。異常時は蓋を開け、明るさのキーで戻し、補助と抑止を止めて「後片付け」へ進む。光が見えないだけなら中止ではなく、測定限界として残す。

## 準備

- **目的**: 開始前の状態を残し、画面が暗くても元に戻せる状態で C1〜C6 を始める。
- **前提**: 対応環境の MacBook、Xcode、Nix がある。Capsaicin が検証用環境で正常に動作し、「オンのまま」を使えるヘルパーの準備をオーナーが別途済ませている。本手順では設置・修復や `sudo`、`pmset` の設定変更、`launchctl` を行わない。準備がなければ PM に相談して止める。未保存の作業を保存する。
- **操作**:
  1. 外部ディスプレイをすべて外し、机の上に置く。Capsaicin の開始前の抑止状態と、「ディスプレイを閉じたとき」「ディスプレイを自動でオフにしない」、自動解除の条件を控える。別の試験や LED の検証と同時に行わない。
  2. ターミナルでリポジトリのルートを開き、Bash に入る。補助をビルドし、記録先と開始値を残す。

     ```sh
     bash
     umask 077
     ROOT="$PWD"
     LC="$(mktemp -d "$HOME/Capsaicin-dimming.XXXXXX")"
     mkdir -p .build/manual
     xcrun swiftc scripts/manual/display-brightness.swift -o .build/manual/display-brightness
     DB="$ROOT/.build/manual/display-brightness"
     sw_vers > "$LC/environment.txt"
     sysctl -n hw.model >> "$LC/environment.txt"
     "$DB" get | tee "$LC/before.log"
     printf '記録先: %s\n' "$LC"
     ORIGINAL="$(grep -o 'brightness=[0-9.e-]*' "$LC/before.log" | cut -d= -f2)"
     printf '元の輝度: %s\n' "$ORIGINAL" | tee "$LC/original-brightness.txt"
     ```

  3. `LC` の絶対パスを別のメモにも残す。以後の `$ORIGINAL` は開始前の輝度である。システム設定の「ディスプレイ」の自動輝度調節、True Tone、Night Shift と、「ロック画面」の「ディスプレイがオフになったあとにパスワードを要求」の値を画面写真かメモで `LC` に残す。スクリーンセーバーと画面消灯までの時間も控える。
  4. 蓋を開けたまま明るさを下げるキーを1回、上げるキーを1回押し、明るさが変わり、戻せることを目で確かめる。`"$DB" set "$ORIGINAL"` で開始値へ戻す。
  5. 自動輝度調節、True Tone、Night Shift をオフにする。Capsaicin の自動解除の条件を一時的にオフにし、「ディスプレイを閉じたとき」を「オンのまま」、「ディスプレイを自動でオフにしない」をオンにして抑止を開始する。すでに抑止中なら設定と状態を照合する。ヘルパーの設置・修復や管理者認証を求められたら承認せず止める。
- **期待**: `before.log` が1行で、輝度が 0〜1 の数値である。明るさのキーで復旧でき、Capsaicin は指定の設定で抑止中になる。
- **中止**: 共通条件に加え、オンラインの内蔵ディスプレイがない、開始値を読めない、既存の抑止を変更してよいか分からない、ヘルパーの準備がない場合。
- **復元**: 明るさのキー、または `"$DB" set "$ORIGINAL"` で戻す。変更した設定と抑止状態を「後片付け」で開始前に戻す。
- **記録**: 実行日、macOS の版とビルド、機種、Capsaicin のビルド、接続機器、電源、開始前の輝度と各設定、明るさのキーで戻ったこと、`LC` の絶対パス。

## C1

- **目的**: `HYP-BLK-011`。輝度 0 の暗さと、ディスプレイスリープせずに描画・取り込みが続くかを切り分ける。
- **前提**: 準備が完了し、蓋を開けている。暗い部屋で行う。秒が進む時計を画面に表示する。QuickTime Player の「ファイル」→「新規画面収録」で内蔵画面と時計を収録できる。収録の許可が必要ならオーナーが判断し、変更前の許可状態を控える。収録に秘密情報を映さない。
- **操作**:
  1. 時計が動いていることを目で見て収録を始める。
  2. `"$DB" set 0 > "$LC/C1-zero.log" 2>&1` を実行する。暗い部屋で画面が真っ暗か、淡く光るかを見る。
  3. 1分間操作せずに待ち、`"$DB" get >> "$LC/C1-zero.log" 2>&1` を実行する。暗い画面では事前にコマンドを入力しておき、Enter だけで実行してよい。
  4. 明るさを上げるキー、または `"$DB" set "$ORIGINAL"` で戻す。収録を止めて `LC` に保存し、暗くしていた1分間にも時計が進み、収録が黒くなっていないか再生する。
- **期待（仮説どおりなら）**: 目では真っ暗で、両方の観測が `brightness=0`、`CGDisplayIsAsleep=0` になる。収録には同じ明るさで動く時計が写り続ける。
- **中止**: 共通条件。QuickTime の収録が始まらない場合は取り込みの判定だけを判定不能にする。
- **復元**: 蓋を開けたまま明るさのキー、または `"$DB" set "$ORIGINAL"` で戻す。収録を停止する。
- **記録**: 暗さの目視、2行の状態、暗くした時刻、収録の時計が動く区間と止まる・黒くなる区間、収録ファイルのパス。

## C2

- **目的**: `HYP-BLK-010`。「オンのまま」で閉じた蓋の中が光るか、輝度によって電流が変わるかを見る。
- **前提**: 準備が完了し、C1 の収録を止めている。電源アダプターを外して電池駆動にする。暗い部屋で、同じアプリ・負荷を保つ。自動輝度調節はオフである。
- **操作**:
  1. 蓋を開け、明るさを上げるキーで最大にする。次を実行してから蓋を完全に閉じ、閉じた時刻を控える。

     ```sh
     "$DB" watch > "$LC/C2-max.log" 2>&1 & WATCH_PID=$!
     ```

  2. 蓋を持ち上げず、隙間から光が漏れるかを目で見る。蓋の間に物を挟まず、画面を押さない。5分待って開け、次で補助を止める。

     ```sh
     kill -INT "$WATCH_PID"
     wait "$WATCH_PID"
     ```

  3. 明るさを下げるキーで最小にし、1〜2を繰り返す。ログ名だけ `C2-min.log` に替える。両方で閉じていた区間の電流平均を、C5 の集計方法で比べる。
- **期待（仮説どおりなら）**: 最大のときだけ光漏れが見え、機体全体の放電電流の大きさも最小のときより大きい。見えないことだけでは消灯と断定しない。内蔵画面が `CGDisplayIsAsleep=0` で残るかも照合する。
- **中止**: 共通条件。隙間を安全に見られない場合は目視を判定不能にする。外部電源が接続された区間は電流の比較から外す。
- **復元**: 蓋を開け、補助を SIGINT で止める。`"$DB" set "$ORIGINAL"` で戻す。
- **記録**: 最大・最小それぞれの実測輝度、閉じた区間の開始・終了時刻、光漏れ、電流の平均・標本数、電圧と外部電源、負荷、ログのパス。

## C3

- **目的**: `HYP-BLK-012` と `HYP-BLK-008`。輝度 0 の維持、開けた後の復元、開閉両方の通知を確かめる。
- **前提**: 準備の設定で抑止中である。蓋を開け、`"$DB" set "$ORIGINAL"` で戻している。自動輝度調節がオフの場合とオンの場合の2回を行う。
- **操作**:
  1. 次を実行し、`event=start` が開いた状態を示すことを読む。直前の `brightness` をその回の復元先として控える。

     ```sh
     "$DB" watch --dim > "$LC/C3-auto-off.log" 2>&1 & WATCH_PID=$!
     ```

  2. 蓋を閉じ、5分待って開ける。開閉の時刻を別の時計で秒まで控える。開けた直後の明るさを目で見て、さらに1分間操作せずに待つ。`kill -INT "$WATCH_PID"` と `wait "$WATCH_PID"` で止める。
  3. `event=close` と `event=open` の両方が開閉から数秒以内にあるかを読む。`close` の `restoreBrightness` が実際の復元先である。閉じている間の10秒ごとの輝度が 0 か、開けてから1分間の輝度がその復元先と一致するかを比べる。`HYP-BLK-012` の30秒ごとの記録は、この10秒ごとのログで含めて観測する。
  4. 自動輝度調節をオンにして落ち着いてから、1〜3を `C3-auto-on.log` で繰り返す。閉じる直前の値を改めて控える。読み戻しの小さな差も生の値で残し、一致の許容幅は PM が判断する。
  5. 自動輝度調節をオフに戻す。閉じたまま元の輝度へ戻せるかを確かめる（抑止を閉じたまま解除したときに当たる）。1と同じ起動を `C3-restore-closed.log` で行い、次を実行して30秒以内に蓋を閉じる。1分後に開け、開ける直前に `event=signal-2` の行で輝度が戻っていたかと、開けた直後の明るさを控える。

     ```sh
     sleep 30; kill -INT "$WATCH_PID"; wait "$WATCH_PID"
     ```

- **期待（仮説どおりなら）**: 両方の自動輝度調節の設定で、閉じている間は輝度 0、開けた後は閉じる直前の値が続く。両通知が届く。閉じたままでも元の輝度へ戻せる。
- **中止**: 共通条件。通知がなく暗くならない場合や、輝度が上書きされた場合は失敗を記録し、手で戻す。`timer` だけを通知の成功に数えない。
- **復元**: 蓋を開け、SIGINT で止める。戻らなければ明るさのキー、または `"$DB" set "$ORIGINAL"` で戻す。自動輝度調節はオフに戻す。
- **記録**: 各設定での閉じる直前の値、開閉時刻と通知の遅れ、閉じた全区間と開けた後1分間の輝度、上書きの有無と時刻、閉じたままの復元の結果。

## C4

- **目的**: `HYP-BLK-011`。閉じたまま描画・収録が続き、パスワードを要求する時間を過ぎてもロックされないかを見る。
- **前提**: 準備が完了し、自動輝度調節はオフである。C1 と同じ時計と QuickTime の収録を用意する。パスワードを要求するまでの時間を `T` として控える。「しない」の場合はロックの比較ができないので、オーナーが有限の時間への一時変更を承認するか、ロックだけ判定不能にする。開始値は必ず残す。
- **操作**:
  1. 「オンのまま」で時計の収録を始め、`"$DB" watch --dim > "$LC/C4-dim.log" 2>&1 & WATCH_PID=$!` を実行する。
  2. 蓋を閉じ、10分と `T` の長い方にさらに1分を足した時間、操作せず待つ。有限の `T` を設定しない場合は11分待ち、ロックは判定不能にする。可能なら、すでに利用できる別端末から画面共有で時計が進むかを見る。共有機能を新たに有効にする必要があるなら、この確認は省略してその旨を残す。
  3. 蓋を開けたときにロック画面が出るかを見る。収録を止めて保存し、閉じていた区間で時計が動き続けたか再生する。補助を SIGINT で止める。
  4. 比較のため、抑止を解除して「ディスプレイを閉じたとき」を「ディスプレイをオフ」に替え、抑止を再開する。`watch --dim` は動かさず、`watch` を `C4-display-off.log` に記録する。時計の収録を始め、2〜3と同じ時間、閉じて待つ。ロック画面・収録・共有の違いを比べる。
- **期待（仮説どおりなら）**: 輝度 0 の回は `CGDisplayIsAsleep=0` のままで、開けてもロック画面が出ず、収録と共有で時計が動く。「ディスプレイをオフ」の回ではディスプレイスリープと、設定に応じたロックが起こる。共有あり・なしの結果は混ぜない。
- **中止**: 共通条件。時計の停止、黒い収録、ロック画面は仮説と異なる結果として残す。比較の回でもロックされなければ、パスワードの設定によるロックの切り分けは判定不能にする。
- **復元**: 蓋を開け、収録と補助を止める。明るさを戻す。抑止を解除し、「オンのまま」に戻してから再開する。一時変更したパスワード要求の設定を開始値へ戻す。
- **記録**: `T` と実際の待機時間、両モードの開閉時刻、ロック画面、ディスプレイの状態、時計が進む・止まる・黒くなる時刻、画面共有の有無と接続時刻、収録のパス。

QuickTime と画面共有の結果だけでは、Computer Use が継続することまでは確定しない。必要ならオーナーが利用するツールでも同じ区間を取り込み、ツール名と結果を PM に渡す。

## C5

- **目的**: `Q-BLK-001`。3方式で閉じている間の機体全体の放電電流を比較する。
- **前提**: 電池駆動で、ログの `ExternalConnected=0` が続く。外部ディスプレイなし、自動輝度調節はオフである。時計の表示を含め同じアプリ・負荷を保ち、画面収録・画面共有はすべての回で止める。机、室温、True Tone、Night Shift の条件もそろえる。残量不足なら充電してから初めから測り直す。
- **操作**:
  1. 「オンのまま」で抑止し、`"$DB" set "$ORIGINAL"` で戻す。`watch` を `C5-keep-on.log` に記録し、蓋を閉じて10分間操作せず待つ。開けて SIGINT で止める。起動と停止のコマンドは C2 と同じである。
  2. 同じ設定で `watch --dim` を `C5-dim.log` に記録し、同じく閉じて10分待つ。開けて止め、輝度の復元を読む。
  3. 抑止を解除し、「ディスプレイをオフ」に替えて再開する。輝度の設定は `$ORIGINAL` にそろえ、`watch` を `C5-display-off.log` に記録して同じく10分待つ。開けて止める。
  4. 次で閉じている間の `timer` 行だけを集計する。C2 はファイル名を `C2-max.log` と `C2-min.log` に替えて使う。

     ```sh
     python3 - "$LC/C5-keep-on.log" "$LC/C5-dim.log" "$LC/C5-display-off.log" <<'PY'
     import statistics
     import sys
     for path in sys.argv[1:]:
         samples = []
         with open(path) as log:
             for line in log:
                 fields = dict(word.split('=', 1) for word in line.split() if '=' in word)
                 if (fields.get('event') == 'timer'
                         and fields.get('AppleClamshellState') == '1'
                         and fields.get('ExternalConnected') == '0'
                         and fields.get('InstantAmperage_mA') not in (None, 'unknown')):
                     samples.append(float(fields['InstantAmperage_mA']))
         print(path, 'n=', len(samples), 'mean_mA=', statistics.mean(samples) if samples else '判定不能')
     PY
     ```

- **期待**: 単発値でなく10分区間の平均を比較できる。放電が負なら、平均が 0 に近いほど電流の大きさが小さい。符号の違う区間を絶対値で混ぜない。輝度 0 でどれだけ減るかは未確認であり、数値の合格基準は置かない。
- **中止**: 共通条件。電源接続、アプリの更新・重い処理、電池残量不足、ログの欠測があればその回を比較から外し、判定不能として残す。
- **復元**: 補助を止め、蓋を開け、元の輝度に戻す。抑止を解除して「オンのまま」に戻し、次の C6 を行う場合だけ再開する。
- **記録**: 各回の開始・終了時刻、残量、電圧、電流平均・標本数、3方式の差、同じ負荷だったこと、温度の体感、欠測や別の処理、ログのパス。10秒周期なら1回の標本数はおよそ60であり、時刻と合わせて全区間を測れたか読む。

電流は機体全体の値で、バックライトだけの電力ではない。電圧も残し、電流差だけをそのまま W と書かない。順序や残量、温度の差が大きければ逆順でも測り、結果を別の回として残す。

## C6

- **目的**: `Q-BLK-001`。強制終了や再起動で輝度 0 が取り残されるか、明るさのキーで復旧できるかを見る。
- **前提**: 準備の設定で抑止中、蓋は開いている。自動輝度調節はオフで、元の輝度に戻してある。明るさのキーでの復旧を C1 で確認済みである。対象は補助だけで、Capsaicin を強制終了しない。
- **操作**:
  1. 補助を起動し、対象の PID と実行ファイルを読む。

     ```sh
     "$DB" watch --dim > "$LC/C6-kill.log" 2>&1 & WATCH_PID=$!
     ps -p "$WATCH_PID" -o pid=,comm=
     ```

  2. 表示が `$DB` の PID と一致した場合だけ次を実行し、30秒以内に蓋を閉じる。SIGKILL では復元処理を通らない。1分待って開け、キーを押す前に暗いままかを目で見て控える。

     ```sh
     sleep 30; kill -KILL "$WATCH_PID"; wait "$WATCH_PID"
     ```

  3. 明るさを上げるキーで戻せるかを確かめ、`"$DB" get > "$LC/C6-after-key.log" 2>&1` で状態を読む。`C6-kill.log` に `event=close` と `brightness=0` がなければ、暗くしている間の強制終了は判定不能にする。
  4. 再起動の確認は任意である。保存済みの作業と、暗いログイン画面から明るさのキーで戻す手段を用意できる場合だけ行う。抑止を解除し、Capsaicin の起動時再開をオフにして開始値を控える。蓋を開けたまま次を実行し、15秒以内に Apple メニューの「再起動…」を選んで確認ダイアログを出す。暗くなってから Enter で確定する。ダイアログを出せなかった場合はキーで明るさを戻し、この確認は省略する。ログイン前の画面が暗いままか、明るさのキーで戻せるかを記録する。ログイン後にも輝度を読み、`LC` は準備で控えたパスを使う。

     ```sh
     sleep 15; "$DB" set 0 > "$LC/C6-before-restart.log" 2>&1
     ```
- **期待**: 強制終了後・再起動後に暗さが残るかは未確認である。暗くする前の値がファイルに保存されないため、自動復元は期待しない。明るさのキーで戻せるかを独立して記録する。
- **中止**: 共通条件。PID が一致しない場合はシグナルを送らない。ログイン前の復旧に不安がある場合は再起動を省略し、理由を残す。
- **復元**: 明るさを上げるキーで画面を見える状態にする。ログイン後、リポジトリのルートで補助の `set` に準備で控えた元の数値を渡して戻す。残る補助があれば SIGINT で止め、抑止と起動時再開の設定を開始値へ戻す。
- **記録**: 止めた PID、停止時刻と直前の輝度、開けた直後の暗さ、キーで戻ったか、再起動の実施・省略理由、ログイン前後の暗さ、元の値へ戻したこと。

## 後片付け

1. 蓋を開ける。動作中の補助があれば、記録した PID へ SIGINT を送り、終了を待つ。
2. 明るさのキーで画面を見える状態にし、`"$DB" set "$ORIGINAL"` で開始前の輝度へ戻す。再起動した場合は、準備のメモから `DB` と `ORIGINAL` を入れ直す。
3. Capsaicin の抑止を解除し、蓋の動作・画面の自動消灯の抑止・自動解除・起動時再開を開始前の値に戻す。開始前に抑止中だった場合だけ、その設定で再開する。解除できなければ復旧済みとせず PM に報告する。
4. 自動輝度調節、True Tone、Night Shift、ロック画面、収録の許可、電源と接続機器を開始前に戻す。自動輝度調節を戻した後は値が変わりうるので、手で設定した値と復元後の観測を分ける。
5. `"$DB" get > "$LC/after.log" 2>&1` と目視で画面を確認する。`LC` のログ・収録は PM が結果を取り込むまで消さない。

## PM に渡す記録

各行を「支持／反証／判定不能／中止」で埋め、期待と照らした事実を書く。実測をしていない行を成功に数えない。生のログ、収録、画面写真は `LC` に残し、表には絶対パスと該当時刻を書く。PM が根拠を作り、仮説と `Q-BLK-001` の判断へ反映する。

| 項目・条件 | 判定 | 実測と期待との差 | ログ・収録の絶対パスと時刻 |

| 準備: 環境・元の輝度・全設定・復旧キー | | | |
| C1: 暗さ・Asleep・時計の収録 | | | |
| C2: 最大 / 最小の光漏れ・電流平均と標本数 | | | |
| C3: 自動輝度調節オフ / オン、両通知・復元後1分 | | | |
| C3: 閉じたままの復元 | | | |
| C4: 輝度 0 / ディスプレイオフのロック・収録・共有 | | | |
| C5: オンのまま / 輝度 0 / ディスプレイオフの区間平均・電圧・標本数 | | | |
