# 手動のスリープとディスプレイを閉じたときのスリープを止める

「ディスプレイを閉じたとき」がヘルパーを使う値のとき、スリープ防止中は Apple メニューの「スリープ」とディスプレイを閉じたときのスリープが止まり、解除すると元に戻ることを確かめる。確かめる仕様と仮説は `HYP-BLK-006`、`SPEC-BLK-001`、`SPEC-BLK-002`、`HYP-BLK-008` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- `SleepDisabled` が `0` である。
- `prepare.md` で用意した署名・公証済みの PR Debug ビルドを `/Applications` に置いている。ヘルパーの登録とシステム設定での許可を承認済みである。ad-hoc 署名の `just build` では行わない。
- MacBook は電源につなぎ、外部ディスプレイをつながず机上に置く。閉じた Mac をかばんに入れない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
APP="$(cat "$B/app-path.txt")"
printf 'APP=%s\n' "$APP"
/usr/bin/pmset -g
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
/usr/bin/open "$APP"
sleep 5
/bin/ps -axo pid,ppid,comm | /usr/bin/grep '[C]apsaicin.app/Contents/MacOS/Capsaicin'
```

設定の「スリープ」の「ディスプレイを閉じたとき」（MacBook 以外の Mac では「メニューからのスリープも防ぐ」）の値と、設定の「ヘルパー」の「状態」を `"$B/result-manual-and-lid-sleep.txt"` に控える。「状態」が「未インストール」なら、「ディスプレイスリープ」を選び、確認の「インストール」を押す。MacBook 以外の Mac では「メニューからのスリープも防ぐ」をオンにして「インストール」を押す。「システム設定での許可待ち」か「有効」になったら、今回登録したことを控える。

「システム設定での許可待ち」なら、「ヘルパー」の「システム設定を開く」を押す。システム設定の「一般 > ログイン項目と機能拡張」で Capsaicin の項目を許可し、アプリの設定ウインドウに戻る。識別子とパスを BTM の記録と照合し、Release や別アプリと区別できない項目は変更しない。macOS の項目名は実装にないため、検証時の画面で照合する。

```sh
/usr/bin/sfltool dumpbtm
```

「ヘルパー」が「有効」でなければ試験を始めない。ヘルパーはバンドル内のデーモンを登録するもので、実行ファイルを直接呼んだり、システムの配置先へコピーしたりしない。時間とバッテリーの解除条件をオフにし、その開始値も控える。

## 操作と期待

1. 「ディスプレイを閉じたとき」を「ディスプレイスリープ」にし（MacBook 以外の Mac では「メニューからのスリープも防ぐ」をオン）、メニューの「スリープ防止をオンにする」で開始して状態を読む。

   ```sh
   /usr/bin/pmset -g
   ```

   期待: `SleepDisabled` が `1` である。

2. Apple メニューを開き、「スリープ」を選べないことを確かめる。MacBook では続けてディスプレイを1分閉じてから開く。開く前後の時刻とスリープのログを記録する。

   ```sh
   /bin/date '+%Y-%m-%dT%H:%M:%S%z'
   /usr/bin/pmset -g log | /usr/bin/grep -iE 'sleep|wake'
   ```

   期待: Apple メニューのスリープとディスプレイを閉じたときのスリープが止まる。「ディスプレイスリープ」では閉じている間に画面が消える。閉じている間の消灯を安全に目で見られなければ、消灯は判定不能とする。

   ネットワークの応答はスリープの断定に使わない。別の端末から ping を使う場合は、ディスプレイを開いているときに疎通する検証 Mac の IP を記録してから、`IP_ADDRESS` を置き換えて実行する。応答だけ、または無応答だけで判定せず、スリープのログと突き合わせる。

   ```sh
   ping -c 3 IP_ADDRESS
   ```

3. MacBook では、メニューの「スリープ防止をオフにする」で解除し、「ディスプレイを閉じたとき」を「オンのまま」にして、もう一度「スリープ防止をオンにする」で開始する。ディスプレイを1分閉じてから開き、時刻とログを記録する。

   ```sh
   /usr/bin/pmset -g
   /bin/date '+%Y-%m-%dT%H:%M:%S%z'
   /usr/bin/pmset -g log | /usr/bin/grep -iE 'sleep|wake'
   ```

   期待: `SleepDisabled` が `1` で、閉じている間もスリープしない。操作2の「ディスプレイスリープ」と違い、画面を消す処理はしない。

4. メニューの「スリープ防止をオフにする」で解除し、状態を読む。

   ```sh
   /usr/bin/pmset -g
   ```

   期待: `SleepDisabled` が `0` に戻る。もう一度ディスプレイを閉じるとスリープし、開くと復帰する。

`HYP-BLK-006` の「片方だけは指定できない」という仕組みの主張は、実測とは別のソースの調査で確かめる。

## 中止するとき

想定外の権限要求がある、状態が分からない、異常に発熱する、解除後もスリープできない場合は止める。メニューの「スリープ防止をオフにする」で解除し、状態を読む。

```sh
/usr/bin/pmset -g
```

`SleepDisabled` が `0` に戻らなければ、次で下ろす。それでも戻らなければ後続を止めて PM に報告する。

```sh
/usr/bin/sudo /usr/bin/pmset -a disablesleep 0
/usr/bin/pmset -g
```

設定変更のコマンドは成功しても何も出力しないので、直後の `pmset -g` で値を確かめる。

## 元に戻す

メニューの「スリープ防止をオフにする」で解除し、`SleepDisabled` が `0` であることを確かめる。

```sh
/usr/bin/pmset -g
```

この手順でヘルパーを登録した場合は、設定の「ヘルパー」で「削除…」を選び、確認の「削除」を押し、「状態」が「未インストール」になったことを確かめる。「ディスプレイを閉じたとき」（MacBook 以外の Mac では「メニューからのスリープも防ぐ」）と時間・バッテリーの解除条件を控えた値へ戻す。削除に失敗したら登録とアプリを残し、`cleanup.md` で片付ける。

## 記録

`"$B/result-manual-and-lid-sleep.txt"` に次を書く。

- 各操作の `SleepDisabled`
- `pmset -g log` の該当行、ディスプレイを閉じていた時刻、復帰にかかった時間
- 「ディスプレイスリープ」と「オンのまま」の比較、ヘルパーを設置・削除したか
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
