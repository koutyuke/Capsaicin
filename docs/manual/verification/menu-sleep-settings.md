# クイック設定のスリープとディスプレイの項目

メニューの「クイック設定」で、チェックが保存値を示し、スリープ防止中の変更がその場で効くことを確かめる。ヘルパーが使えない場合は、選べない項目と副題を確かめる。確かめる仕様は `SPEC-MENU-008`、`SPEC-SET-005`、`SPEC-SET-006`、`SPEC-BLK-009` である。

最初の1回の準備は [`prepare.md`](prepare.md)、最後の片付けは [`cleanup.md`](cleanup.md) で行う。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- `SleepDisabled = 0` の環境で行う。この手順ではヘルパーの登録や許可を変更せず、ファイルを手で壊して注意の表示を作らない。開始時の状態に当てはまらない操作は判定不能にする。
- MacBook と MacBook 以外の Mac の出し分けは、用意できる機種でそれぞれ確かめる。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
APP="$(cat "$B/app-path.txt")"
printf 'APP=%s\n' "$APP"
/usr/bin/pmset -g
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
/usr/bin/open "$APP"
sleep 5
/bin/ps -axo pid,ppid,comm | /usr/bin/grep '[C]apsaicin.app/Contents/MacOS/Capsaicin'
```

次の開始値を `"$B/result-menu-sleep-settings.txt"` に控えてから変える。

- 設定の「スリープ」の「ディスプレイの自動オフを許可」「ディスプレイを閉じたとき」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）の値と、設定の「ヘルパー」の「状態」。
- 「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をオフにする。
- システム設定の VoiceOver の値。

システム設定の「一般 > ログイン項目と機能拡張」の Capsaicin の許可も、BTM の識別子とパスを照合して控える。macOS の項目名は実装にないため、検証時の画面で照合する。Release や別アプリの項目と区別できなければ変更しない。

```sh
/usr/bin/sfltool dumpbtm
```

## 操作と期待

1. メニューを開き、トップレベルに「クイック設定」が1つだけあり、チェックの付く項目と左のチェック用の余白がないことを見る。「クイック設定」を1回開き、項目・選択肢・区切りを `SPEC-MENU-008` と比べる。

   期待: MacBook では、「ディスプレイの自動オフを許可」、区切り、見出し「ディスプレイを閉じたとき」、「Macをスリープ（標準）」「ディスプレイをオフ」「明るさを0」「オンのまま」、区切りが並ぶ。MacBook 以外の Mac では見出しも閉じたときの選択肢もなく、「ディスプレイの自動オフを許可」に続いて「Appleメニューからのスリープも防ぐ」がある。内蔵バッテリーのある Mac では、さらに区切りと「バッテリー残量…%未満でオフにする」が続く。どの項目も字下げされず、選べる項目はさらにサブメニューを開かずに選べる。項目名・選択肢・順序が設定画面と同じで、チェックが保存値を示す。ヘルパーの注意があるときは、トップレベルの行と保存値の項目に注意の記号が付く。

2. スリープ防止がオフで、ヘルパーが要る設定が保存されていないときに行う。「スリープ」で「ディスプレイの自動オフを許可」をオフにしてから、「クイック設定」で同じ項目をオンにする。設定画面とメニューを開き直す。

   期待: 設定画面とチェックが同じ値を示す。

   「スリープ防止をオンにする」で開始してアサーションを読む。「クイック設定」で同じ項目をオフにし、もう一度アサーションを読む。

   ```sh
   /usr/bin/pmset -g assertions | /usr/bin/grep -i -A2 capsaicin
   ```

   期待: 停止中も抑止中もサブメニューを1回開くだけで項目を選べ、チェックと設定画面が同じ保存値を示す。停止中は仕組みを操作せず、抑止中の変更はその場で反映される。ほかの設定値は変わらない。抑止中は「ディスプレイの自動オフを許可」がオフになった後にだけ Capsaicin の `PreventUserIdleDisplaySleep` がある。

   メニューの「スリープ防止をオフにする」で解除する。

3. ヘルパーが「未インストール」で、「ディスプレイを閉じたとき」が「Macをスリープ（標準）」のときに行う。MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」がオフであることを確かめる。設定ウインドウを閉じ、「クイック設定」で「ディスプレイをオフ」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）を選ぼうとする。

   - MacBook の期待: 「Macをスリープ（標準）」以外の選択肢は選べない項目になり、どの選択肢にも副題は出ない。選んでも何も起きず、設定画面もダイアログも開かない。「Macをスリープ（標準）」の選択肢にチェックが付いたままである。
   - MacBook 以外の Mac の期待: 「Appleメニューからのスリープも防ぐ」は選べず、副題は出ない。設定画面もダイアログも開かず、チェックは付かない。

4. ヘルパーが要る設定を保存したまま、ヘルパーが一部だけ残っていて使えない試験環境がすでにある場合だけ、トップレベルの「クイック設定」の行を見てからサブメニューを開く。元の保存値を選び直せなくなるため、この操作では値を変えない。

   - MacBook の期待: トップレベルの行が「⚠︎ クイック設定」になっている。保存値の選択肢にチェックが残り、項目名の先頭に「⚠︎」が付き、副題に「ヘルパーが有効になっていないため、設定を反映できません。」が出る。ほかの選択肢に副題は出ない。「Macをスリープ（標準）」は選べ、ほかの選択肢は選べない。
   - MacBook 以外の Mac の期待: トップレベルの行は「⚠︎ クイック設定」になっている。「Appleメニューからのスリープも防ぐ」はチェックが残り、同じ記号と副題が付き、オフにするために選べる。オフにすると選べない項目になり、副題は消える。

5. ヘルパーが「有効」な MacBook で VoiceOver をオンにする。「クイック設定」を開き、「ディスプレイを閉じたとき」の各選択肢を順に読み上げ、1つ選ぶ。

   期待: 閉じたときの見出しの下に、設定画面と同じ順序で選択肢が並び、前後が区切りで囲まれていて、さらにサブメニューを開かずに選べる。何の動作を選ぶかが読み上げで分かり、選んだ保存値の選択肢だけにチェックが付く。

   VoiceOver を開始値に戻す。

## 中止するとき

保存値とチェックが食い違う、選べないはずの項目を選べた、またはその操作で設定画面やダイアログが開いた場合は止める。設置の確認が開いた場合は「キャンセル」で閉じる。登録や許可は変更しない。抑止中ならメニューの「スリープ防止をオフにする」で解除し、状態を記録する。

```sh
/usr/bin/pmset -g
/usr/bin/sfltool dumpbtm
```

## 元に戻す

抑止中なら、メニューの「スリープ防止をオフにする」で解除する。VoiceOver と変更した設定を控えた値に戻し、`SleepDisabled` が `0` であることを確かめる。元の値を選べない場合は、ヘルパーの登録や許可を変更せず PM に報告する。保存値の最終復元は `cleanup.md` で行う。

```sh
/usr/bin/pmset -g
/usr/bin/sfltool dumpbtm
```

## 記録

`"$B/result-menu-sleep-settings.txt"` に次を書く。

- 機種ごとの項目と選択肢、サブメニューを開いた回数、トップレベルの左の余白
- チェックと保存値の前後、アサーションの前後
- 選べない項目と副題の位置、設定画面やダイアログが開いたか、注意の記号と副題、読み上げ
- 安全に用意できず判定不能にした確認、成功／失敗／判定不能、未実施の操作と理由
