# クイック設定のスリープとディスプレイの項目

メニューの「クイック設定」から、設定画面と同じスリープとディスプレイの設定をサブメニュー1回で切り替えられ、チェックが保存値を示し、スリープ防止中の変更がその場で効くことを確かめる。確かめる仕様は `SPEC-MENU-008`、`SPEC-SET-005`、`SPEC-SET-006`、`SPEC-BLK-009` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- ヘルパーの設置や修復は、`SleepDisabled` が `0` の環境で、表示される確認と認証を承認できる場合だけ行う。ヘルパーのファイルを手で壊して注意の表示を作らない。
- MacBook と MacBook 以外の Mac の出し分けは、用意できる機種でそれぞれ確かめる。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

次の開始値を `"$B/result-menu-sleep-settings.txt"` に控えてから変える。

- 設定の「スリープ」の「ディスプレイを自動でオフにしない」「ディスプレイを閉じたとき」（MacBook 以外の Mac では「メニューからのスリープも防ぐ」）の値と、設定の「ヘルパー」の「状態」。
- 「タイマー」「指定時刻」「残量が少なくなったらオフにする」をオフにする。
- システム設定の VoiceOver の値。

## 操作と期待

1. メニューを開き、トップレベルに「クイック設定」が1つだけあり、チェックの付く項目と左のチェック用の余白がないことを見る。「クイック設定」を1回開き、項目・選択肢・区切りを `SPEC-MENU-008` と比べる。

   期待: MacBook では、「ディスプレイを自動でオフにしない」、区切り、見出し「ディスプレイを閉じたとき」、「システムスリープ（標準）」「ディスプレイスリープ」「明るさを0」「オンのまま」、区切りが並ぶ。MacBook 以外の Mac では「ディスプレイを自動でオフにしない」と「メニューからのスリープも防ぐ」が並ぶ。内蔵バッテリーのある Mac では、さらに区切りと「バッテリー残量…%未満でオフにする」が続く。どの項目も字下げされず、さらにサブメニューを開かずに選べる。項目名・選択肢・順序が設定画面と同じで、チェックが保存値を示す。

2. スリープ防止がオフのときに「クイック設定」の「ディスプレイを自動でオフにしない」を切り替え、設定画面とメニューを開き直す。

   期待: 設定画面とチェックが同じ値を示す。

   「スリープ防止をオンにする」で開始し、同じ項目を切り替えるたびにアサーションを読む。

   ```sh
   /usr/bin/pmset -g assertions | /usr/bin/grep -i -A2 capsaicin
   ```

   期待: 変更がその場で効き、オンのときだけ `PreventUserIdleDisplaySleep` がある。ほかの設定の値は変わらない。

3. ヘルパーが「未インストール」の環境で、「クイック設定」でヘルパーが要る選択肢（「ディスプレイスリープ」など。MacBook 以外の Mac では「メニューからのスリープも防ぐ」）を選び、「ヘルパーをインストールしますか？」で「キャンセル」を選ぶ。

   期待: 保存値とチェックが元のままである。確認・エラー・巻き戻しは設定画面と同じである。

   設置・修復・認証の取り消し・失敗のときの確認を安全に行える場合だけ、設定画面と同じ条件でメニューからも試す。用意できなければ、その確認を判定不能にする。

4. ヘルパーが要る保存値のまま、ヘルパーを使えない状態がすでにある場合だけ、メニューの「クイック設定」を見る。ヘルパーのファイルを手で壊してこの状態を作らない。なければ、この確認は判定不能にする。

   期待: 「クイック設定」の行に注意の記号がある。サブメニューでは、MacBook では保存値の選択肢、MacBook 以外の Mac では「メニューからのスリープも防ぐ」に注意の記号と副題「ヘルパーが正しくインストールされていないため、この設定を適用できません。設定の「ヘルパー」で修復してください。」があり、チェックを保ったまま操作できる。

5. MacBook で VoiceOver をオンにし、「クイック設定」を開いて「ディスプレイを閉じたとき」の各選択肢へ順に移る。

   期待: 読み上げが「ディスプレイを閉じたとき、ディスプレイスリープ」のように見出しと選択肢を合わせ、ディスプレイを閉じたときの動作の選択だと分かる。

   VoiceOver を開始値に戻す。

## 中止するとき

保存値とチェックが食い違う、取り消しても変更が残る、反映に失敗しても巻き戻らない場合は止める。承認の範囲を超える設置・修復は進めない。メニューの「スリープ防止をオフにする」で解除し、状態を記録する。

```sh
just status
```

## 元に戻す

メニューの「スリープ防止をオフにする」で解除する。試した設定と VoiceOver を控えた値へ戻す。この手順でヘルパーを設置した場合は、設定の「ヘルパー」で「削除…」を選び、確認と認証を承認して削除する。「状態」が「未インストール」になり、`SleepDisabled` が `0` であることを確かめる。

```sh
just status
```

## 記録

`"$B/result-menu-sleep-settings.txt"` に次を書く。

- 機種ごとの項目と選択肢、サブメニューを開いた回数、トップレベルの左の余白
- チェックと保存値の前後、アサーションの前後
- 設置・修復の確認と取り消しの結果、注意の記号の位置と副題、読み上げ
- 安全に用意できず判定不能にした確認、成功／失敗／判定不能、未実施の操作と理由
