# クイック設定のスリープとディスプレイの項目

メニューの「クイック設定」から、設定画面と同じスリープとディスプレイの設定をサブメニュー1回で切り替えられ、チェックが保存値を示し、スリープ防止中の変更がその場で効くことを確かめる。確かめる仕様は `SPEC-MENU-008`、`SPEC-SET-005`、`SPEC-SET-006`、`SPEC-BLK-009` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- ヘルパーを使う確認は、`prepare.md` で用意した署名・公証済みの PR Debug ビルドで、`SleepDisabled = 0` の環境だけで行う。登録とシステム設定での許可の変更をオーナーが承認している。ファイルを手で壊して注意の表示を作らない。
- MacBook と MacBook 以外の Mac の出し分けは、用意できる機種でそれぞれ確かめる。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
APP="$(cat "$B/app-path.txt")"
printf 'APP=%s\n' "$APP"
/usr/bin/pmset -g
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
/usr/bin/open "$APP"
sleep 5
/bin/ps -axo pid,ppid,comm | /usr/bin/grep '[C]apsaicin.app/Contents/MacOS/Capsaicin'
```

次の開始値を `"$B/result-menu-sleep-settings.txt"` に控えてから変える。

- 設定の「スリープ」の「ディスプレイの自動オフを許可」「ディスプレイを閉じたとき」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）の値と、設定の「ヘルパー」の「状態」。
- 「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をオフにする。
- システム設定の VoiceOver の値。

システム設定の「一般 > ログイン項目と機能拡張」の Capsaicin の許可も、BTM の識別子とパスを照合して控える。macOS の項目名は実装にないため、検証時の画面で照合する。Release や別アプリの項目と区別できなければ変更しない。

```sh
/usr/bin/sfltool dumpbtm
```

## 操作と期待

1. メニューを開き、トップレベルに「クイック設定」が1つだけあり、チェックの付く項目と左のチェック用の余白がないことを見る。「クイック設定」を1回開き、項目・選択肢・区切りを `SPEC-MENU-008` と比べる。

   期待: MacBook では、「ディスプレイの自動オフを許可」、区切り、見出し「ディスプレイを閉じたとき」、「Macをスリープ（標準）」「ディスプレイをオフ」「明るさを0」「オンのまま」、区切りが並ぶ。MacBook 以外の Mac では「ディスプレイの自動オフを許可」と「Appleメニューからのスリープも防ぐ」が並ぶ。内蔵バッテリーのある Mac では、さらに区切りと「バッテリー残量…%未満でオフにする」が続く。どの項目も字下げされず、さらにサブメニューを開かずに選べる。項目名・選択肢・順序が設定画面と同じで、チェックが保存値を示す。

2. スリープ防止がオフのときに「クイック設定」の「ディスプレイの自動オフを許可」を切り替え、設定画面とメニューを開き直す。

   期待: 設定画面とチェックが同じ値を示す。

   「スリープ防止をオンにする」で開始し、同じ項目を切り替えるたびにアサーションを読む。

   ```sh
   /usr/bin/pmset -g assertions | /usr/bin/grep -i -A2 capsaicin
   ```

   期待: 変更がその場で効き、オンのときだけ `PreventUserIdleDisplaySleep` がある。ほかの設定の値は変わらない。

3. ヘルパーが「未インストール」の環境で、「クイック設定」で「ディスプレイをオフ」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）を選ぶ。アラートのタイトルは MacBook では「ディスプレイを閉じてもスリープさせないには、ヘルパーのインストールが必要です」、MacBook 以外の Mac では「「Appleメニューからのスリープも防ぐ」を使うにはヘルパーのインストールが必要です」である。「キャンセル」を選ぶ。

   期待: 保存値とチェックが元のままである。確認・エラー・巻き戻しは設定画面と同じである。

   登録と許可の確認も承認済みなら、もう一度「ディスプレイをオフ」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）を選び、確認の「インストール」を押す。「ヘルパー」が「システム設定での許可待ち」か「有効」になったら今回登録したことを控える。許可待ちなら、開いたシステム設定で識別済みの Capsaicin の項目を許可し、アプリの設定ウインドウに戻る。「有効」になってから保存値とチェックが選んだ値になることを確かめる。安全に用意できなければ、この確認は判定不能にする。

4. ヘルパーが要る保存値のまま、ヘルパーを使えない状態がすでにある場合だけ、メニューの「クイック設定」を見る。この操作では許可を変更して状態を作らず、なければ判定不能にする。

   期待: トップレベルの行が「⚠︎ クイック設定」になっている。サブメニューでは、MacBook では保存値の選択肢、MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」の項目名の先頭に「⚠︎」が付き、副題「ヘルパーが有効になっていないため、設定を反映できません。」があり、チェックを保ったまま操作できる。副題は「ヘルパー」の状態によらず同じ文で、設定画面の同じ行の説明文の先頭と一致する。

5. MacBook で VoiceOver をオンにし、「クイック設定」を開いて「ディスプレイを閉じたとき」の各選択肢へ順に移る。

   期待: 読み上げが「ディスプレイを閉じたとき、ディスプレイをオフ」のように見出しと選択肢を合わせ、ディスプレイを閉じたときの動作の選択だと分かる。

   VoiceOver を開始値に戻す。

## 中止するとき

保存値とチェックが食い違う、取り消しても変更が残る、反映に失敗しても巻き戻らない場合は止める。承認の範囲を超える登録・許可の変更は進めない。メニューの「スリープ防止をオフにする」で解除し、状態を記録する。

```sh
/usr/bin/pmset -g
/usr/bin/sfltool dumpbtm
```

## 元に戻す

メニューの「スリープ防止をオフにする」で解除する。VoiceOver を控えた値へ戻す。この手順でヘルパーを登録した場合は、設定の「ヘルパー」で「削除…」を選び、確認の「削除」を押す。「状態」が「未インストール」になったことを確かめる。試した設定を控えた値へ戻し、`SleepDisabled` が `0` であることを確かめる。アプリと登録の最終的な片付けは `cleanup.md` で行う。

```sh
/usr/bin/pmset -g
/usr/bin/sfltool dumpbtm
```

## 記録

`"$B/result-menu-sleep-settings.txt"` に次を書く。

- 機種ごとの項目と選択肢、サブメニューを開いた回数、トップレベルの左の余白
- チェックと保存値の前後、アサーションの前後
- 設置の確認と取り消し、登録と許可の結果、注意の記号の位置と副題、読み上げ
- 安全に用意できず判定不能にした確認、成功／失敗／判定不能、未実施の操作と理由
