# クイック設定のバッテリー残量の項目

メニューの「クイック設定」からバッテリー残量の条件をサブメニュー1回で切り替えられ、スリープ防止中にオフにすると電源を外しても続き、オンに戻すとその場で解除されることを確かめる。この手順はコマンドを使わず、画面と電源アダプターの操作で確かめる。確かめる仕様は `SPEC-MENU-008`、`SPEC-SET-002`、`SPEC-SET-006`、`SPEC-BLK-006`、`SPEC-BLK-009` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- 内蔵バッテリーがあり、残量が30%以上90%以下で、電源アダプターをすぐにつなぎ直せる Mac を使う。残量が範囲外なら充放電して合わせず、この検証を判定不能とする。電池を消耗させて条件を作らない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

次の開始値を `"$B/result-menu-battery.txt"` に控えてから変える。

- 電源アダプターの接続状態。
- 設定の「スリープ」の「残量が少なくなったらオフにする」「しきい値」「電源アダプタ接続中は残量でオフにしない」の値。
- 「ディスプレイを閉じたとき」を「Macをスリープ（標準）」にする（MacBook 以外の Mac では「メニューからのスリープも防ぐ」をオフ）。「タイマー」と「指定時刻」をオフにする。
- 「LED」の「スリープ防止中にCaps LockのLEDを点灯」をオフにする。

## 操作と期待

1. 電源アダプターをつなぎ、設定の「残量が少なくなったらオフにする」をオンにする。「しきい値」を5%、10%、100%と動かす。「電源アダプタ接続中は残量でオフにしない」をオンにして、設定画面を閉じる。

   期待: 「しきい値」は5%刻みで選べ、0%は選べない（`SPEC-SET-002`）。

2. メニューを開き、トップレベルにチェックの付く項目と左のチェック用の余白がないことを見る。「クイック設定」を1回開き、項目の並びを `SPEC-MENU-008` と比べる。

   期待: 区切りの後に「バッテリー残量100%未満でオフにする」があり、さらにサブメニューを開かずに選べる。副題に「電源アダプタ接続中は除く」が出る。チェックと設定画面は同じオン・オフを示す。

   「バッテリー残量100%未満でオフにする」を選んでオフにし、サブメニューのチェックと設定画面を見る。

   期待: どちらもオフになり、項目名は保存した100%のしきい値のままである。

   スリープ防止がオフのままオンに戻し、設定画面を閉じてメニューを開き直す。

3. 「スリープ防止をオンにする」で開始し、「クイック設定」の「バッテリー残量100%未満でオフにする」をオフにする。メニューを開き直し、状態の行とサブメニューのチェックを見る。

   期待: 保存値とチェックがオフになり、状態のバッテリーの行がなくなる。「手動でオフにするまで継続」の行は残る。

   電源アダプターを外す直前に残量が30%以上90%以下であることを確かめてから外す。

   期待: 電源アダプターを外してもスリープ防止が続く。

   同じ項目をオンに戻す。

   期待: 保存値とチェックがオンになり、その場で解除される。残量が減るのを待つ必要はない。

   自動の解除を確かめたらすぐに電源アダプターをつなぎ直し、設定画面とメニューを開いて保存値とチェックを見る。

4. スリープ防止がオフのときに、設定画面で「電源アダプタ接続中は残量でオフにしない」をオフにし、「クイック設定」を開く。

   期待: 「バッテリー残量100%未満でオフにする」の副題がない。

   「電源アダプタ接続中は残量でオフにしない」をオンに戻し、もう一度開く。

   期待: 副題「電源アダプタ接続中は除く」が出る。メニューからは「しきい値」と「電源アダプタ接続中は残量でオフにしない」を変えられず、「タイマー」と「指定時刻」も出ていない。切り替えられる範囲は `SPEC-MENU-008` と一致する。

## 中止するとき

設定とチェックが食い違う、オフでも解除される、オンに戻しても解除されない場合は止める。電源を外す直前に残量が範囲外になっていたら外さずに止める。想定外の権限要求や発熱があるとき、電源をつなぎ直せないときも止める。止めたら電源アダプターをつなぎ、メニューの「スリープ防止をオフにする」で解除する。

## 元に戻す

電源アダプターをつなぎ、スリープ防止が残っていればメニューの「スリープ防止をオフにする」で解除する。スリープ防止がオフのときに、「残量が少なくなったらオフにする」「しきい値」「電源アダプタ接続中は残量でオフにしない」と、ほかの試した設定を控えた値へ戻す。電源の接続を開始前に戻す。

## 記録

`"$B/result-menu-battery.txt"` に次を書く。

- 残量と電源の接続の前後、しきい値の範囲と刻み
- サブメニューを開いた回数、トップレベルの左の余白、項目名・副題・チェック、設定画面との一致
- 状態のバッテリーの行、オンに戻した直後の解除
- 戻した値、成功／失敗／判定不能、未実施の操作と理由
