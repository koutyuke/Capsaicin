# 画面消灯、スクリーンセーバー、MacBook とバッテリーの判定

`pmset displaysleepnow` が root なしで画面を消せること、MacBook かどうかと内蔵バッテリーの有無で画面が出し分けられること、スリープ防止中はスクリーンセーバーが自動で起動しないことを確かめる。確かめる仕様と仮説は `HYP-BLK-001`、`HYP-BLK-008`、`HYP-BLK-009`、`HYP-SET-001`、`HYP-SET-002`、`SPEC-SET-006` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- 画面が消えても、キーボードかトラックパッドで復帰できる。
- 機種ごとの結果を残すので、用意できる MacBook と MacBook 以外の Mac のそれぞれで行う。1台の結果をほかの機種の合格にしない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフ（「スリープ防止をオンにする」が出ている）であることを確かめる。

```sh
just start
just status
```

## 操作と期待

1. 管理者ユーザーと一般ユーザーのそれぞれで、`sudo` なしで実行する。

   ```sh
   /usr/bin/pmset displaysleepnow
   printf 'exit=%s\n' "$?"
   ```

   期待: 終了コード `0` で画面が消える。

2. 開閉とバッテリーの検出値を読む。

   ```sh
   /usr/sbin/ioreg -r -c IOPMrootDomain -d1 -w0 | /usr/bin/grep AppleClamshellState
   /usr/bin/pmset -g batt
   ```

   設定の「スリープ」を開き、検出値と照らす。

   期待: MacBook だけで `AppleClamshellState` があり、「ディスプレイを閉じたとき」のポップアップが表示され、行のアイコンが `laptopcomputer` になる。MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」のスイッチが表示され、アイコンが `powersleep` になる。

3. 設定の「スリープ」に「バッテリーによる自動解除」のグループがあるかを記録する。メニューの「クイック設定」を開き、「バッテリー残量…%未満でオフにする」の項目があるかを見る。UPS がある場合は、その有無と製品名も書く。

   期待: 「バッテリーによる自動解除」のグループと、「クイック設定」のバッテリー残量の項目は、内蔵バッテリーのある Mac だけにある。

4. システム設定の「ロック画面」で、スクリーンセーバーの自動起動までの時間とディスプレイをオフにするまでの時間を控える。スクリーンセーバーの時間を最短にし、ディスプレイをオフにするまでの時間をそれより長くする。設定の「スリープ」で「ディスプレイの自動オフを許可」をオフにし、メニューの「スリープ防止をオンにする」で開始する。スクリーンセーバーの時間より長く操作せずに待つ。「スリープ防止をオフにする」で解除し、同じだけ待つ。

   期待: スリープ防止中はスクリーンセーバーが自動で起動せず、解除後は起動する。

`pmset -g batt` は IOPS の型の直接の測定ではない。`HYP-SET-002` の UPS と内蔵バッテリーの型の区別は、型を出す試作プログラムがないので判定不能とする。`HYP-BLK-008` の通知時刻もアプリが記録しないので、画面消灯は間接の確認にとどめる。

## 中止するとき

画面の消灯から復帰できない、想定外の権限要求がある場合は止める。キーボードかトラックパッドで画面を復帰させ、メニューの「スリープ防止をオフにする」で解除する。

## 元に戻す

メニューの「スリープ防止をオフにする」で解除する。システム設定の「ロック画面」の2つの時間と、設定の「ディスプレイの自動オフを許可」を控えた値へ戻す。接続した機器を開始前の状態に戻す。

## 記録

`"$B/result-display-sleep-and-hardware-detection.txt"` に、機種ごとに次を書く。

- 機種名、操作1を実行したユーザーの種類（管理者・一般）と終了コード
- `AppleClamshellState` の有無、設定のポップアップかスイッチか、行のアイコン
- 「バッテリーによる自動解除」のグループと、「クイック設定」のバッテリー残量の項目の有無、UPS の有無
- スクリーンセーバーと画面の時間の開始値、スリープ防止中と解除後の自動起動の有無、戻した値
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
