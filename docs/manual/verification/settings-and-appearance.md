# 設定画面の構成と外観

設定ウインドウの寸法と構成、各セクションのカード・見出し・アイコン・説明、子の行の無効表示、外観への追従、「このアプリについて」からの終了、「継続時間」の入力を確かめる。計測できない寸法は目で見ただけで合格にしない。確かめる仕様は `SPEC-SET-001`、`SPEC-SET-002`、`SPEC-SET-003`、`SPEC-SET-004`、`SPEC-SET-005`、`SPEC-SET-006`、`SPEC-UI-001`、`SPEC-UI-002`、`SPEC-UI-003`、`SPEC-UI-004`、`SPEC-UI-005`、`SPEC-UI-006` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。準備で OS の外観・アクセントカラー・文字の大きさの開始値を写真に残している。
- 設定の既定値の判定は、既存の設定がない環境（準備で `defaults.absent` ができた環境）でだけ行う。既存の設定を削除して既定値の試験を足さない。
- 寸法は、画面写真に定規を当てるのではなく、Accessibility Inspector か画面撮影の解像度から換算して確かめる。換算できない場合は「目視のみ」と書いて判定不能に寄せる。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

試す設定（「一般」の「メニューバーにアイコンを表示」、「スリープ」の「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」とその子の行）の開始値を `"$B/result-settings-and-appearance.txt"` に控える。

## 操作と期待

1. メニューの「設定…」で設定を開き、サイドバーの6セクション（「一般」「スリープ」「フィードバック」「操作」「ヘルパー」「このアプリについて」）を順に選ぶ。

   期待: ウインドウは幅720 pt × 高さ500 pt、サイドバー200 pt の固定で、最小化とズームが無効である。上端を横切るタイトルバーの帯がなく、サイドバーが上端まで伸び、右側の最上段に選んだセクション名が出る。サイドバーの上に4項目、下端に「ヘルパー」と「このアプリについて」が並び、下端からシステム既定の余白だけ離れている。

   文字サイズやサイドバーのアイコンのサイズを変えたときの下端寄せは確かめ済みなので（`EVID-SET-002`）、ここでは試さない。

   サイドバーで ↑↓ を押し、6項目を通して移動する。

   期待: 上下の境目でも選択が続く。

2. 各セクションの項目名の下の説明文を読む。続けて VoiceOver をオンにし、説明文のある行のコントロールに移る。

   期待: 説明文は操作しなくても項目名の下に出ている。「スリープ」では「ディスプレイの自動オフを許可」、MacBook 以外の Mac の「Appleメニューからのスリープも防ぐ」、「指定時刻に自動解除」にだけ説明文があり、文が `SPEC-SET-002` の表と一致する。VoiceOver は、コントロールに移ったときに説明文を読む。

   「フィードバック」セクションを選んでから ⌘W で閉じ、開き直す。

   期待: 選択が保たれる。

   各セクションのカード・見出し・アイコンを `SPEC-SET-002` の表と比べる。

   期待: 「スリープ」が「スリープとディスプレイ」「時間による自動解除」「バッテリーによる自動解除」の3グループに分かれ、「タイマーで自動解除」と「指定時刻に自動解除」が「時間による自動解除」に、「バッテリー残量が少ないときに自動解除」とその子の行が「バッテリーによる自動解除」にある。「バッテリー残量」の値は「20%未満」の形で出る。「一般」は見出しがなく、「ログイン時に起動」のカードと、「メニューバーにアイコンを表示」「Dockにアイコンを表示」のカードの2枚が並ぶ。「フィードバック」は「Caps LockのLED」と「HUD」の2グループで、それぞれ先頭に説明とイラストのカードがあり、イラストはカードの右端まで広がって角で切り取られる。内蔵バッテリーがない Mac では「バッテリーによる自動解除」のグループ全体がない。子の行にはアイコンがなく、項目名が親とそろう。「スリープ」は下端までスクロールでき、すべての行を操作できる。

   「操作」が、ホットキーの割り当ての失敗の表示を含めてスクロールせずに収まるかを記録する（`HYP-UI-004`）。失敗の表示を出す安全な条件を用意できなければ、その項目だけ判定不能とする。

   「フィードバック」を開いたまま10秒ほど見る。続けて「視差効果を減らす」をオンにして見直し、控えた値に戻す。

   期待: `SPEC-SET-009` のとおりに動く。LED は点いた直後だけ輪が広がり、点いている間は明るさが変わらない。「視差効果を減らす」がオンの間は、LED が点灯し HUD が出ている絵のまま動かない。

3. 「スリープ」の各行を見る。

   期待: 「ディスプレイを閉じたとき」に「Macをスリープ（標準）」「ディスプレイをオフ」「明るさを0」「オンのまま」の4つがあり、独立した子の行がない。「バッテリー残量が少ないときに自動解除」の項目名だけで、オンにするとバッテリー残量が少ないときにスリープ防止が自動解除されると分かる。

   ヘルパーが使えない状態で、それを要する設定が保存されている場合は、表示を見る。このファイルでは許可の変更やファイルの破損で状態を作らない。その状態がなければ、この確認だけ判定不能にする。

   期待: 保存した選択肢（MacBook 以外の Mac ではオンのスイッチ）が表示されたまま、行のアイコンが注意の記号に替わる。項目名の下の説明文の先頭に「ヘルパーが有効になっていないため、設定を反映できません。」が出る。「ヘルパー」の状態（未インストール、システム設定での許可待ち、このビルドでは使用不可）によらず同じ文である。

   ヘルパーが「有効」のときは、ヘルパーに関する注意の記号と注意の文がない。「明るさを0」で輝度を変えられない注意は別に扱う。

   「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をそれぞれオフ・オンする。

   期待: 子の行（「継続時間」「時刻」「バッテリー残量」「電源アダプタ接続中は自動解除しない」）は、親がオフの間は字下げとグレーで無効と分かり、説明文がない。切り替えで行が動かない。オンに戻すと値が保たれている。

4. 「このアプリについて」でバージョンとビルド番号をコピーし、別の場所に貼る。

   期待: 「バージョン…（…）」の文字列をコピーできる。

5. システム設定でライト、ダーク、アクセントカラーを切り替え、各画面を撮る。変えるたびに値を記録する。文字の大きさを変えられる環境では、変える前の値を記録してから比べる。

   期待: 外観に追従して読める。既定値の判定をする環境では、既定値が [設定仕様](../../specs/settings.md) の表と一致する。

6. メニューの「スリープ防止をオフにする」で解除されていることを確かめ、設定の「一般」の「メニューバーにアイコンを表示」をオフにする。設定画面を閉じ、Finder と同じ経路で開き直す。

   ```sh
   /usr/bin/open .build/xcode/Build/Products/Debug/Capsaicin.app
   ```

   「このアプリについて」のバージョンの下にある「Capsaicinを終了」を押す。

   ```sh
   just status
   ```

   期待: ボタンは標準の枠付きで色が付かず、押すとアプリが終了する。

   アプリを起動し直し、「メニューバーにアイコンを表示」を控えた値に戻す。

   ```sh
   just start
   ```

7. 「スリープ」で「タイマーで自動解除」をオンにし、「継続時間」の時間・分それぞれに `Stepper` があることを見る。次を順に試し、保存値の前後を記録する。
   1. 0時間0分、24時間1分、数字でない文字を入力する。

      期待: 別の値に直らず、確定もできず、最後の有効な保存値が変わらない。

   2. 0時間58分にして分の `Stepper` を上げ、分の数値欄で ↓ を押す。

      期待: 上げると1時間3分になり、↓ で0時間58分に戻る。

   3. 23時間30分にして時間の `Stepper` を上げ、時間の数値欄で ↑ を押す。

      期待: 24時間0分で止まる。

   4. 0時間3分から分を下げる。

      期待: 0時間1分で止まる。

   試した値と「タイマーで自動解除」のオン・オフを控えた値へ戻す。

## 中止するとき

元の OS の設定が分からない、ほかのアプリへ影響する変更を避けられない場合は止める。変えた OS の設定を、準備で撮った写真の開始値へ戻す。

## 元に戻す

試したアプリの設定を控えた値へ戻す。OS の外観、文字の大きさ、アクセントカラーを開始値へ戻す。アプリが止まっていれば起動する。

```sh
just status
just start
```

## 記録

`"$B/result-settings-and-appearance.txt"` に次を書く。

- 6セクションそれぞれの表示、寸法の実測値と測り方、タイトルバーとサイドバーの状態
- カードと項目のアイコン、ヘルパーの状態・説明文・注意の文、スクロールの有無、「一般」が収まるか
- 「このアプリについて」からの終了、「継続時間」の入力の結果と保存値の前後
- 撮った画面写真の絶対パス、戻した設定、成功／失敗／判定不能、未実施の操作と理由
