# 設定画面を開くデスクトップと前面

設定画面が、ほかのデスクトップやフルスクリーンのアプリの上でも、いまのデスクトップに前面のキーウインドウとして開くことを確かめる。この手順はコマンドをほとんど使わず、目で確かめる。確かめる仕様と仮説は `SPEC-SET-001` の「ほかのデスクトップとフルスクリーン」と `HYP-SET-003` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- デスクトップ（Space）が2つ以上ある。Safari など、フルスクリーンにできるアプリを1つ用意する。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動する。

```sh
just start
just status
```

次の開始値を `"$B/result-settings-window-placement.txt"` に控えてから変える。

- システム設定の「デスクトップと Dock」にある「アプリケーションの切り替えで、アプリケーションのウインドウが開いているスペースに移動」をオンにする。この項目名は macOS の版で変わりうるので、検証する Mac の画面の表記を控える。
- Capsaicin の設定の「一般」の「Dockにアイコンを表示」をオフにする。

## 操作と期待

キーウインドウになったかは、タイトルの色と閉じるボタンの色で見る。

1. 設定画面を閉じた状態で Safari を前面にし、メニューの「設定…」で開く。

   期待: 設定画面が Safari の前に、前面のキーウインドウとして開く。

2. デスクトップ1で設定画面を開いたまま、デスクトップ2に移って Safari を前面にし、メニューの「設定…」で開く。

   期待: デスクトップ1へ移り、設定画面が前面のキーウインドウになる。

3. 設定画面を ⌘W で閉じ、デスクトップ2で Safari を前面にしてから、メニューの「設定…」で開く。

   期待: デスクトップ2に、前面のキーウインドウとして開く。デスクトップ1へは移らない。

4. 設定画面を閉じ、Safari をフルスクリーンにしてから、メニューの「設定…」で開く。終わったら Safari のフルスクリーンを解除する。

   期待: フルスクリーンの Safari の上に、前面のキーウインドウとして開く。デスクトップは切り替わらない。

5. 設定画面を閉じ、「Dockにアイコンを表示」をオンにして、次を順に行う。
   1. Safari を前面にし、メニューの「設定…」で開く。
   2. 設定画面をデスクトップ1で開いたまま、デスクトップ2に移って Safari を前面にし、メニューの「設定…」で開く。続けて同じ状態から、メニューの代わりに Dock のアイコンをクリックする。
   3. 設定画面を ⌘W で閉じ、デスクトップ2で Safari を前面にしてから、メニューの「設定…」で開く。閉じて同じ状態から、Dock のアイコンのクリックでも開く。
   4. 設定画面を閉じ、Safari をフルスクリーンにしてから、メニューの「設定…」で開く。終わったら Safari のフルスクリーンを解除する。

   期待: 1は Safari の前に前面のキーウインドウとして開く。2はデスクトップ1へ移り、設定画面が前面のキーウインドウになる。3はデスクトップ2に前面のキーウインドウとして開き、デスクトップ1へは移らない。4はフルスクリーンの Safari の上に前面のキーウインドウとして開き、デスクトップは切り替わらない。メニューと Dock のアイコンで結果が同じである。

6. 「アプリケーションの切り替えで…」をオフにする。設定画面をデスクトップ1で開いたまま、デスクトップ2に移って Safari を前面にし、メニューの「設定…」で開く。

   期待: デスクトップ2にとどまる。設定画面がデスクトップ2へ移ってくることもない。

## 中止するとき

設定画面がどのデスクトップにも見つからない、操作を受け付けなくなった場合は止める。Safari のフルスクリーンを解除し、アプリを終了して起動し直す。

```sh
just stop
just start
just status
```

## 元に戻す

Safari のフルスクリーンを解除する。「アプリケーションの切り替えで…」と「Dockにアイコンを表示」を控えた値へ戻す。

## 記録

`"$B/result-settings-window-placement.txt"` に、「Dockにアイコンを表示」のオン・オフごと、操作ごとに次を書く。

- 前面になったアプリ、移ったデスクトップ、設定画面が出たデスクトップ、キーウインドウになったか
- 期待と違った操作の画面録画の絶対パス
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
