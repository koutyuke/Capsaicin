# 「ディスプレイを閉じたとき」の表示と説明

設定の「スリープ」の「ディスプレイを閉じたとき」が1つのポップアップに4つの選択肢を持ち、ヘルパーが要る設定を適用できないときに注意の表示が出ることを確かめる。ディスプレイを実際に閉じる試験やヘルパーの設置は含めない。確かめる仕様は `SPEC-SET-002`、`SPEC-SET-005`、`SPEC-SET-006` である。

最初の1回の準備は [`prepare.md`](prepare.md)、最後の片付けは [`cleanup.md`](cleanup.md) で行う。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- MacBook を使う。
- ヘルパーの登録と許可は変更しない。開始時の状態に当てはまらない操作は判定不能にする。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
APP="$(cat "$B/app-path.txt")"
printf 'APP=%s\n' "$APP"
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
/usr/bin/open "$APP"
just status
```

設定の「ヘルパー」の「状態」（「有効」「未インストール」「システム設定の許可待ち」「このビルドでは使用不可」のどれか）と、「ディスプレイを閉じたとき」の現在の値を `"$B/result-lid-close-setting.txt"` に控える。

## 操作と期待

1. 設定の「スリープ」を開き、「ディスプレイを閉じたとき」の選択肢と、項目名の下を見る。

   期待: 独立した子の行がなく、1つのポップアップに「Macをスリープ（標準）」「ディスプレイをオフ」「明るさを0」「オンのまま」の4つがある。ヘルパーが「有効」で、輝度の注意もなければ、項目名の下に説明文がない。

2. ヘルパーが「有効」なら、「オンのまま」、「Macをスリープ（標準）」、「ディスプレイをオフ」の順に選ぶ。「Macをスリープ（標準）」を選んだ後は、設定ウインドウを一度閉じて開き直してから「ディスプレイをオフ」を選ぶ。各選択の後に保存値を読む。

   ```sh
   /usr/bin/defaults export io.github.koutyuke.capsaicin.debug - | python3 -c 'import json, plistlib, sys; print(json.dumps(json.loads(plistlib.loads(sys.stdin.buffer.read()).get("capsaicin.settings", b"{}")), ensure_ascii=False, indent=2))'
   ```

   期待: 各選択で保存値が表の対応になり、開き直しても保存値に対応する選択肢が表示される。行の数と並びは変わらない。

   | 選択肢 | `blocksManualSleep` | `lidCloseDisplay` |
   | --- | --- | --- |
   | 「オンのまま」 | `true` | `keepOn` |
   | 「Macをスリープ（標準）」 | `false` | `keepOn`（変わらない） |
   | 「ディスプレイをオフ」 | `true` | `turnOff` |

3. ヘルパーが使えず、「Macをスリープ（標準）」が保存されている場合は、ポップアップを開いて「オンのまま」を選ぼうとする。ポップアップを閉じて項目名の下を見る。

   期待: 「Macをスリープ（標準）」以外の選択肢はグレーで選べず、アラートは出ない。項目名の下に「「Macをスリープ（標準）」以外を選ぶには、ヘルパーを有効にする必要があります。」が出る。保存値は変わらない。

4. ヘルパーが使えず、「オンのまま」が保存されている場合は、表示を見てポップアップを開く。この手順では元の値を選び直せなくなるため、「Macをスリープ（標準）」を実際には選ばない。

   期待: ポップアップは「オンのまま」を表示し、開いて「Macをスリープ（標準）」を選べる。ほかの選択肢はグレーで選べない。アイコンが注意の記号に置き換わり、項目名の下に「ヘルパーが有効になっていないため、設定を反映できません。」だけが出る。

## 中止するとき

ヘルパーが使えないのにヘルパーが要る選択肢を選べた、またはアラートが出た場合は止める。設置の確認が開いた場合は「キャンセル」で閉じる。結果を記録し、登録や許可は変更しない。

## 元に戻す

操作2で値を変えた場合は、「ディスプレイを閉じたとき」を始める前に控えた値へ戻す。ヘルパーの状態は変えない。元の値を選べない場合は、許可を変更せず PM に報告する。保存値の最終復元は `cleanup.md` で行う。

## 記録

`"$B/result-lid-close-setting.txt"` に次を書く。

- ポップアップの表示、各選択肢の操作可否、保存値、注意の記号と説明文
- ヘルパーの状態、元の設定値と戻した値
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
