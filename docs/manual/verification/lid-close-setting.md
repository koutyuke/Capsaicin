# 「ディスプレイを閉じたとき」の表示と説明

設定の「スリープ」の「ディスプレイを閉じたとき」が1つのポップアップに4つの選択肢を持ち、ヘルパーが要る設定を適用できないときに注意の表示が出ることを確かめる。ディスプレイを実際に閉じる試験やヘルパーの設置は含めない。確かめる仕様は `SPEC-SET-002`、`SPEC-SET-005`、`SPEC-SET-006` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- MacBook を使う。
- ヘルパーの設置や許可の案内が出ても、この手順では承認しない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

設定の「ヘルパー」の「状態」（「有効」「未インストール」「システム設定での許可待ち」「このビルドでは使用不可」のどれか）と、「ディスプレイを閉じたとき」の現在の値を `"$B/result-lid-close-setting.txt"` に控える。

## 操作と期待

1. 設定の「スリープ」を開き、「ディスプレイを閉じたとき」の選択肢と (i) を見る。

   期待: 独立した子の行がなく、1つのポップアップに「Macをスリープ（標準）」「ディスプレイをオフ」「明るさを0」「オンのまま」の4つがある。(i) の通常の説明は「Capsaicinがオンの間は、「システムスリープ」以外なら、ディスプレイを閉じても、アップルメニューの「スリープ」などを選んでもスリープしません。OSの仕組み上、この2つは個別に設定できず、ヘルパーとシステム設定での許可が必要です。「明るさを0」では、閉じている間も画面は暗いだけでロックされません。「ディスプレイを自動でオフにしない」がオフなら、時間が来るとディスプレイがオフになり、ロックされることがあります。」である。

2. ヘルパーが「有効」なら、4つの選択肢を順に選ぶ。

   期待: 選んだ値が表示されたまま保たれる。

3. ヘルパーが使えない状態で、ヘルパーが要る設定（「Macをスリープ（標準）」以外）が保存されている場合だけ、表示と (i) の先頭を記録する。このファイルでは許可の変更やファイルの破損で状態を作らない。その状態がなければ、この操作は判定不能にする。

   期待: ポップアップは無効にならず、保存した選択肢を表示し、行のアイコンが注意の記号に替わる。項目名の下に、小さめの薄い文字で「ヘルパーが有効になっていません」が出る。(i) の先頭は状態に応じて次の文になる。

   | 「ヘルパー」の状態 | (i) の先頭 |
   | --- | --- |
   | 未インストール | ヘルパーが未インストールのため、この設定を適用できません。設定の「ヘルパー」でインストールしてください。 |
   | システム設定での許可待ち | ヘルパーが承認待ちのため、この設定を適用できません。システム設定の「一般 > ログイン項目と機能拡張」でCapsaicinの項目を許可してください。設定の「ヘルパー」から開けます。 |
   | このビルドでは使用不可 | このビルドではヘルパーを使えないため、この設定を適用できません。署名にTeam IDがあるビルドが必要です。 |

## 中止するとき

「Macをスリープ（標準）」以外を選んで設置の確認か許可の案内が出たら、「キャンセル」を選ぶ。保存値に対応する表示へ戻ることを確かめて止める。このビルドでは使えない旨のエラーが出た場合は「OK」で閉じ、保存値の表示へ戻ることを確かめる。システム設定で許可しない。

## 元に戻す

「ディスプレイを閉じたとき」を始める前に控えた値へ戻す。ヘルパーの状態は変えない。

## 記録

`"$B/result-lid-close-setting.txt"` に次を書く。

- ポップアップの表示、選択肢、(i) の内容、注意の記号と行の下の状態の文の有無
- ヘルパーの状態、元の設定値と戻した値
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
