# 「ディスプレイを閉じたとき」の表示と説明

設定の「スリープ」の「ディスプレイを閉じたとき」が1つのポップアップに4つの選択肢を持ち、ヘルパーが要る設定を適用できないときに注意の表示が出ることを確かめる。ディスプレイを実際に閉じる試験やヘルパーの設置は含めない。確かめる仕様は `SPEC-SET-002`、`SPEC-SET-005`、`SPEC-SET-006` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- MacBook を使う。
- ヘルパーの設置・修復の確認が出ても、この手順では承認しない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

設定の「ヘルパー」の「状態」（「インストール済み」「未インストール」「構成が不完全」のどれか）と、「ディスプレイを閉じたとき」の現在の値を `"$B/result-lid-close-setting.txt"` に控える。

## 操作と期待

1. 設定の「スリープ」を開き、「ディスプレイを閉じたとき」の選択肢と (i) を見る。

   期待: 独立した子の行がなく、1つのポップアップに「システムスリープ（標準）」「ディスプレイスリープ」「明るさを0」「オンのまま」の4つがある。(i) の説明から、スリープ防止中にディスプレイを閉じたときの動作を決めることと、「システムスリープ」以外ではヘルパーのインストールが必要なことが読める。

2. ヘルパーが「インストール済み」なら、4つの選択肢を順に選ぶ。

   期待: 選んだ値が表示されたまま保たれる。

3. ヘルパーが正しく設置されていない状態で、ヘルパーが要る設定（「システムスリープ（標準）」以外）が保存されている場合だけ、表示と (i) の先頭を記録する。その状態を安全に用意できなければ、この操作は判定不能にする。

   期待: ポップアップは無効にならず、保存した選択肢を表示し、行のアイコンが注意の記号に替わる。(i) の先頭に「ヘルパーが正しくインストールされていないため、この設定を適用できません。設定の「ヘルパー」で修復してください。」が出る。

## 中止するとき

「システムスリープ（標準）」以外を選んだときに設置・修復の確認が出たら、その場では承認せず取り消す。値が「システムスリープ（標準）」のままになることを確かめて止める。

## 元に戻す

「ディスプレイを閉じたとき」を始める前に控えた値へ戻す。ヘルパーの状態は変えない。

## 記録

`"$B/result-lid-close-setting.txt"` に次を書く。

- ポップアップの表示、選択肢、(i) の内容、注意の記号の有無
- ヘルパーの状態、元の設定値と戻した値
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
