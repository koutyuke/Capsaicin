# 英語・日本語の表示と時刻の表記

アプリの表示が言語の設定に従って英語か日本語になり、時刻が OS の地域と24時間表示の設定に従うことを確かめる。確かめる仕様は `SPEC-UI-011`、`SPEC-UI-012`、`SPEC-HLP-006`、`SPEC-SET-005` である。

最初の1回の準備は [`prepare.md`](prepare.md)、最後の片付けは [`cleanup.md`](cleanup.md) で行う。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- オーナーがシステム設定を操作する。
- 設置の確認を見るには、`prepare.md` で選んだ署名済みの Debug ビルドでヘルパーが未インストールであることが必要である。確認が開いたら必ず取り消す。ヘルパーの登録やシステム設定での許可には進まない。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
APP="$(cat "$B/app-path.txt")"
printf 'APP=%s\n' "$APP"
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
/usr/bin/open "$APP"
just status
```

アプリの設定の次の値を `"$B/result-localization.txt"` に控えてから変える。

ヘルパーが使えず、ヘルパーが要る値が保存されている場合は、元の値を選び直せなくなるため、この手順を始めない。

- 「スリープ」の「ディスプレイを閉じたとき」を「Macをスリープ（標準）」にする（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」をオフ）。「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をオフにする。
- 「フィードバック」の「スリープ防止中にCaps LockのLEDを点灯」をオフにする。
- 「フィードバック」の「切り替え時にHUDを表示」をオンにする。

## 操作と期待

1. システム設定の「一般」→「言語と地域」で地域の値を、「一般」→「日付と時刻」で「24時間表示」の値を `"$B/result-localization.txt"` に控える。「言語と地域」の「アプリケーション」に Capsaicin の言語の指定があればその値を、なければ指定がないことを控える。
2. アプリを終了する。

   ```sh
   just stop
   ```

   「アプリケーション」で Capsaicin の項目を編集し、言語を English にする。項目がなければ「＋」から `$APP` に記録されたパスの Debug アプリを選んで足す。「日付と時刻」で「24時間表示」をオフにし、アプリを起動する。macOS の項目名は実装にないため、検証時の画面で照合する。

   ```sh
   /usr/bin/open "$APP"
   ```

   期待: アプリが英語で表示される。

3. 英語・12時間制で次を見る。
   1. メニューとサブメニューを開き、設定の6セクションを項目名の下の説明文まで読む。
   2. 「Turn On with Time Limit」の「Enter Duration…」で1時間30分を入力し、「Turns off at …」の時刻を控えて「Turn On」で開始する。HUD とメニューの残り時間を見る。
   3. 「Turn Sleep Prevention Off」で解除し、「Set a Time…」で午後の時刻を指定して開始する。HUD とメニューの解除の時刻を見て、解除する。
   4. 「Helper」の「Status」が「Not installed」なら、「Sleep」で「The helper must be installed.」と「Helper Settings…」が表示されることを確かめる。
   5. 「Helper」の「Status」が「Not installed」で「Install…」が表示されているときだけ、「Install…」を選ぶ。シートの文言を読み、必ず「Cancel」を選ぶ。「Install」を押さない。前提を満たさない場合は、設置の確認だけ判定不能にする。

   期待: メニュー、入力パネル、HUD、設定画面、開けたアラートが英語で表示される。入力する時刻、確定したらオフになる時刻、メニューと HUD の解除の時刻が OS の地域に合った12時間制で、午前・午後を区別できる。期間は英語の時間と分の単位で表示される。アプリ名とコマンドの書式は変わらない。

4. アプリを終了する。

   ```sh
   just stop
   ```

   「日付と時刻」で「24時間表示」をオンにし、English のまま起動し直す。

   ```sh
   /usr/bin/open "$APP"
   ```

   英語・24時間制で次を見る。
   1. メニューとサブメニューを開き、設定の6セクションを項目名の下の説明文まで読む。
   2. 「Turn On with Time Limit」の「Enter Duration…」で1時間30分を入力し、「Turns off at …」の時刻を控えて「Turn On」で開始する。HUD とメニューの残り時間を見る。
   3. 「Turn Sleep Prevention Off」で解除し、「Set a Time…」で午後の時刻を指定して開始する。HUD とメニューの解除の時刻を見て、解除する。
   4. 「Helper」の「Status」が「Not installed」で「Install…」が表示されているときだけ、「Install…」を選ぶ。シートの文言を読み、必ず「Cancel」を選ぶ。「Install」を押さない。前提を満たさない場合は、設置の確認だけ判定不能にする。

   期待: 画面と期間は英語のまま、入力パネル、メニュー、HUD の時刻が OS の地域に合った24時間制になる。

5. アプリを終了し、「アプリケーション」の Capsaicin の言語を日本語にする。「24時間表示」はオンのまま起動し直す。

   ```sh
   just stop
   ```

   言語を日本語にしてから起動する。

   ```sh
   /usr/bin/open "$APP"
   ```

   メニューとサブメニューを開き、設定の6セクションを項目名の下の説明文まで読む。「時間・時刻を指定してオン」の「時間を入力…」で1時間30分を入力し、「…にオフ」の時刻を控えて「オンにする」で開始する。HUD とメニューの残り時間を見て、「スリープ防止をオフにする」で解除する。「時刻を指定…」で午後の時刻を指定して開始し、HUD とメニューの解除の時刻を見て解除する。

   「ヘルパー」の「状態」が「未インストール」なら、「スリープ」で「ディスプレイを閉じたとき」（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」）の項目名の下に、ヘルパーを有効にする必要があることを伝える文が表示されることを確かめる。「ヘルパー」に戻り、「インストール…」が表示されていれば選ぶ。シートの文言を読み、必ず「キャンセル」を選ぶ。「インストール」を押さない。前提を満たさない場合は、設置の確認だけ判定不能にする。

   期待: 画面と期間が日本語になり、時刻は OS の地域に合った24時間制になる。

## 中止するとき

Debug アプリを識別できない、開始前の設定が分からない、言語や時刻の設定を元に戻せない場合は止める。設置の確認は英語なら「Cancel」、日本語なら「キャンセル」で閉じる。入力パネルを Esc で閉じ、メニューで解除してアプリを終了する。

```sh
just stop
```

## 元に戻す

パネルを Esc で閉じ、メニューで解除してアプリを終了する。

```sh
just stop
```

「一般」→「言語と地域」→「アプリケーション」で、Capsaicin の言語を控えた値へ戻す。始める前に指定がなかった場合は、今回足した Capsaicin の項目だけを「−」で消す。「日付と時刻」の「24時間表示」を控えた値へ戻し、地域が控えた値のままであることを確かめる。アプリを起動し直し、試したアプリの設定を控えた値へ戻す。

```sh
/usr/bin/open "$APP"
```

## 記録

`"$B/result-localization.txt"` に次を書く。

- 英語・12時間制、英語・24時間制、日本語・24時間制のそれぞれの表示言語
- 入力パネル・メニュー・HUD の時刻と期間の単位、ヘルパーが要る場合の説明文、設置の確認の表示と取り消し
- 画面写真の絶対パス、言語と時刻の設定を戻したこと
- 成功／失敗／判定不能、未実施の操作と理由
