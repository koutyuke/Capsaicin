# メニューの並びと時間・時刻の入力パネル

メニューの項目の並び、時間と時刻の入力パネルの入力の扱い、残り時間の表示と自動解除、開始の項目の副題を確かめる。この手順はコマンドを使わず、目と画面の操作で確かめる。確かめる仕様は `SPEC-MENU-001`、`SPEC-MENU-002`、`SPEC-MENU-003`、`SPEC-MENU-004`、`SPEC-MENU-005`、`SPEC-UI-005` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。
- 内蔵バッテリーのある Mac では、電源アダプターをつなぐ。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

設定の次の値を `"$B/result-menu-and-panels.txt"` に控えてから変える。

- 「スリープ」の「ディスプレイを閉じたとき」を「Macをスリープ（標準）」にする（MacBook 以外の Mac では「Appleメニューからのスリープも防ぐ」をオフ）。「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をオフにする。
- 「フィードバック」の「スリープ防止中にCaps LockのLEDを点灯」をオフにする。

## 操作と期待

1. メニューを開き、スリープ防止がオフのときの並びを `SPEC-MENU-001` と比べる。

   期待: 上から、見出し「Capsaicin」、「スリープ防止をオンにする」、区切り、「時間指定なしでオン」、「時間・時刻を指定してオン」、区切り、「クイック設定」、区切り、「設定…」、「Capsaicinを終了」が並ぶ。トップレベルにチェックの付く項目がなく、左にチェック用の余白がない。

   「時間・時刻を指定してオン」を開き、`SPEC-MENU-002` と比べる。

   期待: 見出し「今から」、15分・30分・1時間・2時間・4時間・8時間、「時間を入力…」、区切り、「時刻を指定…」が並ぶ。チェックと「時間指定なしでオン」はない。パネルを開く項目は末尾に省略記号があり、さらにサブメニューを開く矢印がない。

   「クイック設定」の中は `SPEC-MENU-008` と比べる。

2. 「時間・時刻を指定してオン」の「時間を入力…」でパネル「時間を指定してオン」を開き、次を順に試す。
   1. 0時間0分、24時間1分、数字でない文字を入力する。

      期待: 別の値に直らず、「オンにする」で開始できない。

   2. 0時間58分を入力して分の `Stepper` を上げ、分の数値欄で ↓ を押す。

      期待: 上げると1時間3分になり、↓ で0時間58分に戻る。

   3. 23時間30分を入力して時間の `Stepper` を上げ、時間の数値欄で ↑ を押す。

      期待: 24時間0分で止まる。

   4. 0時間3分から分を下げる。

      期待: 0時間1分で止まる。

   5. Esc で閉じ、もう一度開いて1分を入力する。入力欄の下の「…にオフ」の時刻を控え、Return で開始する。

      期待: パネルが重ねて開かず、1分で開始する。

3. メニューを開き、状態の行を見る。1分後の自動解除を待つ。

   期待: 「（控えた時刻）まで（残り…）」が出て、残り時間が分単位で更新される。控えた時刻に自動で解除される。アイコンの見た目は状態で動かない。

4. スリープ防止がオフのときに「時間・時刻を指定してオン」の「時刻を指定…」でパネル「時刻を指定してオン」を開き、その日に過ぎた時刻を入力する。開始せず Esc で閉じる。

   期待: 時間のパネルの「…にオフ」と同じ位置に「翌日のこの時刻にオフ」が出る。

5. 設定の「タイマーで自動解除」をオンにして「継続時間」を3分にし、「スリープ防止をオンにする」で開始する。メニューを2分開いたままにする。解除後、「タイマーで自動解除」をオフに戻す。

   期待: 開いている間も残り時間が分単位で更新され、期限どおりに解除される。

6. 内蔵バッテリーのある Mac では、設定の「バッテリー残量が少ないときに自動解除」と「電源アダプタ接続中は自動解除しない」をオンにする。次の順で、スリープ防止がオフのときの「スリープ防止をオンにする」の副題を見る。各段階で、トップレベルに「時間指定なしでオン」があることも確かめる。内蔵バッテリーのない Mac では、この操作は判定不能として飛ばす。
   1. 「タイマーで自動解除」と「指定時刻に自動解除」をオフにする。

      期待: 副題が「オフにするまで」である。

   2. 「タイマーで自動解除」を1時間でオンにする。

      期待: 副題が「1時間後にオフ」の形である。

   3. 「タイマーで自動解除」をオフにし、「指定時刻に自動解除」をその日に過ぎた時刻でオンにする。

      期待: 副題が「明日（時刻）にオフ」の形である。

   4. 「指定時刻に自動解除」もオフにし、「時間指定なしでオン」で開始して状態の行を見る。

      期待: どの副題にもバッテリー残量の条件は含まれない。開始後は「手動でオフにするまで継続」の下に、「電源アダプタ接続中（残量低下でも継続）」か「バッテリー残量…%未満でオフ」の行がある。

## 中止するとき

入力を受け付けない、パネルが重ねて開く、期限どおりに解除されない場合は止める。パネルを Esc で閉じ、メニューの「スリープ防止をオフにする」で解除する。

## 元に戻す

パネルを Esc で閉じ、メニューの「スリープ防止をオフにする」で解除する。試した設定を控えた値へ戻し、電源アダプターの接続を開始前に戻す。

## 記録

`"$B/result-menu-and-panels.txt"` に次を書く。

- メニューとサブメニューの並び、パネルを開いた項目
- 入力した値と反応、控えた時刻と自動で解除された時刻、残り時間の表示、アイコンの見た目
- 開始の項目の副題と状態の行
- 戻した設定と電源の接続、成功／失敗／判定不能、未実施の操作と理由
