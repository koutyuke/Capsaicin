# 抑止を続けたまま時間を変更する

スリープ防止中に「オフにする時刻を変更」で解除の時刻を置き換えたり時間の条件をなくしたりしても、スリープ防止が途切れないことと、パネルの初期値・表記、状態が変わったときにパネルが閉じることを確かめる。確かめる仕様は `SPEC-BLK-003`、`SPEC-BLK-011`、`SPEC-MENU-002`、`SPEC-MENU-003`、`SPEC-HUD-001`、`SPEC-HUD-002` である。

この手順はこのファイルだけで完結する。最初の1回の準備（[`prepare.md`](prepare.md)）を除き、ほかの検証ファイルの手順は行わない。共通の決まりは [`README.md`](README.md) にある。

## 始める前に

- 準備（`prepare.md`）を終え、退避先 `B` の絶対パスを控えている。

リポジトリのルートで devShell に入る。

```sh
cd <リポジトリのルート>
nix develop
```

devShell の中で退避先を入れ、足場を確かめる。`OK` が出なければ、退避先かチェックアウトが違うので止める。試験する CLI のパスも入れる（操作4で使う）。

```sh
B='控えた退避先の絶対パスに置き換える'
test "$(cat "$B/repository-path.txt")" = "$PWD" && echo OK
CLI="$PWD/.build/xcode/Build/Products/Debug/Capsaicin.app/Contents/Helpers/capsaicin"
just status
```

アプリが動いていなければ起動し、メニューでスリープ防止がオフであることを確かめる。

```sh
just start
just status
```

設定の次の値を `"$B/result-change-time-while-active.txt"` に控えてから変える。

- 「スリープ」の「ディスプレイを閉じたとき」を「Macをスリープ（標準）」にする（MacBook 以外の Mac では「メニューからのスリープも防ぐ」をオフ）。「タイマーで自動解除」「指定時刻に自動解除」「バッテリー残量が少ないときに自動解除」をオフにする。
- 「フィードバック」の「スリープ防止中にCaps LockのLEDを点灯」をオフにする。
- 「フィードバック」の「切り替え時にHUDを表示」と、「操作」の「CLIからの操作を許可」をオンにする。

## 操作と期待

1. スリープ防止がオフのときに「時間・時刻を指定してオン」を開いて並びを記録し、30分を選んで開始する。アサーションを読む。

   ```sh
   /usr/bin/pmset -g assertions | /usr/bin/grep -i -A2 capsaicin
   ```

   1分以上待ってからメニューを開き、スリープ防止中の並びを `SPEC-MENU-001` と比べる。

   期待: 上から見出し「スリープ防止中」、状態の行、「スリープ防止をオフにする」、「オフにする時刻を変更」、区切り、「クイック設定」、区切り、「設定…」、「Capsaicinを終了」が並ぶ。トップレベルにチェックの付く項目と左のチェック用の余白がない。

   「オフにする時刻を変更」を開き、`SPEC-MENU-002` と比べる。

   期待: 見出し「今から」、プリセット、「時間を入力…」、区切り、「時刻を指定…」に続けて、スリープ防止中だけ区切りと「時間指定なし」がある。チェックはない。

   30分を選び直し、操作した時刻を控えて、もう一度アサーションを読む。

   ```sh
   /usr/bin/pmset -g assertions | /usr/bin/grep -i -A2 capsaicin
   ```

   期待: 選び直した時点から30分後が解除の時刻になり、アサーションは同じ ID のままである。スリープ防止は続き、開始と同じ形の HUD に新しい条件が出る。

2. 「オフにする時刻を変更」から「時間を入力…」と「時刻を指定…」のパネルを順に開き、初期値を `SPEC-MENU-003` と比べる。時間のパネルで2分に変え、「…にオフ」の時刻を控えて「変更」で確定する。

   期待: パネルのタイトルが「オフにする時刻を変更」、確定のボタンが「変更」で、変更であることが分かる。新しい時刻に置き換わり、スリープ防止は続き、HUD に新しい条件が出る。

3. 自動解除を待たずに、「オフにする時刻を変更」の「時間指定なし」を選ぶ。操作2で控えた時刻を過ぎるまで待つ。時間と時刻のパネルを開き、初期値がスリープ防止オフのときと同じ規則かを確かめて「キャンセル」で閉じる。

   期待: 解除の時刻がなくなり、HUD は時間では自動解除しないことを示す。操作2の期限を過ぎてもスリープ防止が続く。時間を選ぶ操作で設定の「タイマーで自動解除」と「指定時刻に自動解除」の値は変わらない。

4. 時刻のパネルを開いたまま、CLI で解除する。

   ```sh
   "$CLI" off
   printf 'exit=%s\n' "$?"
   ```

   期待: パネルが閉じる。

   スリープ防止がオフのときに時間のパネルを開いたまま、CLI で開始する。

   ```sh
   "$CLI" on --for 1m
   printf 'exit=%s\n' "$?"
   ```

   期待: パネルが閉じる。

   メニューの「スリープ防止をオフにする」で解除し、設定の「タイマーで自動解除」をオンにしてから、トップレベルの「時間指定なしでオン」で開始する。メニューの状態の行を見る。

   期待: 「手動でオフにするまで継続」と出て、設定の「タイマーで自動解除」を使わない。

## 中止するとき

置き換えでスリープ防止がオフになる、期限や初期値が仕様と違う、パネルが閉じず古い状態のまま確定できる場合は止める。パネルを Esc で閉じ、メニューの「スリープ防止をオフにする」で解除する。

## 元に戻す

パネルを Esc で閉じ、メニューの「スリープ防止をオフにする」で解除する。試した設定を控えた値へ戻す。

## 記録

`"$B/result-change-time-while-active.txt"` に次を書く。

- 選び直した時刻と解除の時刻、アサーションの ID の前後
- パネルの初期値・タイトル・ボタン・「…にオフ」の表示、HUD の内容
- 時間の条件をなくした後の状態、設定の保存値の前後、状態が変わったときにパネルが閉じたこと
- 成功／失敗／判定不能、未実施の操作と理由、気づいたこと
