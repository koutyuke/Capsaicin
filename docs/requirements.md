# Capsaicin 要件定義書

Capsaicin は、Mac のスリープを止めている間だけ Caps Lock の LED を点灯させる、メニューバー常駐アプリである。本書は v1 の要件と設定項目の既定値、将来に回すもの、実装前に試作で確かめることを定める（2026-11-06 時点）。実装は本書に従い、試作で前提が崩れた場合は本書を更新してから進める。

```text
[停止中]
   │ on: メニューバー / ホットキー / CLI
   ▼
[抑止中]  「止めるスリープ」でオンにした種類のスリープを止める
   │      Caps Lock の LED を点灯する
   │
   │ off / タイマー終了 / 指定時刻 / 電池がしきい値未満 / アプリ終了・クラッシュ
   ▼
[停止中]  LED を通常の動作に戻し、スリープ設定を元に戻す
```

## 1. 目標と非目標

### 目標

- 自動スリープ、画面の自動消灯、手動スリープ、蓋を閉じたときのスリープを、種類ごとに止められる。
- 抑止中であることを、画面を見ずにキーボードの LED で分かる。
- Caps Lock の入力状態（大文字入力）は変えず、LED だけを制御する。Caps Lock キーを別のキーに割り当てている人も使える。
- すべての設定項目を、利用者が個別に切り替えられる。モードのように複数の設定をまとめて切り替える仕組みは設けない。
- root 権限が必要な処理は、機能を最小限に絞った別のヘルパーに切り出す。

### 非目標（v1 では扱わない）

- Mac App Store での公開、有料販売、ライセンス認証、公証、自動アップデート
- 英語の UI、Intel Mac、macOS 25 以前
- Caps Lock キーによる抑止の切り替え
- 温度による自動解除
- 将来に回す機能（7 章）

既存の類似アプリ Capsomnia（MIT ライセンス）とは、コード・名前・アイコンを共有しない。

## 2. 抑止の開始と解除

### 2.1 操作

- メニューバー: アイコンのメニューから、抑止の開始・解除と、今回の解除条件（タイマーまたは指定時刻）を選ぶ。
- ホットキー: 抑止の開始・解除を切り替える。解除条件は設定の既定値を使う。
- CLI: `capsaicin on [--for <時間> | --until <時刻>]`、`capsaicin off`、`capsaicin status` を提供する。オプションを省略したときは、設定の既定値を使う。アプリが起動していなければ、CLI がアプリを起動する。

### 2.2 解除条件

次のどれか 1 つを満たした時点で、抑止をすべて解除する。

- タイマーが終了した。
- 指定時刻になった。指定時刻は、次に来るその時刻を指す（例: 23:00 に開始して 4:00 を指定したら、翌日の 4:00）。
- バッテリー残量がしきい値を下回った。
- 利用者が解除した。アプリが終了またはクラッシュした（5 章）。

タイマーと指定時刻の既定値は設定で決める。メニューと CLI では、開始するときに別の値で上書きできる。

### 2.3 切り替えたときの画面表示（HUD）

抑止の開始・解除を、画面の表示でも知らせる。macOS の明るさ表示や Revisual と同じく、画面中央下に小さなカプセル形のパネルを約 2 秒表示して消す。パネルはフォーカスを奪わず、クリックも受け付けない。

- 表示する場面: ホットキーまたはメニューで切り替えたとき、自動で解除したとき。CLI で切り替えたときは表示しない。
- 表示する内容: アイコン、状態、解除条件。例: 「スリープ抑止 オン・4:00 まで」「スリープ抑止 オフ・バッテリー 20%」。
- 表示する画面: マウスカーソルがある画面。

Apple の明るさ表示を呼び出す公開 API はないため、パネルは自前で描く。

## 3. 設定画面

### 3.1 画面の構成

macOS のシステム設定と同じ構成にする（参考: Revisual の設定画面）。

- 左のサイドバーに、アイコンとセクション名を並べる。よく使う 5 つのセクションを上に置き、「ヘルパー」と「このアプリについて」は下に離して置く。
- 右側には、選んだセクションの項目を角丸のグループにまとめて並べる。各行は、左に項目名、右にスイッチや値を置く。
- 項目名だけで内容が伝わるようにし、説明文は付けない。名前だけでは結果が分かりにくい項目（例: 蓋閉じスリープ）には、項目名の横に (i) アイコンを置き、ツールチップで説明する。

| 位置 | セクション         | アイコン（SF Symbols） |
| ---- | ------------------ | ---------------------- |
| 上   | 一般               | `gearshape`            |
| 上   | 止めるスリープ     | `moon.zzz`             |
| 上   | 解除の条件         | `timer`                |
| 上   | LED                | `capslock`             |
| 上   | 操作               | `keyboard`             |
| 下   | ヘルパー           | `lock.shield`          |
| 下   | このアプリについて | `info.circle`          |

「このアプリについて」には、バージョンとビルド番号を表示する。

### 3.2 設定項目と既定値

すべての項目は個別に切り替えられる。

| セクション     | 項目                                      | 既定値                                                                  |
| -------------- | ----------------------------------------- | ----------------------------------------------------------------------- |
| 一般           | ログイン時に起動する                      | オン                                                                    |
|                | 再起動後に抑止を再開する                  | 再開しない（ほかに「アプリの再起動時だけ」「アプリと Mac の再起動時」） |
|                | 切り替えたときに画面に表示する（HUD）     | オン                                                                    |
| 止めるスリープ | 自動スリープ                              | オン                                                                    |
|                | 画面の自動消灯                            | オフ                                                                    |
|                | 手動スリープ                              | オフ                                                                    |
|                | 蓋閉じスリープ                            | オフ                                                                    |
|                | 蓋を閉じたら画面を消す                    | オン                                                                    |
| 解除の条件     | タイマー                                  | なし（時間を指定）                                                      |
|                | 指定時刻                                  | なし（時刻を指定）                                                      |
|                | バッテリー残量                            | オン、しきい値 20%（0〜100% で指定）                                    |
| LED            | Caps Lock の LED で知らせる               | オン                                                                    |
|                | 抑止中に Caps Lock をオンにしたときの表示 | 抑止の表示を優先して点灯（ほかに「Caps Lock を優先」）                  |
| 操作           | ホットキー                                | 割り当てなし                                                            |
|                | CLI                                       | 使える                                                                  |
| ヘルパー       | インストールの状態、削除                  | 未インストール                                                          |

手動スリープか蓋閉じスリープを初めてオンにしたときに、ヘルパーを設置する（4.2）。Karabiner-Elements の起動を検出したら、LED が上書きされる場合があることを、メニューと「LED」セクションに表示する。

## 4. 実現方式

### 4.1 スリープの抑止

| 止めるスリープ                             | 方式                                               | root |
| ------------------------------------------ | -------------------------------------------------- | ---- |
| 自動スリープ                               | 電源管理アサーション `PreventUserIdleSystemSleep`  | 不要 |
| 画面の自動消灯                             | 電源管理アサーション `PreventUserIdleDisplaySleep` | 不要 |
| 手動スリープと蓋閉じスリープの両方         | ヘルパー経由で `pmset -a disablesleep 1`           | 必要 |
| 手動スリープだけ、または蓋閉じスリープだけ | 未定（6 章で試作して決める）                       | 未定 |

`disablesleep` はシステムのスリープ全体を止めるため、片方だけを止めることはできない。片方だけを止める組み合わせが試作で実現できなかった場合は、設定画面でその組み合わせを選べないようにする。

蓋を閉じたら画面を消す処理は、蓋の開閉状態（IOKit の `AppleClamshellState`）を監視し、閉じたら `pmset displaysleepnow` を実行する。root 権限は不要という見込みである（6 章で確かめる）。

### 4.2 root ヘルパー

Capsomnia と同じく、アプリ本体は一般ユーザーの権限で動かし、root 権限が必要な処理だけを小さなヘルパーに任せる。

- ヘルパー: root が所有する実行ファイルを `/Library/PrivilegedHelperTools/` に置く。受け付けるのは `on`（`disablesleep 1`）と `off`（`disablesleep 0`）の 2 つのサブコマンドだけで、任意のコマンドや引数は実行しない。
- sudoers のルール: `/etc/sudoers.d/` に置き、インストールしたユーザーに、ヘルパーの `on` と `off` だけをパスワードなしで許可する。設置前に `visudo -c` で書式を検証する。書式を誤ると sudo 全体が使えなくなるためである。
- 起動時に設定を戻す LaunchDaemon: 起動時にヘルパーの `off` を実行する。`disablesleep` は再起動後も残るため、アプリが動いていない状態で起動してもスリープできない状態を残さないようにする。

設置には、管理者認証が 1 回必要である。3 つとも、設定の「ヘルパー」セクションから削除できる。この方式はコード署名に依存しないため、将来ほかの人に配った場合でも動く。

### 4.3 Caps Lock の LED

- 内蔵・外付けとも、非公開のプロパティ `HIDCapsLockLED` で制御する。抑止中は `"On"` を書き込み、解除したら `"Auto"`（Caps Lock の状態に連動する通常の動作）に戻す。書き込みは Passive 型の `IOHIDEventSystemClient` から行う。入力監視の権限は要らない。
- LED は抑止中は常に点灯させる。止めるスリープの種類による点灯の違いや点滅は設けない。
- このプロパティは内蔵キーボードのほか、外付けの機器（このマシンでは「2.4G Wireless Receiver」など）にもあることを `ioreg` で確認した。外付けキーボードで LED が実際に光るかは未確認である（6 章）。

## 5. 終了時とクラッシュ時の復旧

- 終了時: 電源管理アサーションを解放し、ヘルパーの `off` を実行し、LED を `"Auto"` に戻す。
- クラッシュ時: launchd の LaunchAgent（`KeepAlive` の `Crashed`）でアプリを再起動する。起動したアプリは、まずスリープ設定と LED を元に戻す。ログイン時の自動起動も、この LaunchAgent で行う。
- 抑止を再開するかは、設定の「再起動後に抑止を再開する」に従う。

## 7. 将来に回す機能

- プリセット: 止めるスリープの種類や解除条件の組み合わせを名前を付けて保存し、メニューから呼び出す。
- 指定したアプリが終了したら抑止を解除する。
- 電源アダプターに連動する設定（例: 電源アダプターにつながっている間はバッテリー残量による解除をしない）。
- 抑止中にメニューバーのアイコンを変える。

## 8. 非機能要件

- 対応環境: macOS 26 以降、Apple Silicon のみ。
- 表示言語: 日本語のみ。文字列は String Catalog で管理し、あとから言語を追加できるようにする。
- 署名と配布: Apple Developer Program には加入しない。v1 は自分の Mac でソースからビルドして使う。将来ほかの人に無料で配る場合に備えて、コード署名に依存しない方式を選ぶ。
- 将来の配布で生じる制約: 公証していないアプリは、利用者が「システム設定 > プライバシーとセキュリティ」の「このまま開く」で開く必要がある。Homebrew の公式 Cask には掲載できず、配る場合は GitHub Releases か自前の tap を使う。

## 9. 却下した方式

- 「標準」「完全」などのモード: 各設定項目との関係が分かりにくくなるため。
- `SMAppService.daemon` で root ヘルパーを登録する: 無料署名で動く確証がなく、ad-hoc 署名では不安定だと Apple の DTS が説明しているため。
- 従来型の LaunchDaemon ヘルパーと XPC で通信する: ad-hoc 署名では通信相手を安定して検証できず、書くコードも最も多いため。
- sudoers で `pmset` を直接許可する: root で実行する処理を Capsaicin 専用のヘルパー 1 か所にまとめ、sudoers のルールと起動時の LaunchDaemon が同じ入口を使うようにするため。
- LED を `IOHIDDeviceSetValue` で制御する: Karabiner-Elements がキーボードを独占していると `kIOReturnExclusiveAccess` で失敗し、外付けキーボードには入力監視の権限も必要になるため。
- Caps Lock キーで抑止を切り替える: Caps Lock を別のキーに割り当てている人が使えず、入力監視の権限も必要になるため。
