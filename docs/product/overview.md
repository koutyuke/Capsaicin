# Capsaicin の概要

Capsaicin は、Mac のスリープを止めている間だけ Caps Lock の LED を点灯させる、メニューバー常駐アプリである。

## 目的

長時間の処理や放置中の作業のためにスリープを止めたいが、止めたままにしていることを忘れたくない。Capsaicin は、止めるスリープを種類ごとに選べるようにし、止めている間はキーボードの LED で知らせる。画面を見なくても、止めているかどうかが分かる。

## 利用者

- v1 の利用者は作者自身である。将来ほかの人に無料で配る可能性があり、配布物の署名と公証は `DEC-SYS-021` にある。ソースは MIT ライセンスで公開する（`DEC-SYS-009`）。
- Caps Lock キーを別のキーに割り当てている人も対象にする（`DEC-KEY-001`）。

## 目標

- 必要な種類のスリープだけを止め、処理や作業を中断させない（`REQ-BLK-001`〜`REQ-BLK-004`）。
- 止めたまま忘れないようにする。画面を見ずに分かる合図（`REQ-LED-001`）と、自動で元に戻る仕組み（`REQ-BLK-007`〜`REQ-BLK-009`）を持つ。
- 抑止の合図のために、文字入力を妨げない（`REQ-LED-003`）。
- 設定の結果を利用者が予測できるようにする（`DEC-SET-001`、`REQ-SET-005`）。
- root 権限で動く部分を小さく保つ（`REQ-HLP-002`、`DEC-HLP-001`）。
- 安定版をアプリから確認し、更新できるようにする（`REQ-SYS-008`）。

## 非目標

v1 では次のものを扱わない。

- Mac App Store での公開、有料販売、ライセンス認証
- Intel Mac と macOS 25 以前（`DEC-SYS-003`）
- Caps Lock キーによる抑止の切り替え（`DEC-KEY-001`）
- 手動スリープとディスプレイを閉じたときのスリープの片方だけを止めること（`DEC-BLK-006`）
- 温度による自動解除
- 将来に回す機能（`PLAN-BLK-001`、`PLAN-BLK-002`、`PLAN-BLK-003`）

既存の類似アプリ Capsomnia との関係は `REQ-SYS-007` にある。

## 状態の流れ

Capsaicin は「停止中」と「抑止中」を行き来する。状態と要求の遷移は `SPEC-BLK-011`、抑止中に止める範囲は `SPEC-BLK-001`、解除とその後の振る舞いは `SPEC-BLK-007` にある。

アプリが後片付けをできずに終わったときと、開き直したときの扱いは `SPEC-LCY-003` と `SPEC-LCY-006`、同じアプリを複数開いたときの扱いは `SPEC-LCY-009` にある。
