# Q-UI-002 メニュー、HUD、CLI で使う機能名「スリープ防止」を何に替えるか

## 問い

メニュー（「スリープ防止をオンにする」「スリープ防止中」）、HUD（「スリープ防止 オン」）、CLI（「スリープ防止: オン」）、設定の一部の項目名が使う機能名「スリープ防止」を残すか、替えるなら何にするか。`DEC-UI-011` で、アプリ自身の動作を「防止」と書かないことにした。

## 選択肢と帰結

- 「スリープ防止」を残す。変更はないが、`DEC-UI-011` の方針と食い違う。
- 切り替える対象を「Capsaicin」にし、「Capsaicinをオンにする」「Capsaicin オン」と書く。状態は文で「スリープを止めています」と書く。単機能のアプリなので別の名前を作らずに済むが、アプリ名が日本語の文に何度も出る。
- 機能名を「スリープを止める」にする。動詞句で評価を含まないが、オン・オフと組み合わせると「スリープを止める：オフ」のように止めることを止める読みになる。「止める」は「やめる」とも読める。

## 決めるのに必要な情報

- メニュー、HUD、VoiceOver の読み上げで、それぞれの案の文言を並べたときの読みやすさ。
- 設定画面の (i) が使う「Capsaicinがオンの間は」（`DEC-UI-011`）との一貫性。
