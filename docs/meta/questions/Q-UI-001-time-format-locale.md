# Q-UI-001 表示する時刻を 24 時間表記に固定するか、OS の地域の設定に従うか

## 問い

メニュー、HUD、入力パネル、`capsaicin status` に表示する時刻（例: 解除される時刻）を、24 時間表記に固定するか、OS の地域と時刻の設定（12 時間表記など）に従うか。CLI の入力の書式（`SPEC-CLI-001`）は 24 時間表記で決まっている。

## 選択肢と帰結

- 24 時間表記に固定する。CLI の入力の書式と表示が一致する。OS で 12 時間表記を選んでいる利用者には、ほかのアプリと表記が揃わない。
- OS の設定に従う。ほかのアプリと揃う。CLI の入力（24 時間表記）と、表示の表記が食い違うことがある。
- 画面は OS の設定に従い、CLI の出力だけ 24 時間表記に固定する。それぞれの場所では一貫するが、規則が2つになる。

## 決めるのに必要な情報

- オーナーとコピーライターの意向。
