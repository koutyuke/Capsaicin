# Q-BLK-001 閉じたときの画面に「明るさを 0 にする」を加えるか

## 問い

「閉じたときの画面」（`DEC-BLK-006`）に、「つけたまま」「消灯」に加えて、内蔵ディスプレイの明るさを 0 にし、蓋を開けたら元に戻す選択肢を加えるか。

## 選択肢と帰結

- 加える。画面をスリープさせないので、ロックがかからず、蓋を閉じたまま画面収録や Computer Use を続けられる。非公開の DisplayServices に頼ることになり、macOS の更新で使えなくなりうる。蓋を開けたときと、閉じたまま落ちた後の起動時に明るさを元に戻す処理が要る。閉じた蓋の中でパネルが動き続けるので、発熱と電力は「消灯」より不利である。「画面の自動消灯とスクリーンセーバー」をオフにしていると、時間が来て画面が消えるので、その関係も決める必要がある。
- 加えない。非公開の依存と復旧の処理が増えない。蓋を閉じたまま画面を使い続けたい利用者は「つけたまま」を選ぶ。

## 決めるのに必要な情報

- 蓋を閉じたまま画面収録や Computer Use を使う場面が実際にあるか。
- 蓋を閉じた状態で DisplayServices による明るさの変更が効き、蓋を開けたときに元の明るさへ戻せるか。
- 明るさ 0 のとき、閉じた蓋の中でバックライトが消えるか。
