# Q-BLK-001 ディスプレイを閉じたときの動作に「明るさを0」を加えるか

## 問い

「ディスプレイを閉じたとき」のポップアップ（`DEC-SET-005`）に、「スリープ（標準）」「ディスプレイをオフ」「オンのまま」に加えて、内蔵ディスプレイの明るさを 0 にし、ディスプレイを開けたら元に戻す「明るさを0」を加えるか。

## 選択肢と帰結

- 加える。画面をスリープさせないので、ロックがかからず、蓋を閉じたまま画面収録や Computer Use を続けられる。非公開の DisplayServices に頼ることになり、macOS の更新で使えなくなりうる。蓋を開けたときと、閉じたまま落ちた後の起動時に明るさを元に戻す処理が要る。閉じた蓋の中でパネルが動き続けるので、発熱と電力は「ディスプレイをオフ」より不利である。「ディスプレイを自動でオフにしない」をオフにしていると、時間が来て画面が消えるので、その関係も決める必要がある。
- 加えない。非公開の依存と復旧の処理が増えない。蓋を閉じたまま画面を使い続けたい利用者は「オンのまま」を選ぶ。

## 決めるのに必要な情報

- 蓋を閉じたまま画面収録や Computer Use を使う場面が実際にあるか。
- 蓋を閉じた状態で DisplayServices による明るさの変更が効き、蓋を開けたときに元の明るさへ戻せるか。
- 明るさ 0 のとき、閉じた蓋の中でバックライトが消えるか。
