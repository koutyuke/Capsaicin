# Q-MENU-001 ステータスアイコンを何の意匠にするか

## 問い

メニューバーのステータスアイコンの正式な意匠を、何をもとに作るか。決まるまでは SF Symbols の `capslock` で代用する（`SPEC-MENU-005`）。

## 選択肢と帰結

- LED（Caps Lock）の意匠にする。HUD とサイドバーで使う `capslock` と `capslock.fill` の対比（`SPEC-UI-004`）と同じ意味のまま使え、ほかの画面のシンボルを揃え直さずに済む。抑止中にアイコンを変える計画（`PLAN-MENU-001`）も、輪郭と塗りつぶしの対比で表せる。
- Capsaicin（唐辛子）の意匠にする。アプリ名と結びつき、ほかのメニューバーの項目と見分けやすい。HUD とサイドバーのシンボルを揃え直すか、別の比喩が併存することになる。独自のシンボルを作る手間がかかる（`SPEC-UI-010`）。

## 決めるのに必要な情報

- オーナーが作るアプリアイコンの意匠。
