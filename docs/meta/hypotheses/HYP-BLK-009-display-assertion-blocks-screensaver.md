# HYP-BLK-009 PreventUserIdleDisplaySleep のアサーションはスクリーンセーバーの自動起動も止める

## 主張

`PreventUserIdleDisplaySleep` のアサーションを保持している間は、「使用していない場合はスクリーンセーバを開始」の時間が過ぎても、スクリーンセーバーが自動で起動しない。

## 外れたときに起きること

「画面の自動消灯とスクリーンセーバー」をオンにしても、スクリーンセーバーは起動し、ロックの設定によっては画面がロックされる。`DEC-BLK-006` の覆す条件により、項目名から「スクリーンセーバー」を外し、`REQ-BLK-002`、`SPEC-BLK-001`、`SPEC-SET-002` を直す。

## 確かめ方

永続的なシステム変更は伴わない。オーナーが実機で行う。

1. 「システム設定 > ロック画面」で、スクリーンセーバーを開始するまでの時間を最短にし、ディスプレイをオフにするまでの時間をそれより長くする。元の値を控えておく。
2. 「画面の自動消灯とスクリーンセーバー」をオンにして抑止を開始し、スクリーンセーバーの時間より長く操作せずに待つ。
3. 成功: スクリーンセーバーが起動しない。失敗: 起動する。
4. 抑止を解除して同じだけ待ち、スクリーンセーバーが起動することを確かめる（設定が効いていることの対照）。
5. 「システム設定 > ロック画面」を控えた値に戻す。

## 結果

未確認。
