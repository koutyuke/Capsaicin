# HYP-BLK-008 一般ユーザーの権限で蓋の開閉の変化を検知できる

## 主張

一般ユーザーの権限で動くアプリが、IOKit の `AppleClamshellState` の変化を、蓋を閉じてから数秒以内に検知できる。蓋閉じスリープを止めている状態でも検知できる。

## 外れたときに起きること

蓋を閉じたら画面を消す処理を、アプリだけでは実現できない。`DEC-BLK-002` の方式を見直し、`SPEC-BLK-002` が変わる。

## 確かめ方

1. 環境: 対応環境の MacBook。値を一般ユーザーの権限で読めることは `EVID-BLK-003` で確かめてある。ここでは変化の検知を確かめる。
2. 一般ユーザーの権限で動く試作プログラムで、IOKit の通知を使って `AppleClamshellState` の変化を記録する。
3. 蓋閉じスリープを止めた状態（`HYP-BLK-006` の手順）で、蓋を閉じて開ける。
4. 成功: 閉じたときと開けたときの変化が、それぞれ数秒以内に記録される。失敗: 記録されない、または権限のエラーになる。

蓋閉じスリープを止めるために `disablesleep` を使う場合は、永続的なシステム変更を伴う。始める前に `pmset -g` の `SleepDisabled` の値を記録し、終わったら `sudo pmset -a disablesleep <記録した値>` で元に戻す。
