# HYP-UI-003 NSMenu を開いている間も、common モードのタイマーで項目の文字を更新できる

## 主張

`NSMenu` を開いている間（イベント追跡のランループ）も、`RunLoop.Mode.common` に登録したタイマーは動き、`NSMenuItem` のタイトルと副題を変えると、開いたままのメニューに反映される。

## 外れたときに起きること

メニューを開いている間に残り時間が更新されない。`DEC-UI-001` の理由が崩れ、`SPEC-MENU-004` の表示の方法を見直す。

## 確かめ方

1. 環境: 対応環境の Mac。
2. 1 秒ごとに項目の副題を変える試作のメニューを開いたままにする。
3. 成功: 開いたまま副題が変わる。失敗: メニューを閉じて開き直すまで変わらない。

永続的なシステム変更は伴わない。

## 結果

未確認。
