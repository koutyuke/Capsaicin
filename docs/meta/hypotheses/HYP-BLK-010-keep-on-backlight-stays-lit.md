# HYP-BLK-010 「オンのまま」で蓋を閉じると、内蔵ディスプレイのバックライトは点いたままである

## 主張

抑止中に「ディスプレイを閉じたとき」を「オンのまま」にして蓋を閉じると、内蔵ディスプレイはスリープせず（`EVID-BLK-008`）、バックライトも輝度の設定どおりに光り続ける。macOS は、蓋が閉じたことを理由にバックライトを消さない。

## 外れたときに起きること

蓋を閉じるだけで内蔵ディスプレイが暗くなるので、`DEC-BLK-007` の「明るさを0」は要らない。`DEC-BLK-002` の背景（閉じた蓋の中で画面が点いたままになりうる）を直す。

## 確かめ方

`e9e7e3d:docs/manual/lid-close-dimming-verification.md` の C2 で確かめる。レジストリの値は蓋の開閉で変わらないので、判定に使わない（`EVID-BLK-008`）。

1. 環境: 対応環境の MacBook。外部ディスプレイなし、電池駆動。Capsaicin で抑止し、「ディスプレイを閉じたとき」を「オンのまま」、「ディスプレイを自動でオフにしない」をオンにする。
2. 輝度を最大にしてから蓋を閉じ、暗い部屋で蓋の隙間から光が漏れるかを見る。同じ負荷のまま、閉じている間の電池の電流を記録する。
3. 蓋を閉じたまま、補助で輝度を最大、0、最大の順に切り替え、それぞれの間の光漏れを見る。1回の閉じ方の中で比べるので、キーボードのバックライトなど、ほかの光の条件がそろう。
4. 成功: 最大の間だけ光が漏れ、0 の間は漏れない。失敗: 最大の間も光が漏れない。電流の比較は C5 で行う。

永続的なシステム変更は伴わない。輝度は試験の後に元の値に戻す。

## 結果

支持された。最大輝度で閉じると隙間から光が漏れ、閉じても内蔵ディスプレイはスリープしなかった（`EVID-BLK-009`）。1回閉じたまま輝度を最大、0、最大と切り替えると、光も見えた、消えた、また見えたと合わせて変わった（`EVID-BLK-013`）。光源は内蔵ディスプレイのバックライトである。
