# HYP-DOMAIN_CODE-001 仮説の名称

## 主張

確かめれば白黒がつく形で、仮定している事実を書く。

## 外れたときに起きること

`affects` が指す要件・仕様・判断がどう変わるかを書く。

## 確かめ方

手順、環境、成功と失敗の判定基準を書く。永続的なシステム変更を伴う場合は、その旨と元に戻す手順も書く。

## 結果

確かめた後に、結論と根拠（`EVID-*`）を書く。確かめる前は「未確認」と書く。
