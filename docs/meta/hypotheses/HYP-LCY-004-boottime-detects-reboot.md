# HYP-LCY-004 kern.boottime と記録の最終更新の時刻を比べて、Mac の再起動後の起動を判定できる

## 主張

一般ユーザーの権限で `sysctl` の `kern.boottime` を読むと、Mac が起動した時刻を壁時計で得られる。同じ起動の間はこの値が変わらず、アプリが記録した最終更新の時刻は、その起動の間は必ずこの値より後になる。そのため、`kern.boottime` が記録の最終更新の時刻より後なら、記録した後に Mac が再起動している。

## 外れたときに起きること

採用中の要件・仕様への影響はない。`DEC-LCY-010` の構成では、起動の理由を判定せず、`disablesleep` の所有も保存しないので、この比較を使わない。

## 確かめ方

1. 環境: 対応環境の Mac。
2. `sysctl kern.boottime` を読み、`date` と比べる。時刻の比較を記録する試作で最終更新の時刻を残す。
3. Mac を再起動して、もう一度 `kern.boottime` を読み、手順 2 の記録の時刻と比べる。スリープと復帰、時刻の自動設定による小さな補正の後にも、同じ起動の間で値が変わらないかを確かめる。時計を手で戻したときに、再起動後の判定がどうなるかも記録する。
4. 成功: 再起動後だけ `kern.boottime` が記録の時刻より後になり、同じ起動の間は値が変わらない。失敗: 同じ起動の間に値が変わる、または再起動後でも記録の時刻より前になる。

Mac の再起動と時計の変更を伴う。時計を変更する確認は、元の設定に戻す手順を添えて PM に渡し、承認を得た実機で行う。
