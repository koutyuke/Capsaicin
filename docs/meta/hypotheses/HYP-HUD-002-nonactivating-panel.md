# HYP-HUD-002 非アクティブ化パネルはフォーカスを奪わず、クリックを下のウインドウに通す

## 主張

`.nonactivatingPanel` と `.borderless` の `NSPanel` に `ignoresMouseEvents = true` を設定し、`.statusBar` のレベルで表示すると、前面のアプリのキー入力のフォーカスを奪わず、クリックは下のウインドウに届き、フルスクリーンのアプリの上にも表示される。

## 外れたときに起きること

HUD が入力を妨げる。`REQ-HUD-002` を満たす別のウインドウの作り方が要り、`SPEC-HUD-003` が変わる。

## 確かめ方

1. 環境: 対応環境の Mac。
2. テキストエディタで入力しながら、試作のパネルを表示する。パネルの上をクリックする。フルスクリーンのアプリの上でも表示する。
3. 成功: 入力が途切れず、クリックが下のウインドウに届き、フルスクリーンでも表示される。失敗: どれかが満たされない。

永続的なシステム変更は伴わない。

## 結果

未確認。
