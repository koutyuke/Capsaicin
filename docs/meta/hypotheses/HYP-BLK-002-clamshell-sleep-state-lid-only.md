# HYP-BLK-002 kPMSetClamshellSleepState で root なしに蓋閉じスリープだけを止められる

## 主張

一般ユーザーの権限で `kPMSetClamshellSleepState` を使って蓋閉じスリープを無効にすると、蓋を閉じても Mac はスリープせず、Apple メニューからのスリープはできる。この状態は、一度スリープして復帰した後も保たれる。また、設定したプロセスが終了しても、この状態は残る（`SPEC-LCY-006` は、残るものとして起動時に戻す）。

## 外れたときに起きること

蓋閉じスリープだけを止める方式がなくなる。`DEC-BLK-004` により、蓋閉じスリープもヘルパー（`disablesleep`）で止め、設定画面では手動スリープと1行にまとめる（`SPEC-SET-005` の変種 B）。`SPEC-BLK-001` の含意が広がる。

## 確かめ方

1. 環境: 対応環境の MacBook。電源アダプターを接続し、外部ディスプレイを外す。
2. 一般ユーザーの権限で動く試作プログラムから `kPMSetClamshellSleepState` で蓋閉じスリープを無効にする（`EVID-BLK-002` のとおり、この値は SDK のヘッダーに定数があるだけで、使い方の文書はない。カーネルの側に権限の確認がないことは `EVID-BLK-004`、立てたビットで蓋閉じスリープが止まる仕組みは `EVID-BLK-006` で確かめてある）。
3. 蓋を閉じ、1 分後に別の端末から ping が通るかを確かめる。蓋を開ける。
4. Apple メニューから「スリープ」を選び、スリープすることを確かめる。復帰させる。
5. もう一度蓋を閉じ、1 分後に ping が通るかを確かめる。
6. 成功: 手順 3 と 5 で ping が通り、手順 4 でスリープする。失敗: 呼び出しが権限のエラーになる、手順 3 か 5 でスリープする、または手順 4 でスリープしない。

続けて、蓋閉じスリープを無効にしたまま試作プログラムを `kill -9` で終了し、蓋を閉じる。スリープしなければ、プロセスの終了後も残るという主張が成り立つ。スリープすれば、プロセスの終了で戻る（このとき `SPEC-LCY-006` の起動時に戻す処理は、蓋閉じスリープについては不要になる）。残った場合は、同じ呼び出しで蓋閉じスリープを有効に戻し、蓋を閉じるとスリープすることを確かめる。

## 結果

未確認。`DEC-BLK-006` でこの方式を使わなくなったので、確かめない。
