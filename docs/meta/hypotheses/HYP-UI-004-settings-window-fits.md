# HYP-UI-004 720 × 500 pt の設定ウインドウに、最も行の多いセクションがスクロールせずに収まる

## 主張

幅 720 pt、高さ 500 pt、サイドバーの幅 200 pt の設定ウインドウで、最も行の多い「解除の条件」（2つのグループに 7 行）が、システム既定の行の高さと余白のまま、スクロールせずに収まる。

## 外れたときに起きること

ウインドウの高さを変えるか、スクロールを許す。`SPEC-SET-001` の寸法が変わる。

## 確かめ方

1. 環境: 対応環境の Mac。システム設定の文字の大きさは既定にする。
2. 実装した設定画面の「解除の条件」を開く。
3. 成功: すべての行がスクロールせずに見える。失敗: スクロールが要る。

永続的なシステム変更は伴わない。

## 結果

未確認。
