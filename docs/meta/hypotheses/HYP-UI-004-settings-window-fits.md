# HYP-UI-004 720 × 500 pt の設定ウインドウに、スクロールを許すセクション以外で最も行の多い操作が収まる

## 主張

幅 720 pt、高さ 500 pt、サイドバーの幅 200 pt の設定ウインドウで、スクロールを許すセクション以外で最も行の多い「操作」（2枚のカードに、ホットキーの割り当ての失敗の表示を含めて4行）が、システム既定の行の高さと余白のまま、スクロールせずに収まる。

「スリープ」と「フィードバック」（`DEC-SET-008`）と「このアプリについて」（ライセンスの下の階層を含む。`DEC-UI-014`）は、内容が高さに収まらないときのスクロールを許すため、この仮説の対象に含めない。

## 外れたときに起きること

ウインドウの高さを変えるか、ほかのセクションにもスクロールを許す。高さを変える場合は、`SPEC-SET-001` の寸法が変わる。

## 確かめ方

1. 環境: 対応環境の Mac。システム設定の文字の大きさは既定にする。
2. 実装した設定画面で、ホットキーの割り当ての失敗の表示が出ている状態の「操作」を開く。
3. 成功: すべての行がスクロールせずに見える。失敗: スクロールが要る。

永続的なシステム変更は伴わない。
