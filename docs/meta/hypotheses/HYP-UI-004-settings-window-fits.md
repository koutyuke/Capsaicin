# HYP-UI-004 720 × 500 pt の設定ウインドウに、スリープ以外で最も行の多い一般がスクロールせずに収まる

## 主張

幅 720 pt、高さ 500 pt、サイドバーの幅 200 pt の設定ウインドウで、「スリープ」以外で最も行の多い「一般」（2枚のカードに、案内を含めて6行）が、システム既定の行の高さと余白のまま、スクロールせずに収まる。

「スリープ」は、内容が高さに収まらないときのスクロールを許すため、この仮説の対象に含めない（`DEC-SET-005`）。

## 外れたときに起きること

ウインドウの高さを変えるか、「スリープ」以外にもスクロールを許す。高さを変える場合は、`SPEC-SET-001` の寸法が変わる。

## 確かめ方

1. 環境: 対応環境の Mac。システム設定の文字の大きさは既定にする。
2. 実装した設定画面で、自動で再起動できないことの案内が表示される状態の「一般」を開く。
3. 成功: すべての行がスクロールせずに見える。失敗: スクロールが要る。

永続的なシステム変更は伴わない。

## 結果

未確認。
