# HYP-SYS-005 Sparkle 2.10.1 で準備済みの版に Dismiss を返しても、その版は次の確認と終了時にインストールできる

## 主張

Sparkle 2.10.1 で、展開まで終えた版の「インストールして再起動」の返答に Dismiss を返すと、次のすべてが成り立つ。

1. Sparkle の画面が閉じ、更新のセッションが終わる。
2. 利用者がもう一度更新を確認すると、ダウンロードし直さずに、同じ版を「インストールして再起動」の状態で示す。
3. 利用者がそのままアプリを終了すると、その版がインストールされ、アプリは起動し直さない。

根拠にしたのは、`SPUUserDriver.h` の `showReadyToInstallAndRelaunch:` の説明と、`SPUUpdater.m` が確認の前に動いているインストーラーを探して再開する処理である。実機では確かめていない。

## 外れたときに起きること

- 1 が外れたら、取り消した後に画面が残る。`DEC-LCY-007` を見直す。
- 2 が外れたら、取り消した版をもう一度選ぶにはダウンロードし直すか、次の定期の確認を待つことになる。`SPEC-LCY-008` と `SPEC-SET-007` の説明を直す。
- 3 が外れたら、`SPEC-LCY-008` から終了時のインストールの記述を外す。

## 確かめ方

オーナーが実機で確かめる。アプリの起動と `launchctl` は、エージェントが実行しない。

1. 環境: 対応環境の Mac。更新の配信元と公開鍵を渡した Debug 構成の2つの版と、手元の HTTP サーバー（`EVID-SYS-003` と同じ準備）。自動アップデートは「確認のみ」にする。
2. 古い版で抑止を開始し、新しい版をダウンロードして「インストールして再起動」を選び、抑止の解除の確認で取り消す。Sparkle の画面が閉じることを確かめる。
3. 抑止を続けたまま「今すぐ確認する」を押し、同じ版が「インストールして再起動」の状態で示され、ダウンロードの進捗が出ないことを確かめる。もう一度取り消す。
4. 抑止を解除し、設定ウインドウを閉じて1分待つ。インストールされないことを確かめる。
5. Capsaicin を終了する。新しい版がインストールされ、起動し直さないことを確かめる。
6. 成功: 2〜5 がすべて期待どおり。失敗: どれかが違う。違った手順と、そのときの画面を記録する。

## 結果

未確認。
