# HYP-BLK-012 蓋を閉じている間も DisplayServices の輝度の変更が効き、開けたときに元の輝度へ戻せる

## 主張

抑止中に蓋が閉じたことを検知して、一般ユーザーの権限で DisplayServices の輝度を 0 にすると、次のようになる。

- 閉じている間、輝度は 0 のままで、自動輝度調節や macOS に上書きされない。
- 蓋が開いたことを検知して、閉じる前に読んだ輝度を設定すると、その輝度に戻る。開けた直後に macOS が別の値で上書きしない。

## 外れたときに起きること

閉じている間に暗くできない、または開けたときに戻せないので、`Q-BLK-001` の「加える」は、蓋を開けた利用者に暗い画面を残すことになる。上書きされる場合は、上書きに追従して書き直す処理が要り、利用者の操作との区別が難しくなる。

## 確かめ方

`docs/manual/lid-close-dimming-verification.md` の C3 で確かめる。開いたことの検知は `HYP-BLK-008` と同じ試験で確かめる。

1. 環境: 対応環境の MacBook。外部ディスプレイなし。Capsaicin で抑止し、「ディスプレイを閉じたとき」を「オンのまま」、「ディスプレイを自動でオフにしない」をオンにする。自動輝度調節は、オンとオフの両方で試す。
2. 蓋の開閉に合わせて輝度を 0 にし、元に戻す試験用の補助を動かす。
3. 蓋を閉じて5分待つ。この間、輝度を30秒ごとに読み直して記録する。
4. 蓋を開け、輝度が閉じる前の値に戻ったかを、読み直しと目で確かめる。開けてから1分間、輝度を読み直して記録する。
5. 成功: 閉じている間は 0 のまま、開けた後は閉じる前の値のままである。失敗: 閉じている間に 0 から変わる、または開けた後に別の値になる。

永続的なシステム変更は伴わない。補助が輝度を戻せなかったときは、明るさのキーで戻す。

## 結果

未確認。自動輝度調節がオフのときは、閉じている間は輝度 0 のまま、開けた後は閉じる前の値のままだった（`EVID-BLK-010`）。自動輝度調節がオンの回は行っていない。
