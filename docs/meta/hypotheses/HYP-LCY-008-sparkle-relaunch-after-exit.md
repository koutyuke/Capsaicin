# HYP-LCY-008 Sparkle は、更新の後に古いプロセスが終了してから新しい版を起動する

## 主張

Sparkle がアップデートをインストールしてアプリを起動し直すとき、新しい版のプロセスは、古い版のプロセスが終了した後にだけ起動する。古い版と新しい版が同時に動く時間はない。

## 外れたときに起きること

同じ bundle ID のアプリが既に動いていたら後から開いた方が譲って終了する扱いにすると、起動し直した新しい版が、終了しかけの古い版に譲って終了し、アプリが1つも残らないことがある。譲る判定で、古い版の終了を待つなどの扱いを足す。

## 確かめ方

プロジェクトが固定している Sparkle の版のソース（`Package.resolved` の版、`.build/spm` などに取得されたもの）で、インストーラーがアプリを起動し直す前に、元のアプリのプロセスの終了を待つことを確かめる。実機での確かめは、次に更新の流れを確かめるときに合わせて行う。

## 結果

ソースで支持された（`EVID-LCY-006`）。インストーラーは、元のアプリのプロセスの終了を待ってから最後のインストールと起動し直しを行う。実機の更新の流れでは、まだ確かめていない。
