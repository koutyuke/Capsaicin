# HYP-SET-004 macOS のメニュー形式の Picker で、selectionDisabled を付けた選択肢はグレーで選べなくなる

## 主張

設定の「ディスプレイを閉じたとき」のポップアップ（SwiftUI の `Picker`、`.pickerStyle(.menu)`）で、選択肢の `Text` に `selectionDisabled(true)` を付けると、ポップアップを開いたときにその選択肢がグレーで表示され、選べない。保存値がその選択肢のときも、閉じたポップアップのタイトルには保存値の選択肢が表示される。

## 外れたときに起きること

ヘルパーが使えない間に、ヘルパーが要る選択肢がポップアップでは選べるように見える。`SettingsModel` が保存しないので保存値は変わらないが、選んでも何も起きず、`SPEC-SET-005` の見た目にならない。ポップアップを `NSPopUpButton` で作り直し、項目ごとに `isEnabled` を切る。

## 確かめ方

1. 環境: macOS 26 以上の MacBook で、`just build` で作った Debug ビルド（ad-hoc 署名のため、ヘルパーは「このビルドでは使用不可」になる）。
2. 設定の「スリープ」で「ディスプレイを閉じたとき」のポップアップを開き、選択肢を見て、「オンのまま」を選ぼうとする。続けてキーボードの ↑↓ と Return でも選ぼうとする。
3. 成功: 「Macをスリープ（標準）」以外の選択肢がグレーで、マウスでもキーボードでも選べない。失敗: グレーにならない、または選べる。

永続的なシステム変更は伴わない。

## 結果

支持された（`EVID-SET-003`）。ヘルパーが使えない間、MacBook の「ディスプレイを閉じたとき」のポップアップで「Macをスリープ（標準）」以外の選択肢がグレーで表示され、選べなかった。キーボードでの操作と、保存値が選べない選択肢のときの閉じたポップアップのタイトルは確かめていない。
