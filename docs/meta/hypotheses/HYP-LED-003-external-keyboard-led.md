# HYP-LED-003 外付けキーボードでも HIDCapsLockLED で LED が光る

## 主張

`HIDCapsLockLED` を持つ外付けキーボードのサービスに `"On"` を書き込むと、その外付けキーボードの Caps Lock の LED が点灯する。

## 外れたときに起きること

外付けキーボードでは LED で知らせられない。`REQ-LED-004` を内蔵キーボードに限るか、外付けキーボード向けの別の方式を探す。`SPEC-LED-002` の対象が変わる。

## 確かめ方

LED への最初の書き込み前に、対象へ `"Auto"` を書ける独立した復旧プロセスと復旧手順を用意し、PM の承認を得る。用意できなければ、最初の書き込み前で止める。Caps Lock の入力操作は、承認された手順で利用者が手動で行い、ソフトウェアからは変えない。

1. 環境: 対応環境の Mac。USB 接続、Bluetooth 接続、2.4 GHz のレシーバー接続（`EVID-LED-001` の「2.4G Wireless Receiver」など）の外付けキーボードを、手に入る範囲で用意する。
2. 外付けキーボードを接続し、試作プログラムでキーボードに該当するサービスを列挙する。対象と接続方式を記録する。初期プロパティの有無だけでは対象から外さない。
3. そのサービスに `"On"` を書き込み、戻り値を記録して LED を目視する。
4. 成功: 書き込みが成功し、外付けキーボードの LED が点灯する。失敗: 対象サービスが見つからない、書き込みに失敗する、または LED が点灯しない。機器ごとに結果を記録する。

終わったら各対象への `"Auto"` の書き込みの戻り値が成功であることと、各 LED が通常の Caps Lock 連動に戻ったことを確かめる。読み戻し値が `"Auto"` であることは復旧の条件にしない（`EVID-LED-002`）。
