# HYP-BLK-013 「明るさを0」で暗くしたままアプリが終了しても、輝度のキーで輝度を戻せる

## 主張

「ディスプレイを閉じたとき」を「明るさを0」にして抑止し、ディスプレイを閉じて輝度が 0 になった後にアプリが `kill -9` で終了すると、ディスプレイを開いたときに次が成り立つ。

1. 画面は暗いままだが、キーボードの輝度を上げるキー（またはコントロールセンターの輝度のスライダー）で、普段どおり輝度を上げられる。
2. その後にアプリを起動すると、記録した輝度に戻す処理（`SPEC-BLK-013`）が動く。

## 外れたときに起きること

クラッシュで画面が暗いまま残り、利用者が戻せない。クラッシュ時の再起動をやめる方針のもとでは、輝度を戻す別の仕組みを考えるか、「明るさを0」を見直す。

## 確かめ方

オーナーが、内蔵ディスプレイのある MacBook と、試作のアプリで確かめる。試作のアプリは agent を登録しないので、終了しても起動し直されない。戻せなかったときは、システム設定の「ディスプレイ」の輝度のスライダーで戻す。

## 結果

実機で支持された（`EVID-BLK-015`）。`SIGKILL` と `SIGSEGV` のどちらでも、開いた画面は最低限の明るさで見え、輝度のキーとスライダーで戻せた。その後にアプリを起動すると、記録した輝度に戻して記録を消した。「輝度を自動調節」がオフの場合は確かめていない。
