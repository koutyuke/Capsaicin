# HYP-UI-001 ダークのアクセントカラー #6A9CC0 で、既定のボタンの文字が読める

## 主張

外観がダークでアクセントカラーがマルチカラーのとき、アプリのアクセントカラー `#6A9CC0` の既定のボタン（ダイアログの「インストール」など）の文字を、OS が読める明るさで描く。白い文字のままの場合のコントラストは、デザインの試算で 2.95:1 である。

## 外れたときに起きること

ダークで既定のボタンの文字が読みにくい。`DEC-UI-003` の影響に従ってダークの値を見直し、`SPEC-UI-003` の表を変える。

## 確かめ方

1. 環境: 対応環境の Mac。外観をダーク、アクセントカラーをマルチカラーにする。
2. アクセントカラーを設定した試作アプリで、既定のボタンを持つ `NSAlert` を表示し、Accessibility Inspector で文字と背景のコントラストを測る。
3. 成功: OS が文字の色を調整して読める、または 3:1 以上ある。失敗: 白い文字のまま 3:1 を下回る。

永続的なシステム変更は伴わない。

## 結果

未確認。
