### メニューの仕様

- `SPEC-MENU-001`: 停止中と抑止中の構成を `DEC-MENU-006` のとおりにする。トップレベルにチェックの付く項目を置かないことを書く。時間の条件なしで開始する項目は常に出す。受け入れ例を今の構成に合わせる。
- `SPEC-MENU-002`: 停止中のサブメニューと抑止中の「オフにする時刻を変更」を、起点が今であることを示す見出し、プリセット、任意の時間の入力、区切り、時刻の指定にそろえ、抑止中だけ最後に区切りと時間の条件なしの項目を置く。停止中の時刻の指定がトップレベルにあるという記述をなくす。
- `SPEC-MENU-003`: 時刻のパネルを開く場所を、停止中も抑止中もサブメニューにする。
- `SPEC-MENU-008`: タイトルと本文を「クイック設定」のサブメニューにする。
  - トップレベルに「クイック設定」のサブメニューを1つ置き、中にさらにサブメニューを開く項目を置かない。
  - 中の構成: 「スリープとディスプレイ」の見出しとオン・オフの項目、「ディスプレイを閉じたとき」の見出しと選択肢（MacBook）、「バッテリー」の見出しとバッテリー残量の条件の項目（内蔵バッテリーのある Mac）。MacBook 以外の Mac では、閉じたときの見出しと選択肢の代わりに、設定画面と同じオン・オフの項目を「スリープとディスプレイ」の下に置く。
  - 見出しと項目名は設定画面と同じ文言。チェックは保存値を示し、どの項目も「それが有効」を示す。
  - 注意（`SPEC-SET-005`）は、オン・オフの項目ならその項目に、閉じたときなら保存値の選択肢に、記号と副題で示す。「クイック設定」の行にも、中に注意があれば記号を付ける。
  - 「クイック設定」の行は、バッテリー残量の条件をオフにしている間、そのことを副題で示す（内蔵バッテリーのない Mac では示さない）。
  - 閉じたときの選択肢は、読み上げで何の選択かが伝わるようにする。
  - 保存と反映、ヘルパーの扱い、バッテリー残量の項目の内容（しきい値を示す、オフでも示す、電源アダプタの副題）は今の記述のまま。
  - 受け入れ例を今の構成に合わせ、バッテリー残量の条件をオフにしたときに「クイック設定」の行で分かる例を足す。

### 設定画面の仕様

- `SPEC-SET-002`: 「スリープ」の表を3つのグループ（スリープとディスプレイ、スリープ防止の自動解除、バッテリー）にする。バッテリー残量の条件のスイッチの項目名を、何がオンになるかが分かる言い切りの呼び名にする。
- `SPEC-SET-006`: 内蔵バッテリーがないときに表示しないものを、「バッテリー」のグループ全体と、メニューの「クイック設定」の「バッテリー」の見出しと項目、「クイック設定」の行のバッテリーの副題にする。

### 手順書

`docs/manual/verification.md` のうち、メニューの構成（8.1）、抑止中の時間の変更（8.5）、設定の項目（8.6）、バッテリー残量の項目（8.7）、設定画面の「スリープ」のグループ（8.2 など）の確認で、今回の仕様と食い違うところを直す。8.6 と 8.7 では、「クイック設定」の中で項目と選択肢をサブメニュー1回で選べること、トップレベルに左の余白がないこと、バッテリーをオフにしたときの「クイック設定」の副題、VoiceOver で閉じたときの選択肢が何の選択か伝わることを確かめる手順を足す。電池を使い切らせる手順は書かない。
