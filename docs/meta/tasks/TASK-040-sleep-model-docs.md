## 作るもの

1. `DEC-BLK-006` の結論の表を正として、`SPEC-BLK-001` の表を「抑止中は常に自動スリープを止める。画面の自動消灯とスクリーンセーバーがオンなら画面の自動消灯とスクリーンセーバーも、手動スリープとディスプレイを閉じたときのスリープがオンなら手動スリープと蓋閉じスリープも止める」形に書き直す。受け入れ例も合わせる。
2. `SPEC-BLK-002` は「閉じたときの画面」が「消灯」のときに画面を消す、に直す。「つけたまま」の受け入れ例を足す。
3. `SPEC-BLK-012`（抑止に使う設定値）から変種と蓋閉じスリープの行を除き、閉じたときの画面の行に直す。「変種 B では蓋閉じスリープの保存値を使わない」の受け入れ例は削除する。蓋閉じスリープの制御（`kPMSetClamshellSleepState`）に触れている状態の定義や節（例: 抑止の仕組みの定義、`SPEC-BLK-007` 付近の蓋閉じスリープの制御の扱い）からも、その仕組みを除く。
4. `SPEC-SET-002` の「止めるスリープ」の表を `DEC-BLK-006` の3行に直す。セクション名は画面に合わせて「防止するスリープ」とする（現在の画面の文言。`Sources/Capsaicin/Settings/SettingsSleep.xcstrings` の `title` を読むだけにして、編集はしない）。(i) で伝えることは次のとおりにする。
   - 画面の自動消灯とスクリーンセーバー: 一定時間操作がないときの画面の消灯とスクリーンセーバーを防ぐこと。オフにすると、システム設定どおりに画面が消えること。
   - 手動スリープとディスプレイを閉じたときのスリープ: アップルメニューなどの手動スリープと、ディスプレイを閉じたときのスリープを防ぐこと。OS の仕組み上、2つは個別に防止できないこと。ヘルパーが要ること。蓋のない Mac では項目名を「手動スリープ」にし、ディスプレイの記述を除く。
   - 閉じたときの画面: 手動スリープとディスプレイを閉じたときのスリープを防止しているときだけ使えること。「消灯」にすると、Mac を動かしたまま画面を消して消費電力を抑えること。
5. `SPEC-SET-005` を、変種と含意をなくした形に書き直す。残る無効は、閉じたときの画面の前提による無効（親がオフ、またはヘルパーが正しく設置されていない）と、ヘルパーが要る行の保存値がオンなのにヘルパーが正しくないときの注意の表示だけである。含意による無効の受け入れ例は削除し、前提による無効の受け入れ例にする。
6. `SPEC-SET-006` の蓋のない Mac で表示しないものを、「閉じたときの画面」と、手動スリープの行の項目名の扱いに直す。
7. `REQ-BLK-001`〜`REQ-BLK-005` を新しい形に合わせる。`REQ-BLK-001` は「抑止中は、利用者が操作しなくても Mac が自動でスリープしない」（設定によらない）、`REQ-BLK-002` は画面の自動消灯とスクリーンセーバー、`REQ-BLK-003` と `REQ-BLK-004` は「手動スリープとディスプレイを閉じたときのスリープ」を止める設定のとき、`REQ-BLK-005` は閉じたときの画面を「消灯」にしていれば画面が消える、にする。`sources` の `DEC-BLK-004` と `HYP-BLK-002` は `DEC-BLK-006` に替える。`REQ-SET-005` は、各行の値がそのまま止まる範囲を表し、使えない行は理由を示す、という趣旨に直し、`sources` を `DEC-BLK-006` にする。要件の `specs` と仕様の `関連要件` を双方向で一致させる。
8. `HYP-BLK-002` と `HYP-BLK-003` は判断に影響しなくなったので削除し、参照を除く（`SPEC-*` の「確かめていない前提」の箇条や `verification.md` 3.3 を含む）。`HYP-BLK-009`（スクリーンセーバー）の確かめ方を手順書の 3.2 付近に足す。
9. 受け入れ例の共通の前提（`docs/specs/blocking.md` の冒頭）から「変種 A」を除く。
