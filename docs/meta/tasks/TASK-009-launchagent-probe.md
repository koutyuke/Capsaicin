修正担当は、手動専用の `operations.py` に対象照合・原子的配置・未登録時の回収・起動情報の観測を実装し、プローブのログ失敗も非ゼロ終了にした。独立再レビューでは、手動操作の安全境界と新しい生成物を照合した。実機の登録・起動・撤去は、この検証に含めない。

- `load_manifest()` は実 UID だけでなく、実効 UID も manifest の UID と一致することを要求する。実効 UID だけが異なる設置・撤去を、読み取り・コマンド実行前に拒否するテストを追加した。

`launchctl print` の出力は安定した API ではない。既知のフィクスチャでの判定を実機形式の保証とは扱わず、未知・不正な構造は操作せず停止する。生成手順は現リポジトリの操作スクリプトへの絶対参照であり、凍結したコピーではない。
