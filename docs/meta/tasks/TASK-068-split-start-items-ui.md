## 作るもの

### メニューの構成

`DEC-MENU-005` の「結論」の図のとおりにする。

- 停止中: 見出し、警告の行、指定のない開始の項目（副題付き）、区切り、時間の条件なしで開始する項目（`.start(.noTimeLimit)`）、時間を指定するサブメニュー（プリセットと「時間を入力…」だけ）、時刻の入力パネルを開く項目（サブメニューなし）、区切り、設定の項目（下記）、区切り、設定、終了。
- 抑止中: 見出し、警告の行、状態の行、解除の項目、「オフにする時刻を変更」のサブメニュー（「今から」の見出し、プリセット、「時間を入力…」、区切り、「時刻を指定…」、区切り、時間の条件なしの項目）、区切り、設定の項目（下記）、区切り、設定、終了。
- 状態の行: 時間の解除条件がなければ、バッテリーの行の有無にかかわらず「手動でオフにするまで継続」を出す。
- 指定のない開始の項目の副題: タイマーなら「〜後にオフ」、指定時刻が今日なら「〜にオフ」、翌日なら「明日〜にオフ」、時間の条件がなければ、バッテリー残量の条件の有無にかかわらず「オフにするまで」。タイマーと指定時刻の両方がオンなら、今と同じく `TimeLimitRule` が選ぶ方を使う。

### 設定の項目（停止中と抑止中で同じ）

- 「スリープとディスプレイ」の見出し（`NSMenuItem.sectionHeader`。今の「今から」の見出しと同じ仕組み）の下に、今サブメニューに入れている項目を直接並べる。「ディスプレイを閉じたとき」だけ選択肢をサブメニューにする。注意の記号・副題、ヘルパーの確認、エラー、巻き戻しは今の実装のまま使う。
- その下に「スリープ防止の自動解除」の見出しと、バッテリー残量の条件のオン・オフの項目を置く。
  - 項目名は保存されたしきい値を含める（オフのときも）。チェックは保存値のオン・オフ。
  - 「電源アダプタ接続中は残量でオフにしない」の保存値がオンなら、副題を出す。電源アダプタの今の接続状態では変えない。
  - 選ぶと、設定画面のバッテリー残量のスイッチと同じ方法で保存値を切り替える。同じ処理を2つ書かない。抑止中にその場で反映されるのは既存の仕組みに任せる。
  - 内蔵バッテリーのない Mac では、見出しごと出さない。判定は設定画面と同じもの（`SPEC-SET-006`）を使う。
- 2つの見出しの文言は、設定画面の `SettingsSleep.xcstrings` の `behavior.group.title` と `release.group.title` を使う。

### しきい値の範囲

- `BatteryThreshold` の範囲を 5〜100%（5% 刻み）にする。範囲外の保存値は、今の読み込みの仕組みで既定値になることをテストで確かめる。
- 設定画面の Slider の範囲を同じ範囲にする。範囲は `BatteryThreshold` の定義から取り、2か所に数字を書かない。

### 文言

`MenuBar.xcstrings` の Japanese の値。キー名は既存の付け方に合わせて決めてよい。値を変えるキーは、使っている場所がほかにないことを確かめる。

| 場所 | 文言 |
| --- | --- |
| 開始の項目の副題（タイマー） | %@後にオフ（例: 1時間後にオフ、1時間30分後にオフ） |
| 開始の項目の副題（指定時刻、今日） | %@にオフ |
| 開始の項目の副題（指定時刻、翌日） | 明日%@にオフ |
| 開始の項目の副題（時間の条件なし） | オフにするまで |
| 時間の条件なしで開始する項目 | オフにするまでオン |
| 時間を指定するサブメニュー | 時間を指定してオン（今のまま） |
| 時刻のパネルを開く項目（停止中のトップレベル） | 時刻を指定してオン… |
| 抑止中のサブメニューの時刻の項目 | 時刻を指定…（今のまま） |
| 抑止中のサブメニューの時間の条件なし | オフにするまで |
| バッテリー残量の項目 | バッテリー残量%d%%未満 |
| バッテリー残量の項目の副題 | 電源アダプタ接続中は除く |

使わなくなったキーは消す（`fmt-check` は `stale` のキーで失敗する）。

### テスト

名前に仕様 ID（`SPEC-MENU-001`、`SPEC-MENU-002`、`SPEC-MENU-004`、`SPEC-MENU-008`、`SPEC-SET-002` など）を含める。少なくとも次を確かめる。

- 停止中と抑止中の項目の並びと、各項目のコマンド（時間の条件なしの項目が `.start(.noTimeLimit)`、時刻の項目がパネルを開きサブメニューを持たないこと）。
- 停止中の時間のサブメニューがプリセットと「時間を入力…」だけであること。抑止中のサブメニューの中身。
- 開始の項目の副題の4通り（タイマー、今日の指定時刻、翌日の指定時刻、条件なし）と、バッテリー残量の条件がオンで時間の条件がないときも「オフにするまで」になること。
- 状態の行で、時間の条件がなくバッテリーの行があるときも「手動でオフにするまで継続」が出ること。
- 設定の項目の見出し、並び、チェック、ハードウェアによる出し分け（内蔵バッテリーがないときにバッテリーの見出しと項目が出ないこと）。

- しきい値 0% と 105% が作れず 5% と 100% が作れること、保存値 0% を読むと既定値になること。
