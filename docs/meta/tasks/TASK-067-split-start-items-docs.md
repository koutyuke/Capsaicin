### 仕様

- `docs/specs/menu.md` の冒頭の判断への参照を `DEC-MENU-005` にする。
- `SPEC-MENU-001`: 停止中と抑止中の構成を `DEC-MENU-005` のとおりにする。
  - 停止中の指定のない開始の項目の副題は、開始したら使う時間の条件だけを示す（タイマーなら何分後か、指定時刻ならその時刻、翌日なら翌日であること、時間の条件がなければ自分でオフにするまで続くこと）。バッテリー残量の条件は副題に含めない。今の「バッテリー残量の条件も有効でないときだけ」の記述をなくす。
  - 時間の条件なしで開始する項目、時間を指定するサブメニュー、時刻の入力パネルを開く項目を、トップレベルに並べる。
  - 設定の項目の2つの見出しと項目の並びは `SPEC-MENU-008` を参照する。
  - 受け入れ例を今の構成に合わせて直す。バッテリー残量の条件がオンでも、時間の条件がなければ副題が自分でオフにするまで続くことを示す例を入れる。
- `SPEC-MENU-002`: 停止中の時間のサブメニューは、プリセットと任意の時間を入力する項目だけにする。抑止中の「オフにする時刻を変更」のサブメニューは、起点が今であることを示す見出し、プリセット、任意の時間を入力する項目、区切り、時刻を指定する項目、区切り、時間の条件なしの項目にする。
- `SPEC-MENU-003`: 時刻のパネルを停止中はトップレベルの項目から、抑止中はサブメニューから開くことと食い違う記述があれば直す。
- `SPEC-MENU-004`: 時間の解除条件がなければ、バッテリーの行の有無にかかわらず、自分で解除するまで続くことを示す。受け入れ例も合わせる。
- `SPEC-MENU-008`: タイトルと本文を、サブメニューではなく見出しの下に並べる形にする。
  - 「スリープとディスプレイ」の見出しの下に、設定画面と同じ項目名・順序で項目を直接置く。複数の選択肢を持つ項目だけ、選択肢をサブメニューに並べる。保存と反映、ヘルパー、注意の扱いは今の記述のまま。
  - その下に「スリープ防止の自動解除」の見出しと、バッテリー残量の条件のオン・オフの項目を置く。項目名に保存されたしきい値を示し（オフのときも示す）、チェックは保存値のオン・オフを示す。「電源アダプタ接続中は残量でオフにしない」がオンなら副題でそのことを示す。選ぶと設定画面と同じく保存して反映する（`SPEC-BLK-009`）。内蔵バッテリーのない Mac では見出しごと出さない（`SPEC-SET-006`）。しきい値と電源アダプタの設定はメニューでは変えない。
  - 見出しは設定画面の見出しと同じ文言を使う。
  - 受け入れ例に、抑止中にバッテリー残量の項目をオフ・オンにする例を足す（オンに戻したときに残量がしきい値を下回り、電源アダプタにつながっていなければ、その場で解除される）。
- `SPEC-SET-002`: しきい値の選べる値を 5〜100%（5% 刻み）にする。
- `SPEC-SET-006`: 内蔵バッテリーがないときに表示しないものに、メニューのバッテリー残量の見出しと項目を足す。
