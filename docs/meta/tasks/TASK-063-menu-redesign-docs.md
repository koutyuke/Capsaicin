## 作るもの

新しく振る ID は `REQ-BLK-015`、`REQ-MENU-007`、`SPEC-MENU-008` だけにする。言い回しは整えてよい。

### 要件

- `REQ-LED-007`: 案内の表示先を設定の「LED」セクションだけにする。`sources` に `DEC-LED-007`。
- `REQ-BLK-006`: 開始の要求で、時間の条件を持たないことも指定できることを足す。`sources` に `DEC-BLK-009`。
- `REQ-BLK-015`（新規、functional、should）: 抑止中に、メニューと CLI で時間の解除条件を置き換えられる。抑止は途切れない。理由: オンにした後に時間を変えたいとき、一度オフにしてスリープ防止を外さずに済ませるため。`specs` は `SPEC-BLK-003`、`SPEC-BLK-011` など実際に書いた節。`depends_on = ["REQ-BLK-006"]`、`sources = ["DEC-BLK-009"]`。
- `REQ-MENU-002`: 停止中の開始に加え、抑止中にメニューで時間の解除条件を変えられること、時間の条件を持たないことも選べることを足す。`sources` に `DEC-BLK-009`、`DEC-MENU-004`。
- `REQ-MENU-007`（新規、functional、should）: 利用者は、メニューから設定の「スリープとディスプレイ」の項目を切り替えられる。理由: 抑止中に設定画面を開かずに切り替えるため。`specs = ["SPEC-MENU-008"]`、`depends_on = ["REQ-SET-001"]`、`sources = ["DEC-MENU-004"]`。
- `REQ-CLI-001`: 抑止中に時間を指定した `on` は、解除の時刻を置き換えることを足す。
- ほかの要件は、`specs` と `関連要件` の対応を保つために必要なときだけ直す。

### 仕様

- `SPEC-BLK-003`: 開始の要求の時間の指定に「時間の条件なし」を加える。抑止中の置き換えも同じ規則で解除の時刻と由来を決め、起点は要求を受けた時刻であることを書く。
- `SPEC-BLK-011`: 表の「抑止中・開始」を、指定なし（何も変えない）と時間の指定あり（解除の時刻を置き換える。仕組みを外したり掛け直したりしない。バッテリーの条件は変えない）に分ける。「抑止中に解除の時刻を変える操作はない」の文をなくす。置き換えを受けた時点で解除の時刻を過ぎていれば、自動の解除を先に行うことを書く。受け入れ例を足す（抑止中に 30 分を選び直すと、選んだ時点から 30 分後に解除される。抑止中に時間の条件なしを選ぶと、時間では解除されない）。
- `SPEC-BLK-009`: 変えない。設定のタイマーと指定時刻の変更がいまの抑止に効かないことと、メニュー・CLI の置き換えの区別が読み取れるよう、必要なら参照を足す。
- `SPEC-CLI-001`、`SPEC-CLI-007`: 抑止中の `on --for`、`on --until` は置き換え、終了コードは 0、出力で置き換えたことと新しい解除の時刻を伝える。引数なしの `on` は今までどおり。CLI に時間の条件なしの指定は加えない。
- `SPEC-HUD-001`、`SPEC-HUD-002`: メニューで解除の時刻を置き換えたときに、開始したときと同じ形の HUD を新しい条件で表示する。CLI では表示しない。時間の条件をなくしたときに条件の欄に何を出すかを決めて書く。
- `SPEC-LCY-007`: 出来事の表に「解除の時刻の置き換え」を足す（セッションを書き直す。保存できないときは開始以外の出来事と同じ扱い）。
- `SPEC-LED-005`: 案内はメニューに出さず、設定の「LED」セクションだけに出す。受け入れ例のメニューの確認を外す。
- `SPEC-MENU-001`: 構成を `DEC-MENU-004` のとおりにする。
  - 停止中: 見出し、警告の行、開始の項目（副題は今の規則）、時間を指定して開始するサブメニュー、区切り、スリープとディスプレイのサブメニュー（`SPEC-MENU-008`）、区切り、設定、終了。キー配列の案内の項目はなくす。
  - 抑止中: 見出し、警告の行、状態の表示（`SPEC-MENU-004`）、解除の項目、解除の時刻を変更するサブメニュー、区切り、スリープとディスプレイのサブメニュー、区切り、設定、終了。
- `SPEC-MENU-002`: サブメニューの中身を、15 分、30 分、1 時間、2 時間、4 時間、8 時間、任意の時間を入力する項目、区切り、時刻を指定する項目、区切り、時間の条件なしにする。抑止中のサブメニューは同じ中身で、先頭に起点が今であることを示す見出しを置き、選ぶと解除の時刻を置き換える（`SPEC-BLK-011`）。チェックマークは付けない。選んだ値は設定の既定値を変えない。
- `SPEC-MENU-003`: パネルは停止中は開始、抑止中は変更として、タイトルと確定のボタンを替える。時間のパネルに、確定したらオフになる時刻を示す（時刻のパネルの「翌日」の表示と同じ位置）。抑止中の初期値は、時間のパネルは残り時間（分に切り上げ）、時刻のパネルはいまの解除の時刻。時間の条件がなければ停止中と同じ。パネルは、抑止の状態（停止中か抑止中か）が変わったら閉じる。入力欄の操作は `SPEC-UI-005` を参照する。
- `SPEC-MENU-004`: キー配列の案内への言及があれば外す。
- `SPEC-MENU-008 スリープとディスプレイのサブメニュー`（新規、関連要件 `REQ-MENU-007`）: `DEC-MENU-004` のとおり。設定の「スリープとディスプレイ」の項目と同じ項目名・選択肢・ハードウェアによる出し分け（`SPEC-SET-006`）。チェックは保存値を示す。選ぶと設定画面と同じく保存して反映し、ヘルパーが要る選択肢は設定画面と同じ流れ（`SPEC-SET-005`、`SPEC-HLP-001`）にする。ヘルパーの注意（`SPEC-SET-005` の注意の表示）をメニューでどう示すかを決めて書く。停止中と抑止中で同じ形。受け入れ例を足す。
- `SPEC-SET-002`: 「継続時間」のコントロールの列を `SPEC-UI-005` に合わせる（欄ごとの Stepper）。
- `SPEC-UI-005`: 「時間の長さ」を `DEC-UI-013` のとおりにする（時間と分の数値欄それぞれに Stepper、刻み、繰り上がり、↑↓ キー、範囲の端、不正な入力）。受け入れ例を足す（`0 時間 58 分` で分を上げると `1 時間 3 分`、`23 時間 30 分` で時間を上げると `24 時間 0 分`）。
- `SPEC-UI-007`: 入力欄の ↑↓ キーに触れる必要があれば足す。
