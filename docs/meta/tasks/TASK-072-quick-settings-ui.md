## 作るもの

### メニューの構成

`DEC-MENU-006` の「結論」の図のとおりにする。

- 停止中: 見出し、警告の行、指定のない開始の項目（副題は今のまま）、区切り、「時間指定なしでオン」（`.start(.noTimeLimit)`、常に出す）、「時間・時刻を指定してオン」のサブメニュー、区切り、「クイック設定」のサブメニュー、区切り、設定、終了。トップレベルの「時刻を指定してオン…」はなくす。
- 時間・時刻のサブメニュー（停止中）: 「今から」の見出し、プリセット、「時間を入力…」、区切り、「時刻を指定…」。
- 抑止中: 見出し、警告の行、状態の行（今のまま）、解除の項目、「オフにする時刻を変更」のサブメニュー（停止中と同じ並びのあとに、区切りと「時間指定なし」）、区切り、「クイック設定」のサブメニュー、区切り、設定、終了。
- トップレベルには、チェックの付く項目（`state` が `.on`）を置かない。

### クイック設定

- 中に、さらにサブメニューを開く項目を置かない。
- 「スリープとディスプレイ」の見出し（`SettingsSleep.xcstrings` の `behavior.group.title`）の下に、オン・オフの項目を置く。MacBook ではディスプレイスリープの項目、MacBook 以外の Mac ではそれと手動スリープの項目。
- MacBook では「ディスプレイを閉じたとき」の見出し（設定画面の項目名と同じキー）の下に、4つの選択肢を並べ、保存値の選択肢にチェックを付ける。選ぶと今と同じ処理（`changeLidClose`）を呼ぶ。
- 選択肢のアクセシビリティのラベルは、見出しの文言と選択肢の文言を合わせたものにする（今の警告の行と同じ `setAccessibilityLabel` の仕組みを使う）。
- 内蔵バッテリーのある Mac では、「バッテリー」の見出し（`SettingsSleep.xcstrings` に足す、設定画面と同じキー）の下に、バッテリー残量の条件の項目を置く。中身（しきい値を示す、オフでも示す、電源アダプタの副題、選ぶと保存値を切り替える）は今のまま。
- 注意: オン・オフの項目は今のまま、その項目に記号と副題を付ける。「ディスプレイを閉じたとき」の注意は、保存値の選択肢に記号と副題を付ける。中のどれかに注意があれば、「クイック設定」の行にも注意の記号を付ける。
- 「クイック設定」の行の副題: 内蔵バッテリーがあり、バッテリー残量の条件がオフのときだけ出す。
- ヘルパーの確認、エラー、巻き戻しは今の処理をそのまま使う。

### 設定画面

- 「スリープ」を3つのグループにする。「スリープとディスプレイ」（今のまま）、「スリープ防止の自動解除」（タイマーと指定時刻）、「バッテリー」（バッテリー残量の条件のスイッチ、しきい値、電源アダプタ接続中は残量でオフにしない）。内蔵バッテリーのない Mac では「バッテリー」のグループごと出さない。
- バッテリー残量の条件のスイッチの項目名を変える（下の表）。

### 文言

キー名は既存の付け方に合わせて決めてよい。値を変えるキーは、使っている場所がほかにないか確かめる。使わなくなったキーは消す（`fmt-check` は `stale` のキーで失敗する）。コードから動的に引くキーには `"extractionState" : "manual"` を付ける。

| 場所 | 文言 |
| --- | --- |
| 時間の条件なしで開始する項目 | 時間指定なしでオン |
| 停止中の時間・時刻のサブメニュー | 時間・時刻を指定してオン |
| 抑止中のサブメニューの時間の条件なし | 時間指定なし |
| サブメニューの時刻の項目 | 時刻を指定…（今のまま） |
| 「クイック設定」の行 | クイック設定 |
| 「クイック設定」の行の副題（バッテリー残量の条件がオフ） | バッテリー残量ではオフにしない |
| バッテリー残量の項目（メニュー） | 残量%d%%未満でオフにする |
| 閉じたときの選択肢のアクセシビリティのラベル | %1$@、%2$@（見出し、選択肢） |
| 設定画面とメニューの「バッテリー」の見出し（`SettingsSleep.xcstrings`） | バッテリー |
| 設定画面のバッテリー残量の条件のスイッチ（`SettingsSleep.xcstrings`） | 残量が少なくなったらオフにする |

### テスト

名前に仕様 ID（`SPEC-MENU-001`、`SPEC-MENU-002`、`SPEC-MENU-008`、`SPEC-SET-002`、`SPEC-SET-006` など）を含める。少なくとも次を確かめる。

- 停止中と抑止中のトップレベルの並びとコマンド。「時間指定なしでオン」が設定の時間の条件の有無にかかわらず出ること。トップレベルに `.on` の項目がないこと。
- 停止中と抑止中の時間・時刻のサブメニューの並び。
- クイック設定の中身: MacBook、MacBook 以外の Mac、内蔵バッテリーのない Mac。中にサブメニューを持つ項目がないこと。閉じたときの選択肢のチェックとコマンド、アクセシビリティのラベル。
- 注意の記号と副題の付け先（オン・オフの項目、閉じたときの保存値の選択肢、「クイック設定」の行）。
- 「クイック設定」の行の副題が、バッテリー残量の条件がオフのときだけ出ること。内蔵バッテリーがなければ出ないこと。
- 設定画面の「バッテリー」のグループと、内蔵バッテリーがないときに出ないこと（既存の設定画面のテストの形に合わせる）。
