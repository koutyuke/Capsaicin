# PLAN-BLK-002 指定したアプリの終了で解除する

## 目的

長時間の処理を行うアプリが終わったら、自動で抑止を解除できるようにする。

## 想定する体験

利用者は、抑止を開始するときに、解除の条件としてアプリを指定する。指定したアプリが終了したら、抑止が解除される。

## 実現の見込み

解除条件の1つとして、既存の解除条件（`SPEC-BLK-007`）に加えられる見込みである。

## 要件にする前に決めること

- アプリをどう指定するか（メニュー、CLI、設定）。
- 指定したアプリが開始の時点で起動していない場合の扱い。
