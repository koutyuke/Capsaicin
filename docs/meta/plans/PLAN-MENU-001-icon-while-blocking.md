# PLAN-MENU-001 抑止中にメニューバーのアイコンを変える

## 目的

画面を見ているときに、メニューバーで抑止中かどうかを分かるようにする。

## 想定する体験

抑止中は、メニューバーのアイコンが停止中と異なる見た目になる。

## 実現の見込み

ステータスアイコンの画像を、抑止の状態に合わせて切り替えれば実現できる見込みである。

## 要件にする前に決めること

- アイコンの見た目（デザインは別途検討中）。
- アイコンを変えるかを設定で選べるようにするか。
