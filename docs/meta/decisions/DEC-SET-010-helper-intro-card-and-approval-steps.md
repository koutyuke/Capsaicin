# DEC-SET-010 「ヘルパー」の先頭に説明のカードを置き、許可の手順は承認待ちのときだけ状態の行に出す

## 結論

設定の「ヘルパー」セクションで伝えることを、いつ必要になるかで置き分ける。

- セクションの先頭に、説明のカードを置く。macOS のシステム設定が各画面の先頭に置く説明のカードと同じ形にし、左に角丸の四角に入れたアイコン、右に太字の見出しと説明文を置く。説明文では、ヘルパーが何をするかと、システム設定でオフにすると使えなくなることを伝える。説明文は状態によらず同じにする。
- イラストと「詳しい情報…」のリンクは置かない。
- 状態と管理の2行は、説明のカードの下の1枚のカードに、状態、管理の順で置く。
- 「状態」の行の説明文は、承認待ちのときだけ出し、システム設定で許可する手順を伝える。ほかの状態では説明文を出さない。
- 説明のカードのアイコンは、サイドバーの「ヘルパー」と同じ `lock.shield` にする。「状態」の行のアイコンは `smallcircle.filled.circle` に替え、隣り合うカードに同じ記号を並べない。

## 背景

「状態」の行の説明文は、ヘルパーが何をするか、システム設定で許可する手順、システム設定でオフにすると使えなくなること、の3つを状態によらず常に出していた。オーナーは、状態の行に性質の違う説明がすべて入っていて読みにくいとした。

3つは必要になる時期が違う。ヘルパーが何をするかは、インストールするかを決める前から要る。許可の手順は承認待ちのときだけ要る。オフにすると使えなくなることは、どの状態でも成り立つ事実である。

## 選択肢

説明の置き場所:

- 先頭に、システム設定と同じ形の説明のカードを置く（採用）。説明が状態の行から独立し、利用者はこの画面の説明だとすぐ分かる。アイコンを左に寄せて2〜3行に収めるので、行が2つしかない画面でも重くならない。
- カードの下のフッター（小さい灰色の文）にする。部品は増えないが、文が長いとカードの下に灰色の文が続いて読みにくい。
- 「フィードバック」と同じ、説明文とイラストのカード（`DEC-SET-008`）にする。LED や HUD と違って、ヘルパーは裏で動く仕組みで、見せられる変化がない。仕組みの図は説明文の言い直しになり、効果の絵は機種ごとに2枚要る。
- 大きなアイコンを中央に置く見出しのカードにする。行が2つしかない画面には大げさである。

許可の手順の置き場所:

- 承認待ちのときだけ「状態」の行の説明文に出す（採用）。行の数が状態によらず変わらず（`SPEC-HLP-004`）、注意の記号は状態の値の1か所で済む。上から状態、手順、ボタンの順に読める。
- 承認待ちのときだけ、状態と管理の間に注意の行を足す。行の数が状態で変わり、注意の記号が2つになる。注意の案内の右には何も置かない規則（`SPEC-SET-002`）のため、手順と「システム設定を開く」を同じ行に並べられない。

「状態」の行のアイコン:

- `smallcircle.filled.circle` に替える（採用）。状態を示す点として読め、どの状態にも当てはまる。オーナーが選んだ。
- `waveform.path.ecg`。動いているかどうかを表す記号として読めるが、細い1本の線で、すぐ下の `wrench.and.screwdriver` より軽く見える。
- `lock.shield` のまま。隣り合う2枚のカードの左端に同じ記号が縦に並び、描画で見ると目に付く。
- `gearshape.2`。設定画面の中では「設定」に見えやすく、すぐ下の `wrench.and.screwdriver` と意味が重なる。
- `info.circle`。macOS では詳細を開くボタンの記号として使われることが多い。
- `checkmark.shield` などチェックの付く記号。未インストールや承認待ちでもチェックが出て、値の側の `checkmark.circle.fill` とも重なる。

説明のカードのアイコンは、サイドバーと同じ記号にする。システム設定でも、先頭のカードにはその画面のアイコンを出している。

## 理由

- 説明を、必要になる時期ごとに置き分けると、各状態で読む文が最小になる。
- 説明のカードは、システム設定の画面と同じ形なので、利用者が見慣れている。
- イラストとリンクは、伝える情報を増やさないか、リンク先がない。README でヘルパーに触れているのは、概要の1行とアンインストールの手順だけである。

## 影響

- `SPEC-HLP-004` と `SPEC-SET-002` の「ヘルパー」の表を改める。
- 説明のカードを描く部品を1つ足す。角丸の四角にアイコンを入れる部品は、アプリのほかの場所にない。
- 「状態」の行の説明文が常に出ることを前提にした文言とテストを改める。

## 覆す条件

- ヘルパーを説明するページができ、説明のカードからリンクする価値が出る。
- 承認待ち以外の状態でも、利用者が次に何をすればよいか分からないという報告が続く。
