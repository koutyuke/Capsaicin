# DEC-UI-010 設定画面の「終了」ボタンは「このアプリについて」に置く

## 結論

設定画面の「Capsaicin を終了」ボタンを、サイドバーの下端から「このアプリについて」のバージョンの下に移す。ボタンは標準の `Button`（`.bordered`）で、色を付けない。配置は `SPEC-SET-004` にある。

## 背景

`DEC-UI-008` では、どのセクションからでも終了できるよう、サイドバーの下端にボタンを置いた。オーナーは、このボタンを「このアプリについて」に移したいと示した。のちにアップデートの確認などもここに入るので、アプリそのものについての操作を1か所にまとめたい、という理由である。

## 選択肢

- 「このアプリについて」に置く（採用）。
- サイドバーの下端に残す（`DEC-UI-008`）。どのセクションからでも1回で押せるが、サイドバーの下端にセクションではないものが混ざる。

## 理由

- 終了は、メニューバーのアイコンを隠しているときだけの入口で、頻繁には使わない（`REQ-MENU-005`）。1回の移動が増えても困らない。
- アプリのバージョン、終了、のちのアップデートの確認は、どれもアプリそのものについての操作なので、まとめておくと探しやすい。

## 影響

- サイドバーの下端からボタンがなくなり、下の2つのセクションはサイドバーの下端に寄る。
- メニューバーのアイコンを隠しているときに終了するには、設定画面で「このアプリについて」を開く必要がある。「メニューバーにアイコンを表示」の (i) の案内を直す。

## 覆す条件

- アイコンを隠している利用者から、終了の場所が見つからないという報告が続く。
