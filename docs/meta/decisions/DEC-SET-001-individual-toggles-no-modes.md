# DEC-SET-001 設定はすべて項目ごとに切り替え、モードを設けない

## 結論

すべての設定項目を、利用者が1つずつ切り替えられるようにする。「標準」「完全」のように複数の設定をまとめて切り替えるモードは設けない。

## 背景

止めるスリープの種類、解除の条件、LED、HUD など、利用者が選ぶ項目が多い。これらをどう選ばせるかを決める必要があった。

## 選択肢

- 「標準」「完全」などのモードを設ける。少ない操作で選べるが、モードと各設定項目の関係が分かりにくくなる（却下）。
- すべての項目を個別に切り替える（採用）。項目は増えるが、各項目の結果を予測できる。

## 理由

モードを設けると、モードを選んだときにどの項目が変わるのか、モードを選んだ後に項目を変えたらどうなるのかが分かりにくくなるため。

## 影響

- 設定画面は項目ごとのスイッチや値を並べる構成になる（`SPEC-SET-001`、`SPEC-SET-002`）。
- 将来のプリセット（`PLAN-BLK-001`）は、複数の設定をまとめて呼び出す点でモードと似る。要件にするときに、この判断との関係を整理する必要がある。

## 覆す条件

- 個別の項目だけでは、よく使う組み合わせへの切り替えが煩雑すぎると利用者が判断したら見直す。
