# DEC-UI-003 アプリのアクセントカラーを彩度を抑えた青灰色にする

## 結論

アプリのアクセントカラー（asset catalog の `AccentColor`）を、Revisual に近い、彩度を抑えた青灰色にする。値は `SPEC-UI-003` にある。

## 背景

- macOS は、システム設定のアクセントカラーが「マルチカラー」のときだけアプリのアクセントカラーを使い、それ以外では利用者の選んだ色に置き換える（`EVID-UI-002`）。
- Capsaicin は抑止中に画面の側から注意を引かない（`REQ-UI-002`）。

## 選択肢

- アクセントカラーを定めず、システムの青を使う（不採用）。
- Revisual の値（ライトで Display P3 の約 0.41、0.60、0.73）をそのまま使う。白い文字を載せたときのコントラストが足りない（不採用）。
- 少し暗くした青灰色（採用）。

## 理由

- システムの青より落ち着いて見え、オンのスイッチが画面の中で主張しすぎないため。
- デザインの試算では、ライトの値は白い文字と 5.39:1、ウインドウの背景（概算）と 4.82:1 になる。ダークの値は、スイッチや選択の見分けやすさ（グループの背景と、概算で 3.14:1）を優先した。背景の値は近似値であり、実機の色ではない。値は `SPEC-UI-003` にある。

## 影響

- 多くの利用者には、既定の青やそれぞれの好みの色で表示される。
- ダークでは、既定のボタンの白い文字とのコントラストが 2.95:1 になる。読めるかは `HYP-UI-001` で確かめ、読みにくければダークの値を `#5E93B8` に寄せる。

## 覆す条件

- `HYP-UI-001` が外れたら、ダークの値を見直す。
- オーナーの正式なアイコンの色と合わないと分かったら見直す。
