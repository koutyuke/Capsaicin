# DEC-BLK-003 片方だけを止める方式がない組み合わせは選べなくする

## 結論

手動スリープだけ、または蓋閉じスリープだけを止める組み合わせのうち、試作で実現できなかったものは、設定画面で選べないようにする。

## 背景

`disablesleep` はシステムのスリープ全体を止めるため、手動スリープと蓋閉じスリープの片方だけを止められない（`HYP-BLK-006`）。片方だけを止める方式は試作で確かめる（`HYP-BLK-002`、`HYP-BLK-003`）。

## 選択肢

- 実現できなかった組み合わせを選べないようにする（採用）。
- 移行元には、ほかの案の記録がない。

## 理由

選んだ設定と実際に止まるスリープが食い違わないようにするため。すべての項目を個別に切り替えられるという方針（`DEC-SET-001`）の例外になるが、選んだ結果が実現されない設定を見せるよりよい。

## 影響

- `SPEC-SET-002` の「手動スリープ」と「蓋閉じスリープ」は、試作の結果によって独立に切り替えられなくなる場合がある。
- 選べないことを設定画面でどう示すかは、別に決める。

## 覆す条件

- `HYP-BLK-002` と `HYP-BLK-003` がどちらも確かめられ、両方の組み合わせが実現できたら、この判断は不要になる。
