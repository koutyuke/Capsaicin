# DEC-UI-017 設定の説明文はどうなるかを中心に書き、文脈で分かれば「スリープ防止中は」を付けない

## 結論

`DEC-UI-015` のうち、「設定画面の説明で、スリープ防止がオンの間のことを書くときは「スリープ防止中は」で始める」を、次のように改める。ほかの結論（機能名「スリープ防止」と切り替えの言い方、止めるものの言い方、そのほかの言い方、文書の中の呼び名を対象にしないこと）は、そのまま引き継ぐ。

- 設定の説明文は、その項目でどうなるかを中心に書く。スリープ防止がオンの間のことだと項目と文脈から分かるときは、「スリープ防止中は」を付けなくてよい。分かりにくいときは、これまでどおり「スリープ防止中は」で始める。

## 背景

`DEC-UI-016` で、説明文を項目名の下に常に出すようにした。オーナーは「ディスプレイの自動オフを許可」と「Appleメニューからのスリープも防ぐ」の説明文から「スリープ防止中は」を外し、それぞれ「ディスプレイがオフになってもMacはスリープしません。」「Appleメニューからのスリープ操作も無効になります。」とした。「スリープ」のページの項目は、どれもスリープ防止で何が変わるかを決めるものなので、書き出しがなくても利用者には分かる。説明文では、どうなるかを中心に書きたいとした。

## 選択肢

- 文脈で分かれば付けなくてよいとする（採用）。
- 常に「スリープ防止中は」で始める（`DEC-UI-015`）。いつのことかは必ず伝わるが、どの説明文も同じ書き出しになり、本題が後ろに回る。
- どの説明文からも必ず外す。いつのことかが分かりにくい説明文でも書けなくなる。

## 理由

- 説明文は常に見えるので、短く、どうなるかが先に読める方がよい。
- 「スリープ」のページの項目は、スリープ防止のオン・オフで何が変わるかを決めるので、いつのことかはページと項目名から分かる。

## 影響

- `SPEC-SET-002` の「ディスプレイの自動オフを許可」と「Appleメニューからのスリープも防ぐ」の「説明文で伝えること」から「スリープ防止中は」を外し、String Catalog の説明文を合わせる。
- 「指定時刻に自動解除」の説明文は、スリープ防止をオンにした時点のことを書くので、この判断の対象にならない。

## 覆す条件

- 説明文を、スリープ防止がオフのときの動作と読み違えたという報告が出る。
- 「スリープ」のページの外に、スリープ防止中のことを書く説明文が増え、いつのことかが分かりにくくなる。
