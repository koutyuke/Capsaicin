# DEC-LED-007 キー配列を変更するアプリの案内は、設定の「フィードバック」だけに表示する

## 結論

キー配列を変更するアプリの案内（`SPEC-LED-005`）を、メニューから外し、設定の「フィードバック」セクションだけに表示する。案内の条件と内容は `DEC-LED-006` のまま変えない。Capsaicin 自身が LED を合わせられなかったときの警告（`SPEC-MENU-004`）は、メニューに残す。

## 背景

オーナーから、メニューの案内を削除し、設定画面だけに表示したいという要望があった。案内の条件は仮想キーボードがあることだけで、LED が実際に消されたことは示さない。キー配列を変更するアプリを常用していると、停止中も抑止中も、選べない注意の行がメニューに出続ける。

## 選択肢

- 設定の「フィードバック」だけに出す（採用）。
- メニューにも残す。LED が点かない原因の手がかりにすぐ届くが、対処の要らない案内が出続け、`SPEC-MENU-004` の対処が要る警告と同じ見た目で並ぶ。
- ステータスアイコンや見出しで示す。常時の合図が増え、メニューバーのアイコンを静かに保つ方針（`SPEC-UI-001`）とぶつかる。

独立した2人のアドバイザー（Codex と Claude）は、どちらも設定だけに出す案を推した。

## 理由

- 案内は異常の検出ではなく、可能性の提示である。LED の設定を決める場所に置けば、その文脈で読める。
- メニューの警告の行を、対処が要るものだけにできる。

## 影響

- `REQ-LED-007`、`SPEC-LED-005`、`SPEC-MENU-001` からメニューへの表示を外す。
- LED が点かないときに、メニューからは原因の手がかりが得られない。設定の「フィードバック」を開く必要がある。

## 覆す条件

- LED が点かない原因に気づけず困ったという報告が続く。
