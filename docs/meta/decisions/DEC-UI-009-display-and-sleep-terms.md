# DEC-UI-009 画面の文言では「システムスリープ」「ディスプレイスリープ」「ディスプレイの明るさを0にする」を区別し、「消灯」は LED だけに使う

## 結論

画面に出す日本語の文言では、止まるものの違いを次の3つの言葉で区別する。

| 言葉 | 指すもの | 対応する動作 |
| --- | --- | --- |
| システムスリープ | Mac 全体のスリープ | `pmset sleepnow` |
| ディスプレイスリープ | Mac を動かしたまま、ディスプレイだけがスリープすること | `pmset displaysleepnow` |
| ディスプレイの明るさを0にする | ディスプレイをスリープさせず、輝度を 0 にすること | 輝度を 0 にする |

そのほかの言い方は次のとおりにする。

- 装置としての画面と、その状態（スリープ、閉じる、明るさ）は「ディスプレイ」と書く。「画面」は、設定画面、ロック画面のような表示の内容や機能を指すときだけに使う。
- ノートブックの蓋（ディスプレイの面）と、それを閉じる操作は「ディスプレイ」「ディスプレイを閉じる」と書く。「蓋」は画面に出さない。
- 「消灯」「自動消灯」は、ディスプレイについては使わない。「消灯」「点灯」は Caps Lock の LED だけに使う。
- 「手動スリープ」は画面に出さない。アップルメニューの「スリープ」などの操作で書く。
- 「システムスリープ」は、利用者が初めて目にする (i) の説明で「システムスリープ（Mac 全体のスリープ）」と一度言い換える。
- 「スクリーンセーバ」「電源アダプタ」は語尾を伸ばさない。

文書の中の呼び名（`specs/blocking.md` の「手動スリープ」など）は、この判断の対象にしない。

## 背景

オーナーから、「消灯」はディスプレイスリープと混同しないか、アプリ内で表現を統一し、Mac で使われている表現にしたい、という指摘があった。設定画面では、ディスプレイについて「画面の自動消灯」「消灯」、LED について「点灯」「消灯」が混ざっていた。そのうえでオーナーは、システムスリープ、ディスプレイスリープ、明るさを 0 にすることを、アプリ内で名前で区別したいと示した。

ディスプレイスリープと明るさ 0 は、どちらもディスプレイが暗くなるので見た目では区別しにくい。一方で、ディスプレイスリープはシステム設定の「スクリーンセーバの開始後またはディスプレイがオフになったあとにパスワードを要求」の対象になり、明るさ 0 は対象にならない。閉じたときのディスプレイの選択肢に、将来「ディスプレイの明るさを0にする」が加わる（`Q-BLK-001`）。

macOS の今の日本語 UI は、ディスプレイスリープを「ディスプレイをオフにする」と書く（[Mac の「ロック画面」設定を変更する](https://support.apple.com/ja-jp/guide/mac-help/mh11784/mac)）。以前の「省エネルギー」設定は「コンピュータのスリープ」「ディスプレイのスリープ」と書いていた。蓋を閉じる操作は「Mac ノートブックの場合は、ディスプレイを閉じます。」と書く（[Mac をスリープ状態にする／スリープ解除する](https://support.apple.com/ja-jp/guide/mac-help/mh10330/mac)）。「画面」は「Mac の画面を拡大する」「画面共有」のように、映っている内容や機能の名前に使われている。

## 選択肢

- 3つを「システムスリープ」「ディスプレイスリープ」「ディスプレイの明るさを0にする」と呼ぶ（採用）。
- 今の macOS の言い方に合わせ、「Mac のスリープ」「ディスプレイをオフにする」「明るさを0にする」と書く。一般の利用者にはなじみがあるが、「オフにする」がスリープ防止のオン・オフと同じ言葉になり、3つの違いを名前で示しにくい。独立した2人のアドバイザー（Gemini と Codex）は、一般の利用者が「ディスプレイスリープ中に Mac は動いているのか」と迷うとして、こちらを推した。
- 3つ目を「画面の明るさを0にする」と書く。オーナーの最初の案だが、装置と状態を「ディスプレイ」と書く規則の例外になる。
- LED も「オン／オフ」にする。アプリ全体が「オン／オフ」にそろうが、LED は明かりなので「点灯」のほうが自然に読める。

## 理由

- 止まるものが3つあり、利用者が選ぶ場面がある。名前で区別すれば、項目名だけで何が止まるかが分かる。
- CLI やヘルパーまで使う利用者は、スリープの種類の言葉になじみがある。なじみのない利用者のためには、(i) で一度言い換える。
- 「消灯」を LED だけに使えば、ディスプレイの話と LED の話を取り違えない。

## 影響

設定画面、ヘルパーの確認ダイアログ、CLI の状態表示の文言を、この規則に合わせる。新しい文言もこの規則で書く。

## 覆す条件

- 利用者から「システムスリープ」「ディスプレイスリープ」の意味が分からないという報告が続く。
- macOS の日本語 UI が、スリープの種類について別の言い方に変わる。
