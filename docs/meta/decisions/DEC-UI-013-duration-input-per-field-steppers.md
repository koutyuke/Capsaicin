# DEC-UI-013 時間の長さの入力は、時間と分の欄それぞれに Stepper を付け、↑↓ キーでも増減できるようにする

## 結論

時間の長さを入力する場所（メニューの時間の入力パネルと、設定の「継続時間」）は、同じ部品で次のようにする。

- 時間の数値欄と分の数値欄に、それぞれ `Stepper` を付ける。
- 時間の `Stepper` は合計を 1 時間ずつ、分の `Stepper` は合計を 5 分ずつ増減する。分は 60 を超えたら時間に繰り上げ、0 を下回ったら時間から繰り下げる。
- 数値欄にフォーカスがあるときは、↑↓ キーでもその欄の `Stepper` と同じだけ増減する。
- 範囲は 1 分〜24 時間で、端で止める。範囲を出る操作は、範囲の端の値にする。
- 数値欄には 1 分単位で入力できる。範囲外や数字でない入力は、別の値に直さず、確定できない状態にする。

## 背景

今のパネルと設定の「継続時間」は、`Stepper` が1つだけ分の欄の右にあり、合計を 5 分ずつ動かす。オーナーから、up/down が分にしか効かないように見えるので、時間でも up/down したいという要望があった。

## 選択肢

- 欄ごとに `Stepper` を付け、↑↓ キーにも対応する（採用）。
- 欄ごとに `Stepper` を付けるだけにする。マウスでの不満は解けるが、隣の時刻の入力（`DatePicker` は ↑↓ が効く）とキー操作がそろわない。
- `Stepper` は1つのまま、↑↓ キーだけに対応する。マウスで見える形は今と同じで、分にしか効かない印象が残る。
- 入力の方式を変える。macOS に時間の長さの標準の部品はなく、`DatePicker` は 24:00 を表せない。スライダーは 1 分〜24 時間を細かく選びにくい。

独立した2人のアドバイザー（Codex と Claude）は、どちらも欄ごとの `Stepper` と ↑↓ キーの組み合わせを推し、設定の「継続時間」も同じ部品で直すよう指摘した。

## 理由

- どの欄が動くかが見た目で分かる。数値欄と `Stepper` の対は macOS の標準の形である。
- パネルと設定で同じ部品を使えば、刻みと範囲（`SPEC-MENU-003` は設定のタイマーと同じと定める）が食い違わない。

## 影響

- `SPEC-UI-005` の「時間の長さ」、`SPEC-SET-002` の「継続時間」、`SPEC-MENU-003` を直す。
- 設定の行とパネルが、`Stepper` 1つ分だけ横に長くなる。

## 覆す条件

- macOS に時間の長さを入力する標準の部品が加わる。
