# DEC-SET-009 ヘルパーを使えない行の注意を1つの文にそろえ、項目名の下の状態の文をなくす

## 結論

`DEC-SET-007` のうち、ヘルパーを使えない行の伝え方を改める。承認待ちのときの選び直しをアラートで案内すること（`DEC-SET-007`）は、そのまま引き継ぐ。

- ヘルパーが要る行が、ヘルパーを使えないための注意の記号を出している間は、ヘルパーの状態（未インストール、承認待ち、このビルドでは使えない、承認を待つ間に選んだ値を保留している）によらず、説明文の先頭に同じ1つの文「ヘルパーが有効になっていないため、設定を反映できません。」を出す。直し方は書かず、「ヘルパー」セクションに任せる。
- 項目名の下の状態の文（「ヘルパーが有効になっていません」）はなくす。
- メニューのクイック設定で同じ行に出す注意の文も、この文にそろえる。

## 背景

`DEC-UI-016` で説明文を項目名の下に常に出すようにしたところ、項目名の下に状態の文と説明文の先頭の注意が並び、同じことを2回伝える形になった。オーナーは文言を見直す中で、ヘルパーの問題はヘルパー側で直すものなので、この行で状態ごとの詳細を語る必要はないとした。

## 選択肢

- 状態によらず1つの文にし、状態の文をなくす（採用）。
- 状態ごとに理由と直し方を書き分け、状態の文も残す（`DEC-SET-007`）。直し方がその場で分かるが、文が長く、状態の文と説明文の先頭が重なる。
- 状態の文だけを残し、説明文の先頭の注意をなくす。項目名の下の文が2種類の見た目に分かれる。

## 理由

- 説明文が常に出るので、注意の記号を見た時点で、設定が効いていないことが読める。状態の文を別に置く理由（`DEC-SET-007`。(i) を開くまで理由が読めない）はなくなった。
- 直し方は「ヘルパー」セクションが状態ごとに示しているので（`SPEC-HLP-004`）、設定の各行で繰り返さない。行の文を短く保てる。

## 影響

- `SPEC-SET-003` から状態の文の例外を除き、`SPEC-SET-005` の注意の文を1つにする。`SPEC-HLP-001` の承認待ちの表示、`SPEC-MENU-008` の受け入れ例、手順書を合わせて直す。
- 「明るさを0」で輝度を変えられないことの注意（`SPEC-SET-005`）は変えない。ヘルパーの注意と重なるときは、ヘルパーの文を先に置く。
- 承認を待つ間に選んだ値を保留しているときも、まだ保存していないことを行では伝えない。

## 覆す条件

- 注意の文を読んでも何をすればよいか分からず、「ヘルパー」セクションにたどり着けないという報告が続く。
