# DEC-HLP-002 ヘルパーは C の小さな実行ファイルにし、検証してから設置する

## 結論

`DEC-HLP-001` を補い、次のようにする。

- ヘルパーは C で書いた小さな実行ファイルにする。受け付けた引数に応じて、空の環境変数で `/usr/bin/pmset -a disablesleep 1|0` を `execve` する。シェル、PATH の探索、任意の引数を使わない。受け付ける引数と、それ以外の扱いは `SPEC-HLP-002` にある。
- アプリは `/usr/bin/sudo -n <ヘルパーの固定パス> on|off` を、シェルを介さずに実行する。
- 設置は1回の管理者認証（`osascript` の `do shell script … with administrator privileges`）で、次の順に行う。
  1. ヘルパーを root だけが書き込める場所へ写し、内容のハッシュを確かめる。
  2. sudoers のルールを `.` を含む一時名で書き、`visudo -c -f` で検証してから置く。
  3. `visudo -c` で全体を確かめる。
  4. LaunchDaemon（起動時に `off`）を置く。
- 削除は逆の順で行う。sudoers の主体は uid（`#<uid>`）で書く。
- `disablesleep` には持ち主を決め、Capsaicin は自分が立てたものだけを戻す案を採る。規則は `SPEC-HLP-005` にある。

## 背景

root で動くコードは小さく、環境の影響を受けないものにしたい。sudoers の書式を誤ると sudo 全体が使えなくなる（`REQ-HLP-003`）。開発用の Mac では、Capsaicin と関係なく `SleepDisabled` が 1 になっていたことがある（`EVID-BLK-003`）。

## 選択肢

- sudoers で `pmset` を引数まで固定して直接許可する。root の自作コードがなくなるが、最小のヘルパーに切り出す方針（`DEC-HLP-001`）に合わない（不採用）。
- ヘルパーを Swift で書く。root で動くコードが大きくなる（不採用）。
- ヘルパーをシェルスクリプトにする。環境変数などの影響を受ける（不採用）。
- C の小さな実行ファイル（採用）。

## 理由

- root で動くコードを、引数の照合と1回の `execve` だけに絞れるため。
- sudoers を一時名で書いて検証してから置けば、書式の誤りで sudo を壊さないため（`EVID-HLP-001`）。`.` を含む名前のファイルは sudoers の読み込みの対象にならない。
- `-n` を付ければ、sudo が認証待ちで止まらないため。
- 持ち主を決めれば、ほかの道具や利用者が設定したスリープの禁止を、Capsaicin の解除で取り消さずに済むため。外部のものがすでにあるときに開始を拒否しないのは、利用者が求めた状態（スリープしない）がすでに満たされているのに失敗にしないためである。
- 持ち主を記録に持つのは、クラッシュの後でも、残った値が自分のものか外部のものかを見分けられるようにするためである（書く順序は `SPEC-LCY-007`）。
- Mac の起動時の LaunchDaemon だけが持ち主を問わず戻すのは、アプリが動いていない起動の直後には持ち主の記録を読めず、スリープできない状態を残さないことを優先するためである。
- ヘルパーの削除で `disablesleep` をヘルパーではなく削除の処理の中で戻すのは、ヘルパーが壊れていて `off` できない場合でも戻せるようにするためである。

## 影響

- sudoers は「このアプリだけ」ではなく、同じ利用者のほかのプロセスにも `on` と `off` を許す。被害はスリープが止まること（電池の消耗と発熱）にとどまるので受け入れる。
- 削除の処理は root で `pmset` を実行することがある（条件と、任意の入力を渡さないことは `SPEC-HLP-005`）。
- 実機での設置の確認は、承認を得て行う（`DEC-SYS-008`）。
- 自分で `disablesleep` を使う利用者は、ヘルパーを入れないこと。ヘルパーを入れると、Mac の起動のたびに LaunchDaemon がその `disablesleep` を 0 に戻す。

## 覆す条件

- 同じ利用者のほかのプロセスによる `on` の悪用が、実際の問題になると分かったら見直す。
- `HYP-BLK-001` が外れ、ヘルパーに画面を消す処理を足す必要が出たら、受け付ける引数を見直す。
