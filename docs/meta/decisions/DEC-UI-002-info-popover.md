# DEC-UI-002 設定の (i) の説明はポップオーバーを主にし、ツールチップも付ける

## 結論

設定の (i) の説明は、選択肢のうち「ポップオーバーを主にし、ツールチップも付ける」を採る。振る舞いは `SPEC-SET-003` にある。

## 背景

移行元の要件定義書は、名前だけでは結果が分かりにくい項目に (i) を置き、ツールチップで説明するとしていた。設定画面は、無効になった行の理由も (i) で示す（`SPEC-SET-005`）。

## 選択肢

- ツールチップだけ。キーボードと VoiceOver で開けない（不採用）。
- ポップオーバーを主にし、ツールチップも付ける（採用）。

## 理由

キーボードと VoiceOver だけで全操作ができるようにするため（`REQ-UI-003`）。無効の理由を読む手段をなくさないため、無効な行でも (i) は押せるようにする。

## 影響

- 移行元の「ツールチップで説明する」を、ポップオーバーとツールチップの両方に広げた（`REQ-SET-003`）。

## 覆す条件

- macOS の標準のコントロールで、ツールチップをキーボードと VoiceOver で開けるようになったら見直す。
