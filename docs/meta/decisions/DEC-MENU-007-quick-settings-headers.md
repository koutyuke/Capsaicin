# DEC-MENU-007 クイック設定の見出しを選択肢を持つ項目の名前にだけ使い、選択肢を字下げする

## 結論

`DEC-MENU-006` のうち、クイック設定の中の並べ方を次のように改める。ほかの決定（トップレベルの構成、時間・時刻のサブメニュー、クイック設定の行の注意の記号と副題、`DEC-MENU-005` から引き継いだもの）はそのまま引き継ぐ。

```text
✓ ディスプレイを自動でオフにしない
───
ディスプレイを閉じたとき              （見出し）
    ✓ システムスリープ（標準）          （1段字下げ）
      ディスプレイスリープ
      明るさを0
      オンのまま
───
✓ バッテリー残量20%未満でオフにする
    電源アダプタ接続中は除く
```

- 見出しは、選択肢を持つ項目（「ディスプレイを閉じたとき」）の名前にだけ使う。「スリープとディスプレイ」「バッテリー」のようなグループの名前は置かず、まとまりの間は区切りで分ける。
- 見出しの下の選択肢は、`NSMenuItem.indentationLevel` で1段字下げする。
- オン・オフの項目は、見出しがなくても何の設定か分かる名前にする。バッテリー残量の項目は、項目名にバッテリー残量であることを含める。

## 背景

`DEC-MENU-006` のとおり実装したクイック設定を見たオーナーから、グループの名前の見出し（「スリープとディスプレイ」「バッテリー」）と、項目の名前の見出し（「ディスプレイを閉じたとき」）が同じ見た目で並ぶことに違和感があると挙がった。見出しが2つの違う階層を表していた。

`NSMenuItem.sectionHeader` の見出しは、チェックの列の右、項目名と同じ位置から描かれる。そのため、見出しの下の選択肢がそのままでは見出しと同じ階層に見える。見出しを左に出す標準の手段はない。

## 選択肢

- 見出しは選択肢を持つ項目の名前にだけ使い、選択肢を字下げする（採用）。
- 見出しはグループの名前にだけ使い、閉じたときの選択肢を「閉じたらシステムスリープ」のような文の項目にする。4つの選択肢が独立したオン・オフに見え、同じ言葉が繰り返される。
- 設定ごとにトップレベルのサブメニューにし、今の値を副題で示す。見出しは要らないが、オン・オフにも2回の操作が要り、1つの設定が2行を使ってメニューが長くなる。

## 理由

- 見出しが「この下は選択肢」という1つの意味だけになり、階層のずれがなくなる。
- 字下げは標準の API で、見出しと選択肢の関係を形で示せる。
- 変更がクイック設定の中だけで済む。

## 影響

- `SPEC-MENU-008`、`SPEC-SET-006`、手順書のクイック設定の確認を直す。
- クイック設定の中に、設定画面のグループの名前が出なくなる。

## 覆す条件

- 字下げした選択肢の見た目に違和感があるという報告が続く。
- クイック設定の項目が増え、グループの名前がないと探しにくくなる。
