# DEC-UI-005 HUD の設定がオフでも、VoiceOver では切り替えを読み上げる

## 結論

HUD の設定は画面に表示するかだけを切り替えるものとし、VoiceOver の読み上げは HUD の設定によらず行う案を採る。振る舞いは `SPEC-HUD-008` にある。

## 背景

HUD はフォーカスを受けないので、VoiceOver はパネルの内容を自動では読まない。HUD の設定は、画面の表示を出すかどうかを選ぶものである（`REQ-HUD-003`）。

## 選択肢

- HUD の設定がオフなら、読み上げもしない。画面を見ない利用者が HUD の表示を消すと、操作の結果が伝わらなくなる（不採用）。
- 設定によらず、VoiceOver では読み上げる（採用）。

## 理由

HUD の表示を消しても、操作の結果が伝わらなくならないようにするため。

## 影響

- HUD の設定の意味は「画面に表示するか」になり、読み上げは含まない。

## 覆す条件

- 読み上げを止めたいという要望があり、別の設定を設ける価値があると分かったら見直す。
- `HYP-HUD-003` が外れたら、読み上げの方法を見直す。
