# DEC-LCY-004 終了理由が不明なら後片付けだけ行い、自動再開しない

## 結論

`DEC-LCY-003` を補い、終了理由を判定できないときは、抑止のセッションを消して後片付けする。自動再開はせず、終了を妨げるダイアログも出さない。戻せなかった制御と所有は既存の規則で記録し、次の起動で合わせ直す。判定できた利用者終了とセッション終了の扱いは変えない。

終了理由を利用者終了やセッション終了と偽って記録しない。既存の保存形式を維持し、実行中の印が下りていて `exitReason` が `nil` の記録を、理由不明の正常終了として扱う。実行中の印を残してクラッシュ扱いにすることもしない。

## 判定の境界

同じ終了試行に結び付いた明示的な利用者終了を優先する。次に、その試行で取得できたセッション終了の理由を使い、どちらもなければ判定不能とする。試行の終了・取り消し後に前の判定材料を持ち越さない。OS の通知順序と理由の取得可能性は `HYP-LCY-005` の検証対象であり、単体テストで確認済みとは扱わない。

## 選択肢と理由

- 不明な終了でも再開用セッションを残す。利用者が終了した抑止を勝手に再開する可能性があるため採らない。
- 不明な終了では再開せず、後片付けの失敗だけを記録する。意図しない抑止の再開を防ぐため採る。

## 影響

本当はログアウトや Mac の再起動だった場合も、理由を取得できなければ抑止は再開されない。この制約は利用者が承認した。

記録を保存できないまま終了した場合は、古い記録に従って再開し得る。`SPEC-LCY-007` の既知の保存失敗の制約は、この終了にも適用する。

## 覆す条件

対応環境で終了理由を確実に取得する方法が確認できた場合、判定不能になる経路を見直す。再開と停止のどちらを優先するかを変更するときは、利用者への影響を示して再度判断する。
