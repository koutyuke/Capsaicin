# DEC-UI-015 機能名は「スリープ防止」のまま、止めるものは macOS に合わせて「スリープ」「ディスプレイをオフ」と書く

## 結論

画面に出す文言を、次の規則で書く。`DEC-UI-012` から変えたのは「止めるもの」と、それに合わせた「消灯」の言い換えだけである。

### 機能名と切り替え

- スリープを止める機能の名前を「スリープ防止」とする。メニュー、HUD、CLI、設定の項目名で同じ名前を使う。
- 切り替えは「スリープ防止をオンにする」「スリープ防止をオフにする」、状態は「スリープ防止中」と書く。文脈から対象が分かる場所では「オン」「オフ」だけでよい（「時間を指定してオン」「4:00にオフ」）。
- メニューの開始と解除の項目は、状態に応じて項目名を入れ替える。チェックマークでは表さない。
- 利用者の操作で切ることを「停止する」「解除する」とは書かない。自動でオフにする条件をまとめて呼ぶときは「スリープ防止の自動解除」と書く。
- 設定画面の説明で、スリープ防止がオンの間のことを書くときは「スリープ防止中は」で始める。

### 止めるもの

| 指すもの | 日本語 | 英語 |
| --- | --- | --- |
| Mac 全体のスリープ | 「スリープ」。「ディスプレイを閉じたとき」の選択肢では「Macをスリープ」 | Sleep。選択肢では Put Mac to sleep |
| Mac を動かしたまま、ディスプレイだけがオフになること | 「ディスプレイをオフ」「ディスプレイがオフになる」。操作がないためにオフになることは「自動オフ」 | Turn display off、the display turns off |
| ディスプレイをオフにせず、輝度を 0 にすること | 「明るさを0」（追加の判断は `DEC-BLK-007`） | Set brightness to 0 |

- 「システムスリープ」「ディスプレイスリープ」は画面に出さない。
- ディスプレイについて「オフ」と書くときは、「ディスプレイを」「ディスプレイの」を必ず付け、スリープ防止のオン・オフと区別する。
- 設定の項目名は、項目が何をするかを動詞句で書く。「防ぐ」「制限」「抑止」を新しい項目名に使わない。
- 「手動スリープ」は画面に出さない。アップルメニューの「スリープ」などの操作で書く。

### そのほかの言い方

- 装置としての画面と、その状態（オフ、閉じる、明るさ）は「ディスプレイ」と書く。「画面」は、設定画面、ロック画面のような表示の内容や機能を指すときだけに使う。
- ノートブックの開閉する部分と、それを閉じる操作は「ディスプレイ」「ディスプレイを閉じる」と書く。
- 「消灯」「点灯」は Caps Lock の LED だけに使う。ディスプレイが暗くなることは「ディスプレイをオフ」と書く。
- macOS の日本語 UI に同じ語があれば、その表記に合わせる。「スクリーンセーバ」「電源アダプタ」は語尾を伸ばさない。

文書の中の呼び名（`specs/blocking.md` の「システムスリープ」「ディスプレイスリープ」「抑止」「手動スリープ」など）は、この判断の対象にしない。文書では、`pmset` などの技術の名前に合わせた呼び名を使い続ける。

## 背景

`DEC-UI-012` は、止めるものを「システムスリープ」「ディスプレイスリープ」と書いていた。名前だけで止まるものが分かり、「オフにする」をスリープ防止の切り替えだけに使えるからである。

オーナーは、この2つの語が技術の側に寄せた名前で、とくに新しい利用者にはなじみがなく、読む負担が大きいと指摘した。あわせて、項目名「ディスプレイの自動スリープを許可」の「スリープ」が、システム設定の言い方と違うことも挙げた。

macOS 26 のシステム設定の日本語 UI は、Mac 全体を「スリープ」、ディスプレイを「ディスプレイをオフにする」と書く。バッテリーの設定には「ディスプレイがオフのときに自動でスリープさせない」があり、2つをこの対で区別している。ホットコーナーには「ディスプレイをスリープさせる」が残るが、ロック画面とバッテリーの設定は「オフ」で書く。「システムスリープ」という語は使わない（開発機の `/System/Library/ExtensionKit/Extensions/` の `LockScreen.appex`、`BatterySettingsIntentsExtension.appex`、`DesktopSettings.appex` の `Localizable.loctable`、2026-11-19 に確認）。

同じ種類のアプリの Amphetamine は、日本語で「ディスプレイのスリープを許可」「ディスプレイを閉じたとき、システムのスリープを許可」と書く。英語の「display sleep」「system sleep」を訳した形で、アプリの中でも「ディスプレイスリープ」「ディスプレイをスリープ」と揺れている。

## 選択肢

Mac 全体のスリープ:

- 「Macをスリープ」（採用。ほかの場所では「スリープ」）。
- 「スリープ」だけ。アップルメニューと同じだが、「ディスプレイを閉じたとき」の選択肢では、ディスプレイについての選択肢と並ぶため、何が眠るかを読み取る必要がある。
- 「システムをスリープ」。macOS の日本語 UI は Mac 全体を「システム」と呼ばず、アップルメニューの「システム終了」と結び付けて読まれるおそれがある。
- 「システムスリープ」のまま（`DEC-UI-012`）。

ディスプレイ:

- 「ディスプレイをオフ」（採用）。
- 「ディスプレイスリープ」のまま（`DEC-UI-012`）。
- 「ディスプレイをスリープ」。ホットコーナーと同じだが、ロック画面とバッテリーの設定は「オフ」で書く。

## 理由

- 利用者は、システム設定とアップルメニューを毎日見ている。同じ言葉なら、新しい利用者も読み替えずに済み、システム設定と見比べやすい。
- 「ディスプレイを閉じたとき」の選択肢は、Mac が眠るか、ディスプレイだけが変わるかを選ぶものである。「Macをスリープ」「ディスプレイをオフ」と対象を書けば、読み比べるだけで違いが分かる。
- `DEC-UI-012` が心配した「オフにする」の重なりは、ディスプレイについての文言に「ディスプレイを」「ディスプレイの」を必ず付けることで避けられる。該当するのは設定の「スリープ」とメニューの「クイック設定」の項目、ヘルパーの削除の確認だけで、どれも対象のディスプレイを書いている。
- 「ディスプレイの自動オフを許可」の「自動」は、止める範囲と合っている。Capsaicin が止めるのは、操作がないためにオフになること（`PreventUserIdleDisplaySleep`）だけで、ホットコーナーや `pmset displaysleepnow` による利用者の操作は止めない。

## 影響

- String Catalog の「ディスプレイを閉じたとき」の選択肢、「ディスプレイの自動オフを許可」とその説明、ヘルパーの削除の確認を、この規則に合わせる。
- 仕様と手動確認の文書で、画面の名前を引くところを新しい名前にする。
- 判断・根拠・仮説は、書いた時点の名前を残す。

## 覆す条件

- 「ディスプレイをオフ」を、スリープ防止をオフにする意味に読み違えたという報告が続く。
- 「スリープ防止をオフにする」を、スリープしなくなる意味に読み違えたという報告が続く。
- macOS の日本語 UI が、スリープとディスプレイについて別の言い方に変わる。
