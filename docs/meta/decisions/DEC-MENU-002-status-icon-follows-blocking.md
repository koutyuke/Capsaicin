# DEC-MENU-002 抑止中はメニューバーのアイコンを塗りつぶしの版にする

## 結論

メニューバーのアイコンは、停止中は `custom.capsaicin.led`（輪郭）、抑止中は `custom.capsaicin.led.fill`（塗りつぶし）にする。切り替えは抑止の状態にだけ従い、設定では選ばせない。

## 背景

これまでメニューバーは、停止中も抑止中も同じアイコンを表示していた。オーナーは、画面を見ているときにメニューバーで抑止中かどうかを分かるようにしたいと求めた。

## 選択肢

- 抑止中は塗りつぶしの版にする（採用）。
- 停止中と抑止中で同じアイコンのままにする。抑止中かどうかはメニューを開くか、Caps Lock の LED を見るまで分からない。
- アイコンを替えるかを設定で選べるようにする。替えたくない利用者の声がまだなく、設定項目が増えるだけになる。

## 理由

- LED が消えている・点いていることを輪郭と塗りつぶしで表す規則（`SPEC-UI-004`）を、そのままメニューバーにも当てはめられる。HUD とサイドバーと同じ意味になる。
- 外付けキーボードなど、Caps Lock の LED が見えない環境でも、抑止中かどうかが分かる。

## 影響

- `REQ-MENU-004` に、抑止中かどうかをアイコンの見た目でも示すことを足す。
- 替えるときは、HUD と同じ置き換えの動きを1回だけ付ける。状態が変わった瞬間に1回動くだけで、点滅や脈動のように注意を引き続けない（`REQ-UI-002`、`SPEC-UI-006`）。

## 覆す条件

- ダークのメニューバーで、塗りつぶしの版の LED の穴が「消えている」と読まれ、抑止中なのに止まっているように伝わる（`DEC-MENU-001` の覆す条件と同じ）。
- 常に塗りつぶしが目に入ることが、抑止を長く続ける利用者にとって邪魔だという声が出る。
