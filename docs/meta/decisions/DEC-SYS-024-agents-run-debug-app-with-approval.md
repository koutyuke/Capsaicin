# DEC-SYS-024 オーナーが承認したら、エージェントは Debug アプリの起動と状態の読み取りまでを実機で行う

## 結論

`DEC-SYS-008` の「実機での確認は、手順を書いてオーナーの承認を得て行う」を補い、確認を行う人を分ける。`DEC-SYS-020` を置き換え、実機確認の操作の入口は次のとおり引き継ぐ。

- 実機確認で Debug アプリを操作する入口は、justfile の `app` グループのレシピ（`start`、`stop`、`restart`、`status`）にする。`stop` と `status` は、どのチェックアウトの Debug ビルドも対象にする。`start` は、Debug アプリが動いていないことを確かめ、LaunchAgent のジョブを外してから、このチェックアウトのビルドを開く。レシピの出力は英語にする。
- 実機の確認手順（`docs/manual/verification/`）が持つシェル変数は、検証ごとの退避先 `B` と、CLI を試すファイルが冒頭で定義する試験対象のパス `CLI` だけにする。検証用の変数は `.envrc` にも devShell にも置かない。

エージェントは、確認する対象と手順をオーナーに示して承認を得たら、その範囲で次を行ってよい。

- 自分の worktree でビルドした Debug アプリ（`io.github.koutyuke.capsaicin.debug`）を起動し、終了する。justfile の `app` グループのレシピを使ってよい。
- Debug アプリが起動のときに行う LaunchAgent の登録（SMAppService の agent と、「ログイン時に起動する」がオンなら mainApp。`DEC-LCY-008`）と、Debug のジョブに対する `launchctl` の `print`、`bootout`、`kickstart`。
- 状態の読み取り: `log show` と `log stream`、`launchctl print`、`pmset -g`（`assertions` などの読み取りを含む）、`ps`、Debug の CLI の `status`。
- 承認された手順に含まれる場合だけ、Debug の CLI の `on` と `off`。
- `screencapture` による画面写真。画面収録の許可は、オーナーが与える。

次は、承認があってもエージェントは行わず、手順書でオーナーに渡す。

- 画面のボタンなどの操作、UI の自動操作。
- 管理者の認証やシステム設定での承認が要る操作（ヘルパーの設置と削除、SMAppService のデーモンの承認）。
- `sudo`、`pmset` の設定の変更、Mac の再起動とログアウト。
- Release のアプリ（`io.github.koutyuke.capsaicin`）と、Debug 以外の launchd のジョブの操作。

## 背景

`DEC-SYS-020` は、実機確認のレシピをオーナーだけが実行すると決めていた。そのためエージェントはアプリを起動できず、実機での確認はすべてオーナーの手作業だった。ビルドやテストで確かめられない振る舞い（launchd の管理下での起動、ログ、抑止の状態）も、確かめるたびにオーナーの時間を使っていた。オーナーは、承認を得たうえでエージェントが自分で確かめられるようにしたいと決めた。

## 選択肢

- これまでどおり、実機の確認はすべてオーナーが行う（不採用）。
- 起動と読み取りまでをエージェントに任せる（採用）。
- 上に加え、System Events などで画面を操作させる。ターミナルにアクセシビリティの許可が要り、UI の自動操作は壊れやすい（不採用）。

## 理由

- 起動、終了、読み取りは、Debug のアプリとジョブだけに限れば、オーナーの環境の正式版や設定を変えない。
- 画面の操作を任せないことで、許可の範囲を広げずに済む。

## 影響

- `AGENTS.md` の禁止事項に、承認を得たときの例外を書く。
- justfile のグループの名前を `manual` から `app` に変え、レシピの説明を直す。`manual` は「オーナーが手で行う」という意味を持っていたので、エージェントも承認を得て実行する運用に合わせた。グループの指定は残し、承認が要るレシピを `just --list` でほかと分けて示す。
- Debug のジョブのラベルは worktree によらず同じなので、エージェントが Debug アプリを起動し直すと、オーナーがほかの worktree で動かしている Debug アプリは止まる。承認を求めるときに、そのことを示す。
- エージェントの確認の結果は、根拠（`EVID-*`）に残し、行ったコマンドを書く。

## 覆す条件

- エージェントの操作で、オーナーの環境に意図しない変更が残ったとき。
- 画面の操作も任せたいと決めたとき。
