# DEC-LED-002 抑止中は LED を常に点灯し、Caps Lock をオンにしたときの表示を選ぶ設定を置かない

## 結論

抑止中は、Caps Lock の状態にかかわらず LED を常に点灯する。「抑止中に Caps Lock をオンにしたときの表示」の設定は置かない。

## 背景

移行元の要件定義書は、この設定に「抑止の表示を優先して点灯」と「Caps Lock を優先」の2つの選択肢を定めていた。一方で、LED は抑止中は常に点灯させ、点滅などの区別は設けない方針だった。オーナーが 2026-11-06 に決めた。

## 選択肢

- 2つの選択肢を持つ設定を置く。抑止中も Caps Lock がオンのときも LED は点灯するので、どちらを選んでも見た目が同じになり、選択肢として意味を持たない（不採用）。
- 点滅などで区別する。抑止中に画面の側からも LED の側からも注意を引かない方針と合わない（不採用）。
- 設定を置かず、常に点灯する（採用）。

## 理由

どちらの選択肢でも LED の見た目が同じになり、利用者が選んでも結果が変わらないため。

## 影響

- 設定項目が1つ減る（`SPEC-SET-002`）。抑止中に Caps Lock をオンにしたかどうかは、LED では分からない。
- 抑止中の点灯の振る舞いは `SPEC-LED-001` にある。

## 覆す条件

- 抑止中に Caps Lock の状態を LED で知りたいという要望が出て、点灯以外の表示（消灯など）で区別する方法を受け入れられると分かったら見直す。
