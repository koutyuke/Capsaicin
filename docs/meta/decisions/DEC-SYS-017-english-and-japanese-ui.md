# DEC-SYS-017 画面を英語と日本語で表示し、開発言語を英語にし、時刻は OS の設定に従う

## 結論

- アプリの画面に表示する文字列を、英語と日本語で用意する。
- どちらを表示するかは macOS の言語の設定（システム設定の「言語と地域」の優先する言語と、アプリごとの言語の設定）に任せる。アプリの中に言語の切り替えは作らない。
- 開発言語（String Catalog の `sourceLanguage` と、バンドルの開発言語）を `ja` から `en` に替える。英語でも日本語でもない言語の設定では英語を表示する。
- 画面に表示する時刻は、OS の地域と時刻の設定（12時間制・24時間制を含む）に従う。残り時間などの期間も、表示している言語で示す。
- 文字列は引き続き String Catalog で管理し、コードに直接書かない。CLI の出力は `DEC-CLI-003` のとおり英語だけで、時刻は24時間制のまま変えない。

## 背景

`DEC-SYS-002` は、利用者が作者自身であることを前提に、表示言語を日本語だけにしていた。その覆す条件「日本語以外の利用者に配ることになったら、英語などの追加を見直す」に当たり、オーナーが英語への対応を求めた。公開したアプリは README を英語でも用意しており、日本語を読まない利用者も使う。

文字列はすでに機能ごとの String Catalog にあり、キーは文言ではなく意味の名前（例: `menu.battery`）である（`DEC-SYS-007`）。そのため、言語の追加と開発言語の切り替えは、カタログの値と `sourceLanguage` の変更で済む。

時刻の表記は、24時間制に固定するか OS の設定に従うかを未決の論点として残していた。画面の時刻は `H:mm` に固定しており、英語の利用者の多くが使う12時間制の設定と食い違う。

## 選択肢

表示言語:

- 英語と日本語を用意し、開発言語を英語にする（採用）。英語でも日本語でもない設定の利用者には英語が出る。カタログの `sourceLanguage` とバンドルの開発言語を検査するテストを直す。
- 英語と日本語を用意し、開発言語を日本語のままにする（不採用）。変更は小さいが、英語でも日本語でもない設定の利用者には日本語が出る。
- アプリの中に言語の切り替えを置く（不採用）。macOS がアプリごとの言語の設定を持っており、同じ機能を重ねることになる。

画面の時刻:

- OS の地域と時刻の設定に従う（採用）。ほかのアプリと表記がそろう。CLI の入力と出力（24時間制）と表記が食い違うことがある。
- 24時間制に固定する（不採用）。CLI と一致するが、12時間制の利用者にはほかのアプリと表記がそろわない。

## 理由

- 公開して配る以上、英語でも日本語でもない設定の利用者にも読める言語を出すほうがよい。開発言語を英語にするのは、macOS が優先する言語のどれにも当たらないときに開発言語を使うためである。
- 言語の選択は macOS の仕組みに任せれば、アプリに設定や状態を足さずに済む。
- 画面の時刻は、利用者が OS で選んだ表記に合わせるほうが読み違えにくい。CLI は、入力の書式（`SPEC-CLI-001`）と出力をそろえる理由が `DEC-CLI-003` にあるので変えない。
- `Locale.current` は、アプリの表示言語と、OS の地域・12時間制か24時間制かの設定の両方を反映する。小さな検証用のバンドルで、英語を指定して地域が日本なら `en_JP`、優先する言語がフランス語だけなら `en_FR` になることを確かめた。そのため、時刻と期間は `Locale.current` でそのまま書式化でき、言語と地域を組み合わせたロケールを独自に作らずに済む。

## 影響

- `REQ-SYS-003` と `REQ-SYS-004` を、英語と日本語の表示と、開発言語が英語であることに合わせて直す。`SPEC-UI-011` に表示言語の選び方を、`SPEC-UI-012` に時刻と期間の表記を書く。時刻の表記の論点は、画面について決まったので削除する。
- すべての String Catalog に英語の値を入れ、`sourceLanguage` を `en` にする。`project.yml` の開発言語と既知の地域を直す。
- コードに直接書いていた画面の文字列（終了時のアラート）を String Catalog に移す。
- 時刻と期間を書式化するコードを、OS の設定と表示している言語に従わせる。
- バンドルの開発言語と言語ごとのリソースを検査するテストを直す。
- 文言を変えるときは、英語と日本語の両方を直す必要がある。

## 覆す条件

- 英語と日本語以外の言語を追加することになったら、開発言語と、言語ごとの文言の管理の仕方を見直す。
- 12時間制の表示で、メニューや HUD に時刻が収まらないことが分かったら、表記を見直す。
