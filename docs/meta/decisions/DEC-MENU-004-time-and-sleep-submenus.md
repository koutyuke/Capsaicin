# DEC-MENU-004 メニューの時間の指定を1つのサブメニューにまとめ、スリープとディスプレイの2項目をメニューから切り替えられるようにする

## 結論

時間の指定:

- 時間を決めて開始するサブメニューに、時刻の指定と「時間の条件なし」を入れる。トップレベルの「時刻を決めて開始する項目」はなくす。
- 抑止中は、同じ中身のサブメニューを「オフにする時刻を変更」として出す。選ぶと、`DEC-BLK-009` のとおり解除の時刻を置き換える。サブメニューの先頭に、起点が今であることを示す見出しを置く。
- プリセットや選んだ値にチェックマークは付けない。いまの解除の時刻は、状態の表示（`SPEC-MENU-004`）で示す。
- 時間・時刻の入力パネルは、停止中は開始、抑止中は変更として、タイトルと確定のボタンを替える。パネルには、確定したらオフになる時刻を示す。

スリープとディスプレイ:

- メニューに「スリープとディスプレイ」のサブメニューを置き、設定の「スリープ」の「スリープとディスプレイ」にある2つの項目（ディスプレイスリープの項目と「ディスプレイを閉じたとき」）を切り替えられるようにする。ディスプレイを閉じられない Mac では、「ディスプレイを閉じたとき」の代わりに、その Mac で設定画面に出す項目を出す（`SPEC-SET-006`）。
- 項目名と選択肢は設定画面と同じにし、選ぶと設定画面で変えたときと同じく保存してその場で反映する（`SPEC-BLK-009`）。ヘルパーが要る選択肢の確認、エラー、巻き戻しも設定画面と同じ流れにする。
- 停止中と抑止中で同じ形にする。
- タイマー、指定時刻、バッテリー残量の設定は、メニューに出さない。

## 背景

オーナーから、オンにした後に時間と詳細設定を変えたいという要望があった。詳細設定として挙がったのは、ディスプレイの自動のスリープと、ディスプレイを閉じたときの動作の2つである。

Amphetamine の「クイック設定」は、保存される既定のセッションの設定をメニューに並べ、「今現在のセッションである必要はありません」という注意書きを置いている。メニューの値が今の状態なのか既定値なのかが分からなくなるためである。

## 選択肢

時間の指定の置き場所:

- 時刻の指定もサブメニューに入れる（採用）。停止中と抑止中のトップレベルが同じ形（切り替えの項目と時間のサブメニュー）になる。時刻で始める操作が1階層深くなる。
- 時刻の指定をトップレベルに残す。時刻で始めるのは速いが、抑止中に同じ形の変更の項目を作ると、トップレベルの項目が増える。

詳細設定:

- 2つの項目をサブメニューで切り替えられるようにする（採用）。
- メニューに出さず、設定画面だけで変える。入口は1つで済むが、抑止中に切り替えるたびに設定画面を開く。
- 設定画面の「スリープ」を開く項目だけを置く。

アドバイザーの2人は、詳細設定をメニューに出さない案を推した。Amphetamine と同じく、今の値と既定値がメニューで混ざることを理由にしていた。

## 理由

- この2つの項目は、設定画面で変えても抑止中にその場で反映され、保存値と今の値がいつも一致する。Amphetamine のように、今の値と既定値が分かれることがない。メニューの項目は、同じ設定へのもう1つの入口になるだけである。
- タイマーと指定時刻の設定は、抑止中に変えてもいまの抑止に効かないので、メニューに並べると今の値と既定値が混ざる。メニューの時間の指定と役割も重なる。
- バッテリー残量は、しきい値など値を持つ項目で、メニューで切り替える場面が少ない。

## 影響

- `SPEC-MENU-001`〜`SPEC-MENU-003` を直し、スリープとディスプレイのサブメニューを新しい仕様にする。
- ヘルパーの確認のダイアログが、メニューの操作からも開く。
- 同じ設定を変える入口が、設定画面とメニューの2つになる。

## 覆す条件

- メニューの項目が設定画面と食い違って見えたという報告が続く。
- ほかの設定もメニューで切り替えたい場面が続き、今の値と既定値を分けて見せる必要が出る。
