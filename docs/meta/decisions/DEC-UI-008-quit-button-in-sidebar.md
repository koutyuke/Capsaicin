# DEC-UI-008 設定画面の「終了」ボタンはサイドバーの下端に、色を付けずに置く

## 結論

設定画面のサイドバーの下端に、標準の `Button`（`.bordered`）で「終了」ボタンを置く。色は付けない。どのセクションを選んでいても表示する。配置と寸法は `SPEC-SET-001` にある。

## 背景

メニューバーのアイコンを隠せるようにする（`REQ-MENU-005`）と、メニューの「終了」が使えなくなる。そのため、設定画面に終了の入口が要る。設定画面を開き直すと前回のセクションが開く（`SPEC-SET-001`）ので、どのセクションから開いても終了できる場所に置く必要がある。

オーナーは、AltTab の設定ウインドウ（サイドバーの下端に「AltTab を終了」ボタンがある）を参考に挙げ、サイドバーの下端か「一般」の一番下に赤字で置く案を示した。

## 選択肢

- サイドバーの下端に、色を付けないボタンを置く（採用）。
- 「一般」の一番下に、独立したグループとして赤字のボタンを置く（不採用）。実装は1行で済むが、終了するには先に「一般」を開く必要がある。
- アイコンを隠しているときだけボタンを表示する（不採用）。表示の条件が増え、ボタンの位置が設定によって変わる。

## 理由

- どのセクションを開いていても、移動せずに終了できる。
- 赤は、macOS では削除などの破壊的な操作に使う色である。終了で保存した設定が失われることはないので、赤にしない。
- オーナーがサイドバーの下端を選んだ。

## 影響

- `SPEC-SET-001` のサイドバーの下端の配置を変える。下の2項目は、下端ではなく「終了」ボタンのすぐ上に寄せる。
- 下の2項目を寄せる空きの高さ（`DEC-UI-006` の「影響」）は、ボタンの分を除いて決める。

## 覆す条件

- サイドバーの下端のボタンが、セクションの選択や VoiceOver の移動を妨げると分かったら、置き場所を見直す。
