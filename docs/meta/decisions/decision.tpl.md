# DEC-DOMAIN_CODE-001 判断の名称

## 結論

選んだ案を書く。

## 背景

判断が必要になった状況と制約を書く。

## 選択肢

検討した案と、それぞれを選んだ場合に起きることを書く。

## 理由

選んだ案に決めた理由を書く。

## 影響

この判断で変わる要件、仕様、実装、運用と、引き受ける代償を書く。

## 覆す条件

どんな事実が分かったらこの判断を見直すかを書く。
