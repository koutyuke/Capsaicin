# EVID-SYS-002 macOS が止めたアプリは、プライバシーとセキュリティの「このまま開く」で開ける

## 確かめた事実

Apple の Mac ユーザガイドによると、macOS が開くのを止めたアプリは、次の手順で開ける。

1. Apple メニュー >「システム設定」を選び、サイドバーの「プライバシーとセキュリティ」をクリックする。
2. 「セキュリティ」で「開く」をクリックする。
3. 「このまま開く」（英語版では Open Anyway）をクリックする。このボタンは、アプリを開こうとしてから約 1 時間だけ使える。
4. ログインパスワードを入力し、「OK」をクリックする。

## 確かめ方

上記の URL の英語版を読んだ。日本語版の表記は英語版の「Open Anyway」に当たるものとして移行元の表記（「このまま開く」）に合わせた。

## 適用範囲

公証していないアプリを利用者が開く手順の根拠に使ってよい。

## 未確認のこと

- 日本語版のガイドでのボタンの正確な表記。
- 公証していないアプリを配布した場合に、実際にこの手順で開けるか。
